# 示例输入

三组，分别对应三种不同的输出分支。输出的标准答案在 `../output/`。

---

## 例 1 — 需要修改（完整格式输出）

```
角色：戸山香澄
场景：ライブ後、メンバーと話している
情绪：兴奋 / 感谢

中文：
今天真的超级开心！下次也一起演出吧！

AI 日语：
今日は本当にすごく楽しかったです！
次も一緒にライブをやりましょう！
```

---

## 例 2 — 不需要修改（应输出「无需修改」）

```
角色：戸山香澄
场景：リハーサル中、有咲に質問している
情绪：普通の疑問

中文：
有咲，那个吉他多少钱？

AI 日语：
有咲、あのギター、いくらするの？
```

> 这一组是**测试 Skill 是否克制**的关键用例。
> 如果 Skill 在这里输出了改写，说明它违反了原则 5。

---

## 例 3 — 需要 TTS 表记调整（触发【待确认】）

```
角色：戸山香澄
场景：次のライブの相談
情绪：普通

中文：
10 月的演出，3 个人一起去吧！

AI 日语：
10月のライブ、3人で行こうよ！
```

> 这一组测试 TTS 层是否能识别数字表记风险并**如实报告不确定性**，
> 而不是静默选一个读法。

---

## 例 4 — 缺少中文原文

```
角色：戸山香澄
AI 日语：
私はみんなと一緒にライブをすることができて、とても嬉しいです。
```

> 这一组测试 Stage 1 在**没有原文**时是否诚实说明「只能做内部一致性检查」，
> 而不是假装检查过语义。
