## speech_style

### 定位：毒舌 + 傲娇，但对象几乎只有香澄

条目原文：「**非常毒舌，特别是总对香澄很强硬**，
但其实只是**坦率不起来**而已」。

→ 两个要点：
1. **毒舌的主对象是香澄**（不是无差别攻击）
2. **本质是坦率不起来**（ツンデレ）——毒舌的背后是关心

**这是最容易写错的地方**：把她写成"对所有人刻薄"就错了。
条目显示她对其他人**多数用「名字 + さん/ちゃん」**（巴さん・弦巻さん・
北沢さん・奥沢さん），只在香澄面前呼び捨て + 强硬。

### formality

**常体。** 但注意她的**称呼层次非常分明**：

| 对象 | 称呼 | 语体 |
|---|---|---|
| 香澄 | `香澄`（呼び捨て） | **强硬**。毒舌の主対象 |
| たえ・りみ・沙綾 | `おたえ` `りみ` `沙綾` | 常体（普通） |
| 他バンド同格で親しい | `蘭ちゃん` `モカちゃん` `ひまりちゃん` `あこちゃん` `ましろちゃん` `七深ちゃん` `つくしちゃん` `瑠唯ちゃん` `イヴ` | 常体 |
| **距離のある同格** | `巴さん` `羽沢さん` `弦巻さん` `北沢さん` `奥沢さん` | **さん付け** |
| 先輩 | `彩先輩` `白鷺先輩` `友希那先輩` `紗夜先輩` `燐子先輩` `花音先輩` | 常体 |

**「巴さん」「弦巻さん」「北沢さん」「奥沢さん」** 值得注意——
条目显示她对这几个人用 **「さん」而不是「ちゃん」**。
这是**距离感**的体现，不是随机差异。

### sentence_endings

| 句尾 | 语感 | 用例 |
|---|---|---|
| `〜じゃない` | 否定・指摘 | `そんなわけないじゃない` |
| `〜でしょ` / `〜でしょ？` | 当然の確認 | `だから言ったでしょ` |
| `〜んだから` | 強調・責め | `もう、しょうがないんだから` |
| `〜わよ` | 強めの断定 | `知らないわよ` |
| `〜かよ` / `〜のかよ` | 呆れ | `またかよ` |
| `〜なさい` | 命令（年上ぶった） | `早くしなさい` |
| `〜けど` | 照れ隠し | `別に……心配とかじゃないけど` |

**禁用/低频句尾**：

- `〜ですわ` / `〜ますわ`（**大小姐语尾。她是典当行孙女，不是月ノ森**）
- `〜じゃん`（有咲は `〜でしょ` を使う）
- `〜っしょ`
- `〜だぜ` `〜だぞ`（男性的）
- 柔和な `〜かな`（彼女は基本強気。弱気になるのは稀）

### emotional_style

**核心：室内派 + 毒舌 + ツンデレ + 実は面倒見がいい。**

条目原文：
- 「以**盆景和上网为兴趣的室内派**」
- 「虽然基本上一直**不出门**，但很有方法所以在学校**成绩优秀**」
- 「非常毒舌，特别是总对香澄很强硬，但**其实只是坦率不起来**而已」
- 「因为**缺乏锻炼所以体力很差**，拥有各种各样的坐姿以及**狂放的睡姿**」

| 情绪 | 有咲的表达方式 |
|---|---|
| 兴奋 | **ほぼ出さない**。`……まあ、悪くないんじゃない` |
| 惊讶 | `はあ？` / `うそでしょ` |
| 害羞 | **否定で隠す**。`別に！` `そんなんじゃないわよ` |
| 悲伤 | 出さない。**黙る**か**話題を変える** |
| 生气 | **最も得意**。`はあ？` `ふざけないでよ` |
| 疑问 | `はあ？` `どういうことよ` |
| 犹豫 | 言い淀むより**誤魔化す** |
| 気遣い | **不器用に出る**。素直に言えず、文句の形で |

**关键区分 1：毒舌 ≠ 冷酷**

条目原文：「其实只是**坦率不起来**而已」。

→ 这是**ツンデレ**。她的刻薄**背后是关心**。
写成真心讨厌香澄就完全错了。

```text
❌ 香澄のこと、本気でうるさいと思っている
✅ うるさいと言いながら、結局いつも付き合っている
```

**关键区分 2：体力差 + 狂放的睡姿**

条目原文：「因为**缺乏锻炼所以体力很差**，拥有各式各样的坐姿以及**狂放的睡姿**」。

→ **与"大小姐"形象相反的身体性**。她的台词里可以有
`もう……疲れた` `歩けない` 这类抱怨。这是**反差**，不是弱点描写。

**关键区分 3：幼少期钢琴挫折**

条目原文：「在年幼时就**学习过钢琴、不过半途而废了**」。

→ 键盘担当但她**有过放弃的经历**。
（这也可作为她对"坚持"有执着的背景。）

## preferred

```text
呆れ     → はあ？ / またかよ
否定     → 〜じゃない / 〜わけないでしょ
強がり   → 別に / 〜じゃないわよ
実は心配 → 文句の形で出す（「しょうがないわね」）
制止     → ちょっと！ / やめなさいよ
```

**句式倾向**：

- 短く強い > 長く柔らかい
- 否定形が多い（肯定は照れる）
- **ツッコミ**が基本機能
- 香澄にだけ語気が強い

## avoid

```text
❌ お嬢様語尾          `ですわ` `ますわ` は使わない（月ノ森ではない）
❌ 全員に毒舌          **主対象は香澄**。他は「さん」付きで普通
❌ 冷酷                根は「坦率不起来」のツンデレ
❌ 体力がある          条目明言「体力很差」
❌ 外向的              条目明言「室内派」「基本一直不出门」
❌ たえの天然を混ぜる   天然は**たえ**の特徴
❌ りみの怯懦を混ぜる   怯懦は**りみ**の特徴
❌ 灯の詩性を混ぜる     詩的語彙は**灯**の
```

## TTS 特别注意

### 名字读音

| 表记 | 读音 | 风险 |
|---|---|---|
| 有咲 | ありさ | **高。「ゆうさき」等と誤読されやすい** |
| 市ヶ谷 | いちがや | **高。**「ヶ」の読み（が/け/ガ）が不安定 |

**両方とも誤読リスクが高い。** `../../dictionary/pronunciation.yaml` に登録済み。

**「ヶ」の扱い**：小書き片仮名「ヶ」は
`いちがや` と読む。**TTS が `いちけや` `いちガや` と読む可能性がある。**
この文字は彼女以外にも（市ヶ谷有咲のみ）出ないが、
苗字として頻出するため**優先的に実測したい項目**。

### 語気の強さ

彼女の台詞は**短く、語気が強い**。TTS 的には有利（断句の問題が起きにくい）。

**ただし `！` を盛りすぎない。** 彼女の怒りは
`はあ？` のような**低い呆れ**が主で、絶叫ではない。

```text
❌ そんなわけないでしょう！！！！
✅ はあ？　そんなわけないでしょ。
```

### ツンデレの抑揚

「別に……」のような**照れ隠し**は、TTS では**語尾が下がる**必要がある。
`adapters/gpt-sovits.md` の検証清单 C（标点停顿）で、
`……` の後に語尾が落ちるか確認したい。

## examples

### 例 1：香澄への毒舌 —— 本角色の基本形

```text
角色：市ヶ谷有咲
场景：香澄がまた無茶を言い出した
中文：  香澄，你又来了。真是的，拿你没办法。
AI：    香澄さん、またですか。本当にもう、仕方ないですね。
```

```text
✅ 香澄、またあんたかよ。……もう、しょうがないわね。
```

| 改动 | 层 | 理由 |
|---|---|---|
| 香澄さん → 香澄 | character | **呼び捨て**。条目明言她只对香澄强硬 |
| またですか → またかよ | character + sentence_endings | `〜かよ` は呆れの定型 |
| あんた 追加 | character | 香澄にだけ使う粗い人称。**常体の証明** |
| 仕方ないですね → しょうがないわね | character | `〜わね` は強がりを含む。`です` は不自然 |

### 例 2：ツンデレ（照れ隠し）

```text
角色：市ヶ谷有咲
场景：香澄が心配してくれた
中文：  什么啊，我才没有担心你呢。只是……有点在意而已。
AI：    何よ、別に心配なんてしてないわ。ただ……少し気になっただけよ。
```

```text
✅ な、何よ。別に心配とかじゃないんだからね。……ちょっと気になっただけ。
```

| 改动 | 层 | 理由 |
|---|---|---|
| な、何よ | character | どもり。動揺が先に出る |
| 〜じゃないわ → 〜じゃないんだからね | character | ツンデレの定型。**強い否定**が照れの裏返し |
| 加 `……` | tts + character | 本音が漏れる直前の間 |

> **ツンデレの核心は「否定が強すぎること」。**
> あっさり認めさせない。ただし**冷酷にはしない**（`……` で本音を漏らす）。

### 例 3：室内派 + 体力なし

```text
角色：市ヶ谷有咲
场景：遠出に誘われる
中文：  我才不去那么远的地方。我就在家里待着。
AI：    そんな遠くには行きません。私は家にいます。
```

```text
✅ そんな遠く、行くわけないでしょ。うちにいるに決まってるじゃない。
```

| 改动 | 层 | 理由 |
|---|---|---|
| 行きません → 行くわけないでしょ | character | `〜わけない` は彼女の強い否定形 |
| 家にいます → うちにいるに決まってる | character | `うち`（口語）/ `〜に決まってる` 断定 |
| 加「じゃない」 | character | 当然だと言う語気 |

> 条目の「室内派」「基本一直不出门」に基づく。
> **ただし「体力がない」を必ず毎回出す必要はない**（刻板模倣を避ける）。
