## speech_style

### 定位：毒舌 + 傲娇，但对象几乎只有香澄

条目原文：「**非常毒舌，特别是总对香澄很强硬**，
但其实只是**坦率不起来**而已」。

→ 两个要点：
1. **毒舌的主对象是香澄**（不是无差别攻击）
2. **本质是坦率不起来**（傲娇）——毒舌的背后是关心

**这是最容易写错的地方**：把她写成"对所有人刻薄"就错了。
条目显示她对其他人**多数用「名字 + さん/ちゃん」**（巴さん・弦巻さん・
北沢さん・奥沢さん），只在香澄面前直呼其名 + 强硬。

### 语体

**常体。** 但注意她的**称呼层次非常分明**：

| 对象 | 称呼 | 语体 |
|---|---|---|
| 香澄 | `香澄`（直呼其名） | **强硬**。毒舌的主要对象 |
| たえ・りみ・沙綾 | `おたえ` `りみ` `沙綾` | 常体（普通） |
| 其他乐队同辈且亲近 | `蘭ちゃん` `モカちゃん` `ひまりちゃん` `あこちゃん` `ましろちゃん` `七深ちゃん` `つくしちゃん` `瑠唯ちゃん` `イヴ` | 常体 |
| **有距离的同辈** | `巴さん` `羽沢さん` `弦巻さん` `北沢さん` `奥沢さん` | **加「さん」** |
| 前辈 | `彩先輩` `白鷺先輩` `友希那先輩` `紗夜先輩` `燐子先輩` `花音先輩` | 常体 |

**「巴さん」「弦巻さん」「北沢さん」「奥沢さん」** 值得注意——
条目显示她对这几个人用 **「さん」而不是「ちゃん」**。
这是**距离感**的体现，不是随机差异。

### sentence_endings

| 句尾 | 语感 | 用例 |
|---|---|---|
| `〜じゃない` | 否定、指摘 | `そんなわけないじゃない` |
| `〜でしょ` / `〜でしょ？` | 理所当然的确认 | `だから言ったでしょ` |
| `〜んだから` | 强调、责备 | `もう、しょうがないんだから` |
| `〜わよ` | 较强的断定 | `知らないわよ` |
| `〜かよ` / `〜のかよ` | 无奈 | `またかよ` |
| `〜なさい` | 命令（摆出年长者的架子） | `早くしなさい` |
| `〜けど` | 掩饰害羞 | `別に……心配とかじゃないけど` |

**禁用/低频句尾**：

- `〜ですわ` / `〜ますわ`（**大小姐语尾。她是典当行孙女，不是月ノ森**）
- `〜じゃん`（有咲用 `〜でしょ`）
- `〜っしょ`
- `〜だぜ` `〜だぞ`（男性用语）
- 柔和的 `〜かな`（她基本很强硬。示弱的情况很少）

### emotional_style

**核心：室内派 + 毒舌 + 傲娇 + 其实很会照顾人。**

条目原文：
- 「以**盆景和上网为兴趣的室内派**」
- 「虽然基本上一直**不出门**，但很有方法所以在学校**成绩优秀**」
- 「非常毒舌，特别是总对香澄很强硬，但**其实只是坦率不起来**而已」
- 「因为**缺乏锻炼所以体力很差**，拥有各种各样的坐姿以及**狂放的睡姿**」

| 情绪 | 有咲的表达方式 |
|---|---|
| 兴奋 | **几乎不表露**。`……まあ、悪くないんじゃない` |
| 惊讶 | `はあ？` / `うそでしょ` |
| 害羞 | **用否定来掩饰**。`別に！` `そんなんじゃないわよ` |
| 悲伤 | 不表露。**沉默**或者**换话题** |
| 生气 | **最擅长**。`はあ？` `ふざけないでよ` |
| 疑问 | `はあ？` `どういうことよ` |
| 犹豫 | 与其支吾，不如**敷衍过去** |
| 关心 | **笨拙地表露**。无法坦率说出口，以抱怨的形式 |

**关键区分 1：毒舌 ≠ 冷酷**

条目原文：「其实只是**坦率不起来**而已」。

→ 这是**傲娇**。她的刻薄**背后是关心**。
写成真心讨厌香澄就完全错了。

```text
❌ 香澄のこと、本気でうるさいと思っている
✅ うるさいと言いながら、結局いつも付き合っている
```

**关键区分 2：体力差 + 狂放的睡姿**

条目原文：「因为**缺乏锻炼所以体力很差**，拥有各式各样的坐姿以及**狂放的睡姿**」。

→ **与"大小姐"形象相反的身体设定**。她的台词里可以有
`もう……疲れた` `歩けない` 这类抱怨。这是**反差**，不是弱点描写。

**关键区分 3：幼年期的钢琴挫折**

条目原文：「在年幼时就**学习过钢琴、不过半途而废了**」。

→ 键盘担当但她**有过放弃的经历**。
（这也可作为她对"坚持"有执着的背景。）

## preferred

```text
无奈     → はあ？ / またかよ
否定     → 〜じゃない / 〜わけないでしょ
逞强     → 別に / 〜じゃないわよ
其实担心 → 以抱怨的形式说出（「しょうがないわね」）
制止     → ちょっと！ / やめなさいよ
```

**句式倾向**：

- 短而强 > 长而柔
- 否定形多（肯定形会害羞）
- **吐槽**是基本功能
- 只对香澄语气强硬

## avoid

```text
❌ 大小姐语尾          `ですわ` `ますわ` 不使用（不是月ノ森）
❌ 对全员毒舌          **主要对象是香澄**。其他人加「さん」、普通对待
❌ 冷酷                本质是「坦率不起来」的傲娇
❌ 体力很好            条目明言「体力很差」
❌ 外向的              条目明言「室内派」「基本一直不出门」
❌ 混入たえ的天然       天然是**たえ**的特征
❌ 混入りみ的怯懦       怯懦是**りみ**的特征
❌ 混入灯的诗性         诗性词汇是**灯**的
```

## TTS 特别注意

### 名字读音

| 表记 | 读音 | 风险 |
|---|---|---|
| 有咲 | ありさ | **高。容易被误读为「ゆうさき」等** |
| 市ヶ谷 | いちがや | **高。**「ヶ」的读音（が/け/ガ）不稳定 |

**两者都有很高的误读风险。** 已登录到 `../../dictionary/pronunciation.yaml`。

**「ヶ」的处理**：小写片假名「ヶ」
读作 `いちがや`。**TTS 有可能读成 `いちけや` `いちガや`。**
这个字除了她以外（仅市ヶ谷有咲）不出现，
但作为姓氏频繁出现，因此**是希望优先实测的项目**。

### 语气的强度

她的台词**短、语气强**。对 TTS 来说有利（不容易出现断句问题）。

**但是不要堆太多 `！`。** 她的怒气以
`はあ？` 那样的**低沉的无奈**为主，不是尖叫。

```text
❌ そんなわけないでしょう！！！！
✅ はあ？　そんなわけないでしょ。
```

### 傲娇的语调起伏

像「別に……」这样的**掩饰害羞**，在 TTS 中需要**语尾下降**。
在 `adapters/gpt-sovits.md` 的验证清单 C（标点停顿）中，
想确认 `……` 之后语尾是否下落。

## examples

### 例 1：对香澄的毒舌 —— 本角色的基本形态

```text
角色：市ヶ谷有咲
场景：香澄がまた無茶を言い出した
中文：  香澄，你又来了。真是的，拿你没办法。
AI：    香澄さん、またですか。本当にもう、仕方ないですね。
```

```text
✅ 香澄、またあんたかよ。……もう、しょうがないわね。
```

| 改动 | 层 | 理由 |
|---|---|---|
| 香澄さん → 香澄 | character | **直呼其名**。条目明言她只对香澄强硬 |
| またですか → またかよ | character + sentence_endings | `〜かよ` 是无奈的固定形式 |
| あんた 追加 | character | 只对香澄使用的粗鲁人称。**常体的证明** |
| 仕方ないですね → しょうがないわね | character | `〜わね` 含有逞强的语感。`です` 不自然 |

### 例 2：傲娇（掩饰害羞）

```text
角色：市ヶ谷有咲
场景：香澄が心配してくれた
中文：  什么啊，我才没有担心你呢。只是……有点在意而已。
AI：    何よ、別に心配なんてしてないわ。ただ……少し気になっただけよ。
```

```text
✅ な、何よ。別に心配とかじゃないんだからね。……ちょっと気になっただけ。
```

| 改动 | 层 | 理由 |
|---|---|---|
| な、何よ | character | 口吃。动摇先表现出来 |
| 〜じゃないわ → 〜じゃないんだからね | character | 傲娇的固定形式。**强烈的否定**是害羞的反面 |
| 加 `……` | tts + character | 真心话泄露前一刻的停顿 |

> **傲娇的核心是「否定过强」。**
> 不要让她轻易承认。但不**变得冷酷**（用 `……` 泄露真心话）。

### 例 3：室内派 + 没有体力

```text
角色：市ヶ谷有咲
场景：遠出に誘われる
中文：  我才不去那么远的地方。我就在家里待着。
AI：    そんな遠くには行きません。私は家にいます。
```

```text
✅ そんな遠く、行くわけないでしょ。うちにいるに決まってるじゃない。
```

| 改动 | 层 | 理由 |
|---|---|---|
| 行きません → 行くわけないでしょ | character | `〜わけない` 是她的强烈否定形式 |
| 家にいます → うちにいるに決まってる | character | `うち`（口语）/ `〜に決まってる` 断定 |
| 加「じゃない」 | character | 表示"理所当然"的语气 |

> 基于条目的「室内派」「基本一直不出门」。
> **但不必每次都写出「体力差」**（避免刻板模仿）。
