## speech_style

### 语体

**常体 + 「〜ちゃん」称呼。** 对同辈、后辈一律常体。

- 对前辈用 `〜先輩` 称呼 + 常体（条目没有显示她用です・ます）
- **但她是胆小怯懦的性格**，所以措辞偏**柔和、犹豫、请求式**
- 条目原文：「性格比较**胆小怯懦**，一紧张就容易说出方言，比较**认生**」

**关键区分**：讲话柔和 ≠ 用敬体。
她的柔和体现在**语气的迟疑与请求形**，不是です・ます。

### 関西弁——本角色最重要的语言特征

条目原文：「**关西人**，性格比较胆小怯懦，**一紧张就容易说出方言**」。

→ **紧张时会冒出关西腔。** 这是**条件触发**，不是全程方言：

| 状态 | 语言 |
|---|---|
| 平常 | 标准语（不出现关西腔） |
| 紧张・焦躁・慌张 | **会混入关西腔** |

```text
（平常） あ、あの……ちょっといいかな？
（緊張） あ、あの……ちょっとええかな？　
```

**⚠️ 这是一个高风险规则**，因为：
1. 条目只说"一紧张就容易说"，**没有给出具体词汇表**
2. 关西腔的写法差异很大（大阪腔/京都腔等），**她的具体方言未确证**
3. 写错方言比不写方言更糟

→ **处理方式**：在需要关西腔的场面之前，**先在 `【待确认】` 里问**
具体用哪一种、用到什么程度。**不要自己编关西腔**（G8）。

### sentence_endings

| 句尾 | 语感 | 用例 |
|---|---|---|
| `〜かな` / `〜かな？` | 犹豫、自问 | `これでいいのかな` |
| `〜けど` | 句尾不结、留白 | `私、弾けるかな……けど` |
| `〜の` / `〜の？` | 柔和的疑问 | `そうなの？` |
| `〜だよね` | 确认（弱） | `大丈夫だよね` |
| `〜てほしい` | 请求 | `一緒に来てほしいな` |
| `……` | **高频**。说不出话 | `あ、あの……` |

**禁用/低频句尾**：

- `〜ですわ` / `〜ますわ`（完全不符）
- `〜じゃん` `〜っしょ`（爱音的词汇。りみ不用）
- `〜だぜ` `〜だぞ`（男性化的）
- 过强的断定形（`〜だ！` 之类。她回避断定）

### vocabulary

**高频（条目可确证）**：

```text
チョココロネ        最喜欢的食物。核心
ゲーム / 読書        兴趣
写真                专长（记录乐队日常）
お姉ちゃん          姐姐（牛込ゆり）
こわい               恐惧（但喜欢恐怖电影）
```

**「巧克力螺」的特殊地位**

条目原文：「山吹面包房的常客，**最喜欢的东西是巧克力螺**。
**生活就是巧克力螺**，吃巧克力螺时就像兔子在吃胡萝卜（多惠语），
自己还写了一首歌《我的心是巧克力螺》」。

→ **巧克力螺是她的标志物**，可以自然地出现在台词里。
但和「キラキラドキドキ」一样——**不要每段都塞**。

**反差设定：喜欢恐怖电影**

条目原文：「**喜欢看恐怖电影**，因此和广町七深关系很好」。

→ **注意与香澄的对比**：香澄**极度怕鬼**，りみ**喜欢恐怖电影**。
两人一起看恐怖片时，**怕的是香澄，不是りみ**。
把恐惧反应写反是很容易犯的错。

### interjections

```text
あ、あの……      说不出话时的固定套路
えっ           轻微的惊讶
あっ           发现
うーん          烦恼
ひゃっ          对突发状况的惊讶
```

**注意**：她的感叹词常**带有前置的「あ、」**（どもり）。
这是她怯懦性格在语言上的直接体现。

### emotional_style

**核心：胆小、认生、想改变但难以行动。**

条目原文：「因为担心自己水平不足出错会添麻烦，所以**最初一直拒绝香澄的邀请**，
会**藏在窗帘中假装自己不在**，还会**摇头摇晕自己**」。

| 情绪 | りみ的表达方式 |
|---|---|
| 兴奋 | **克制**。`すごい……`。不放大音量 |
| 惊讶 | `えっ` / `ひゃっ`。会结巴 |
| 害羞 | **沉默 or 结巴**。`あ、あの……` |
| 悲伤 | 声音变小。`……うん` |
| 生气 | **几乎没有**。不满顶多是 `……そうなんだ` 的程度 |
| 疑问 | `〜の？` / `〜かな？`（弱） |
| 犹豫 | **本角色的中心**。`うーん……` `どうしよう` |
| 恐惧（电影） | **不在意**。这一点与香澄相反 |

**关键区分 1：成长轴**

条目原文：「**虽然想改变自己的胆小怯懦与毫无主见，但还是不能好好行动**」。

→ 她**不是安于内向**，而是**想改却改不了**。
写成"安安静静就很满足"是错的——她内心有焦躁。

**关键区分 2：舞台上的反差**

条目记载她的转折点：LIVE 中姐姐因台风无法到场，
**她迈出一步，上台演奏了贝斯**。

→ 她在**关键时刻会跨出去**。这不是矛盾，是角色弧。
在台词设计上：日常怯懦，**关键场面会有一句鼓起勇气的话**（短、直、不修饰）。

**关键区分 3：姐姐**

条目原文：「姐姐牛込百合是 **Glitter☆Green 乐队的主唱**，
使用的粉色 ESP 贝斯也是她送的」。

→ 姐姐是她的**目标与自卑源**。提到姐姐时会**又骄傲又不安**。

## preferred

```text
迷い     → うーん…… / どうしよう / 〜かな
詰まる   → あ、あの……
同意     → うん…… / そうだね（弱く）
請求     → 〜てほしいな / 〜てもいい？
勇気     → （短い断定。日常との対比で使う）
チョココロネ → 自然に言及可（ただし乱用しない）
```

**句式倾向**：

- 短 + 中断 > 长
- 回避断定 > 断定
- **以「あ、」开头**的情况很多
- 只在关键时刻**短促地说到底**（这个落差就是职责）

## avoid

```text
❌ 関西弁の創作      她方言的具体形态未确证。不要擅自写（G8）
❌ 全程標準語で無個性 丢掉结巴和「あ、」就会变成另一个人

❌ 安住した内向      「想改变却改变不了」才是核心

❌ 愛音の語彙        `じゃん` `っしょ`
❌ チョココロネ乱用   会变成刻板模仿
```

## TTS 特别注意

### 名字读音

| 表记 | 读音 | 风险 |
|---|---|---|
| りみ | りみ | **低。因为是假名表记所以不会误读** |
| 牛込 | うしごめ | **高。容易被误读为「ぎゅうこみ」等** |

**注意**：本人的名字是假名（りみ），但**姓氏「牛込」是汉字**。
在 `牛込さん`（友希那・紗夜・燐子・麻弥使用）的场面存在误读风险。
已登记在 `../../dictionary/pronunciation.yaml`。

### どもり与「あ、」的处理

她的台词里有很多 `あ、あの……` `や、やめて` 这样的**结巴**。

在 TTS 层面要注意：
- **不加入「、」就无法再现结巴**，但另一方面，
  像 `あ、あの` 这样**多用短促的「、」会让停顿不自然地拖长**
- 有些引擎会把 `あ、` 读成完全的停顿

→ 在 `adapters/gpt-sovits.md` 的验证清单 C（标点停顿）中是**想优先确认的项目**。
因为结巴・间隔是她角色性的中心，
**这项验证的结果会左右台词设计**。

### 关西腔与TTS

如果要写关西腔，**音高重音与标准语不同**。
由于 GPT-SoVITS 依赖参考音声的说话者特性，
**用标准语的参考音声去读关西腔文本可能会变得不自然**。

→ 在使用关西腔之前，确认 `adapters/gpt-sovits.md` 的 D 类（参考音频影响）。
**未検証のまま関西弁を積極採用しない。**

## examples

### 例 1：怯懦与请求

```text
角色：牛込りみ
场景：練習に誘う
中文：  那个……我也想试着弹一下，可以吗？
AI：    あの、私も弾いてみたいのですが、よろしいでしょうか。
```

```text
✅ あ、あの……わたしも、弾いてみたいな……いいかな？
```

| 改动 | 层 | 理由 |
|---|---|---|
| あの → **あ、あの** | character | どもり。「あ、」が彼女の定型 |
| 〜のですが → 〜な | character | 常体。ただし**断定しない** |
| よろしいでしょうか → いいかな？ | character | 敬体は不自然。`〜かな` で**許可を伺う** |
| 加 `……` 二箇所 | character + tts | 言葉に詰まる間。彼女の核 |

### 例 2：恐怖电影 —— 香澄と逆

```text
角色：牛込りみ
场景：七深とホラー映画の話
中文：  那个恐怖电影，我觉得挺有意思的。
AI：    あのホラー映画は、正直ちょっと怖かったです。
```

```text
✅ あのホラー映画ね、けっこう面白かったよ。七深ちゃんも好きだし。
```

| 改动 | 层 | 理由 |
|---|---|---|
| 怖かったです → 面白かった | character | **りみはホラーが好き**。恐怖反応は誤り |
| 正直 → 削除 | character | 彼女は「正直」のような前置きを使わない |
| 加「七深ちゃんも好きだし」 | character | 条目記載の交友関係（ホラー仲間）を反映 |

> **これは重要な検査項目。** 香澄とりみを同時に登場させるホラー場面では、
> **怖がるのは香澄**。取り違えると両方のキャラが壊れる。

### 例 3：成長軸 —— 短く言い切る

```text
角色：牛込りみ
场景：LIVE前、勇気を出す
中文：  我……我要弹。我要站上这个舞台。
AI：    わ、私は……弾きます。このステージに立ちます。
```

```text
✅ ……弾く。わたし、このステージに立つ。
```

| 改动 | 层 | 理由 |
|---|---|---|
| 弾きます → 弾く | character + sentence_ending | **ここぞという場面では常体で言い切る** |
| わ、私は → わたし | character | どもりを**一回だけ**残し、その後は言い切る |
| 加 `……` の後に断定 | character | **迷い → 決断** の落差が役割 |

> 日常のどもりと、この場面の言い切りの**落差**が本角色の見せ場。
