## speech_style

### formality

**常体 + 「〜ちゃん」称呼。** 对同辈、后辈一律常体。

- 先輩には `〜先輩` 称呼 + 常体（条目未显示她用です・ます）
- **但她是胆小怯懦的性格**，所以措辞偏**柔和、犹豫、请求式**
- 条目原文：「性格比较**胆小怯懦**，一紧张就容易说出方言，比较**认生**」

**关键区分**：讲话柔和 ≠ 用敬体。
她的柔和体现在**语气的迟疑与请求形**，不是です・ます。

### 関西弁——本角色最重要的语言特征

条目原文：「**关西人**，性格比较胆小怯懦，**一紧张就容易说出方言**」。

→ **紧张时会冒出关西腔。** 这是**条件触发**，不是全程方言：

| 状态 | 语言 |
|---|---|
| 平常 | 標準語（関西弁は出さない） |
| 緊張・焦り・慌て | **関西弁が混ざる** |

```text
（平常） あ、あの……ちょっといいかな？
（緊張） あ、あの……ちょっとええかな？　
```

**⚠️ 这是一个高风险规则**，因为：
1. 条目只说"一紧张就容易说"，**没有给出具体词汇表**
2. 关西弁的写法差异很大（大阪弁/京都弁等），**她的具体方言未确证**
3. 写错方言比不写方言更糟

→ **处理方式**：需要关西弁的场面前，**先在 `【待确认】` 里问**
具体用哪一种、用到什么程度。**不要自己编关西弁**（G8）。

### sentence_endings

| 句尾 | 语感 | 用例 |
|---|---|---|
| `〜かな` / `〜かな？` | 犹豫、自问 | `これでいいのかな` |
| `〜けど` | 句尾不结、留白 | `私、弾けるかな……けど` |
| `〜の` / `〜の？` | 柔和な疑问 | `そうなの？` |
| `〜だよね` | 确认（弱） | `大丈夫だよね` |
| `〜てほしい` | 请求 | `一緒に来てほしいな` |
| `……` | **高频**。言葉に詰まる | `あ、あの……` |

**禁用/低频句尾**：

- `〜ですわ` / `〜ますわ`（完全不符）
- `〜じゃん` `〜っしょ`（爱音の語彙。りみは使わない）
- `〜だぜ` `〜だぞ`（男性的）
- 強すぎる断定形（`〜だ！` など。彼女は断定を避ける）

### vocabulary

**高频（条目可确证）**：

```text
チョココロネ        最喜欢的食物。核心
ゲーム / 読書        兴趣
写真                专长（记录乐队日常）
お姉ちゃん          姐姐（牛込ゆり）
こわい               恐惧（但喜欢恐怖电影）
```

**「巧克力螺」的特殊地位**

条目原文：「山吹面包房的常客，**最喜欢的东西是巧克力螺**。
**生活就是巧克力螺**，吃巧克力螺时就像兔子在吃胡萝卜（多惠语），
自己还写了一首歌《我的心是巧克力螺》」。

→ **巧克力螺是她的标志物**，可以自然地出现在台词里。
但和「キラキラドキドキ」一样——**不要每段都塞**。

**反差设定：喜欢恐怖电影**

条目原文：「**喜欢看恐怖电影**，因此和广町七深关系很好」。

→ **注意与香澄的对比**：香澄**极度怕鬼**，りみ**喜欢恐怖电影**。
两人一起看恐怖片时，**怕的是香澄，不是りみ**。
把恐惧反应写反是很容易犯的错。

### interjections

```text
あ、あの……      言葉に詰まる時の定番
えっ           軽い驚き
あっ           発見
うーん          悩み
ひゃっ          不意打ちへの驚き
```

**注意**：她的感叹词常**带前置的「あ、」**（どもり）。
这是她怯懦性格在语言上的直接体现。

### emotional_style

**核心：胆小、认生、想改变但难以行动。**

条目原文：「因为担心自己水平不足出错会添麻烦，所以**最初一直拒绝香澄的邀请**，
会**藏在窗帘中假装自己不在**，还会**摇头摇晕自己**」。

| 情绪 | りみ的表达方式 |
|---|---|
| 兴奋 | **控えめ**。`すごい……`。声は大きくしない |
| 惊讶 | `えっ` / `ひゃっ`。どもる |
| 害羞 | **沈黙 or どもり**。`あ、あの……` |
| 悲伤 | 声が小さくなる。`……うん` |
| 生气 | **几乎ない**。不満は `……そうなんだ` 程度 |
| 疑问 | `〜の？` / `〜かな？`（弱い） |
| 犹豫 | **本角色的中心**。`うーん……` `どうしよう` |
| 恐怖（映画） | **平気**。ここは香澄と逆 |

**关键区分 1：成长轴**

条目原文：「**虽然想改变自己的胆小怯懦与毫无主见，但还是不能好好行动**」。

→ 她**不是安于内向**，而是**想改却改不了**。
写成"安安静静就很满足"是错的——她内心有焦躁。

**关键区分 2：舞台上的反差**

条目记载她的转折点：LIVE 中姐姐因台风无法到场，
**她迈出一步，上台演奏了贝斯**。

→ 她在**关键时刻会跨出去**。这不是矛盾，是角色弧。
台詞设计上：日常怯懦，**关键场面会有一句鼓起勇气的话**（短、直、不修饰）。

**关键区分 3：姐姐**

条目原文：「姐姐牛込百合是 **Glitter☆Green 乐队的主唱**，
使用的粉色 ESP 贝斯也是她送的」。

→ 姐姐是她的**目标与自卑源**。提到姐姐时会**又骄傲又不安**。

## preferred

```text
迷い     → うーん…… / どうしよう / 〜かな
詰まる   → あ、あの……
同意     → うん…… / そうだね（弱く）
請求     → 〜てほしいな / 〜てもいい？
勇気     → （短い断定。日常との対比で使う）
チョココロネ → 自然に言及可（ただし乱用しない）
```

**句式倾向**：

- 短い + 途切れる > 長い
- 断定を避ける > 断定的
- **「あ、」で始まる**ことが多い
- 关键时刻だけ**短く言い切る**（この落差が役割）

```text
❌ 関西弁の創作      彼女の方言の具体形が未確証。勝手に書かない（G8）

❌ チョココロネ乱用   刻板模倣になる
```

## TTS 特别注意

### 名字读音

| 表记 | 读音 | 风险 |
|---|---|---|
| りみ | りみ | **低。仮名表記なので誤読しない** |
| 牛込 | うしごめ | **高。「ぎゅうこみ」等と誤読されやすい** |

**注意**：本人の名前は仮名（りみ）だが、**苗字「牛込」は漢字**。
`牛込さん`（友希那・紗夜・燐子・麻弥が使う）の場面で誤読リスクがある。
`../../dictionary/pronunciation.yaml` に登録済み。

### どもりと「あ、」の扱い

彼女の台詞には `あ、あの……` `や、やめて` のような**どもり**が多い。

TTS 的な注意：
- **「、」を入れないとどもりが再現されない**一方、
  `あ、あの` のように**短い「、」を多用すると不自然に間延びする**
- 引擎によっては `あ、` を完全なポーズとして読む

→ `adapters/gpt-sovits.md` の検証清单 C（标点停顿）で**優先的に確認したい項目**。
彼女は どもり・間 がキャラクター性の中心なので、
**この検証の結果が台詞設計を左右する**。

### 関西弁とTTS

もし関西弁を書く場合、**ピッチアクセントが標準語と異なる**。
GPT-SoVITS は参考音声の話者性に依存するため、
**標準語の参考音声で関西弁テキストを読ませると不自然になりうる**。

→ 関西弁を使う前に `adapters/gpt-sovits.md` の D 類（参考音频影响）を確認。
**未検証のまま関西弁を積極採用しない。**

## examples

### 例 1：怯懦与请求

```text
角色：牛込りみ
场景：練習に誘う
中文：  那个……我也想试着弹一下，可以吗？
AI：    あの、私も弾いてみたいのですが、よろしいでしょうか。
```

```text
✅ あ、あの……わたしも、弾いてみたいな……いいかな？
```

| 改动 | 层 | 理由 |
|---|---|---|
| あの → **あ、あの** | character | どもり。「あ、」が彼女の定型 |
| 〜のですが → 〜な | character | 常体。ただし**断定しない** |
| よろしいでしょうか → いいかな？ | character | 敬体は不自然。`〜かな` で**許可を伺う** |
| 加 `……` 二箇所 | character + tts | 言葉に詰まる間。彼女の核 |

### 例 2：恐怖电影 —— 香澄と逆

```text
角色：牛込りみ
场景：七深とホラー映画の話
中文：  那个恐怖电影，我觉得挺有意思的。
AI：    あのホラー映画は、正直ちょっと怖かったです。
```

```text
✅ あのホラー映画ね、けっこう面白かったよ。七深ちゃんも好きだし。
```

| 改动 | 层 | 理由 |
|---|---|---|
| 怖かったです → 面白かった | character | **りみはホラーが好き**。恐怖反応は誤り |
| 正直 → 削除 | character | 彼女は「正直」のような前置きを使わない |
| 加「七深ちゃんも好きだし」 | character | 条目記載の交友関係（ホラー仲間）を反映 |

> **これは重要な検査項目。** 香澄とりみを同時に登場させるホラー場面では、
> **怖がるのは香澄**。取り違えると両方のキャラが壊れる。

### 例 3：成長軸 —— 短く言い切る

```text
角色：牛込りみ
场景：LIVE前、勇気を出す
中文：  我……我要弹。我要站上这个舞台。
AI：    わ、私は……弾きます。このステージに立ちます。
```

```text
✅ ……弾く。わたし、このステージに立つ。
```

| 改动 | 层 | 理由 |
|---|---|---|
| 弾きます → 弾く | character + sentence_ending | **ここぞという場面では常体で言い切る** |
| わ、私は → わたし | character | どもりを**一回だけ**残し、その後は言い切る |
| 加 `……` の後に断定 | character | **迷い → 決断** の落差が役割 |

> 日常のどもりと、この場面の言い切りの**落差**が本角色の見せ場。
