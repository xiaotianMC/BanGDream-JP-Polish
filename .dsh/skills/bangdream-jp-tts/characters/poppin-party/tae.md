## speech_style

### 定位：这是一个「说慢、说少、但每句都有分量」的角色

条目原文对她的评语：

> 「大多数人初见外表以为会是正经的冰山美人 or 温柔知性沉稳的大姐姐，
> 见识了之后才发现是个**思维异于常人、脑回路很清奇的天然**。
> 但其论本质来说毋庸置疑确实是个很温柔知性的大姐姐，
> **从来没有向任何人发过脾气也不和任何人闹别扭**，也总是表现的很安静，
> 是个**情绪非常稳定**的人，温柔又情感独立，**总是知道该要为他人怎么做，
> 总是准确洞察问题本质**」

→ 两个特质必须**同时**成立：**天然（脱线）+ 知性（洞察）**。
只写"天然呆"会变成傻子，只写"知性"会变成说教角色。**两者都要写**。

### 语体

**仅用常体。** 对谁都使用常体（条目没有显示她用です・ます）。

- 对前辈也用常体 + `〜先輩` 称呼
- 但**对前辈很有礼貌**（条目原文：「对待前辈都很有礼貌」）——
  礼貌靠**称呼与措辞**体现，不靠敬体

### sentence_endings

**说话方式独特**（其他 PPP 成员的条目也注明「たえの口調は独特」）。
但条目没有给出语尾清单，因此**此处只写可确证的部分**：

| 句尾 | 用例 |
|---|---|
| `〜ね` | 共感・确认。`そうだね` |
| `〜よ` | 告知。`おいしいよ` |
| `〜かな` | 自问・提议 |
| `〜でしょ` | 轻度确认 |
| `〜んだ` | 发现・说明 |

> **未确证的部分**：她具体的口癖（是否有独特的语尾、是否有
> 独特的节奏）条目没有系统整理。**不要凭印象补**（G8）。
> 需要在真实台词语料中确认后回填。

### vocabulary

**高频（条目可确证）**：

```text
うさぎ / ラビット   兔子。核心中的核心
おいしい           她对食物的兴趣极高
ギター             音乐
ブルー / 青い       最喜欢的颜色
お風呂             兴趣（泡澡）
ランニング         兴趣（跑步）
```

**食物相关的表现特别丰富**：条目原文说她
「喜欢的食物是汉堡肉（**无比的肉食爱好者**）、年糕红豆粥、
**能吃的都喜欢**，讨厌的食物**好像是没有**」。

→ **"什么都吃"本身是角色特征。** 她对食物的反应是少数会显露情绪的地方。

### interjections

她的感叹词**少**。条目说「总是表现的很安静」。

```text
あ           轻微的发现
ああ         领会
うん         肯定
（無言）      在观察
```

**不要给她加多感叹词。** 她不是安静地没有情绪，而是**情绪不靠声音表达**。

### emotional_style

**核心：情绪极稳定，几乎不波动。温柔但独立。**

条目原文：「情绪非常稳定」「从来没有向任何人发过脾气也不和任何人闹别扭」。

| 情绪 | たえ的表达方式 |
|---|---|
| 兴奋 | **几乎不外露**。`いいね` `おいしい`。不提高音量 |
| 惊讶 | `あ` / `へえ`。很短 |
| 害羞 | 这个概念很淡薄。因为**她会坦然说出口**，所以是周围的人害羞 |
| 悲伤 | **不表现**。不过**作为氛围会变安静** |
| 生气 | **条目明言「没有向任何人发过脾气」** → **不要让她生气** |
| 疑问 | `どうして？` / `なんで？`。直率地询问 |
| 犹豫 | `うーん` / `……そうだね` |
| 洞察 | **用毫无修饰的平叙直奔核心**。这是最大的特征（见下） |

**关键区分 1：天然与知性同时出现**

条目原文：「总是**准确洞察问题本质**」「总是会讲出**非常有道理又让人共鸣的话**」。

→ 她的脱线发言**往往正是正解**。写法上：

```text
❌ ただの頓珍漢な発言（＝天然だけ）
✅ 一見ズレた言い方だが、内容は本質を突いている
```

**关键区分 2：不透支「不生气」设定**

条目明言她从不发脾气。**不要为了戏剧效果让她生气**。
她表达不赞同的方式是**安静地说出事实**，而不是发怒。

**关键区分 3：对朋友的看法要说出来**

条目引用了她的原话（很有代表性）：

```text
「对我来说，Popipa 的大家都很重要。都是陪在我身边的、我最喜欢的朋友」
「乐队真的很厉害呢。组乐队后，我也交到了许多朋友」
「有 Popipa 和大家在，真的是太好了，香澄、沙绫、里美和有咲，我都非常喜欢。
  我们五个人在一起才是 Popipa 呢」
```

→ **她会直接把这种话说出口**，而且说得**平淡**——
不羞涩、不煽情。这种"平淡地说出重话"是本角色的标志。

## preferred

```text
共感     → 〜ね / いいね
食事     → おいしい / （無言で食べる）
音楽     → ギター / いい音
核心をつく → 素の平叙で短く
友情     → 平然と「大好き」「大事」と言う
```

**句式倾向**：

- 短小的平叙 > 冗长的说明
- 平坦的语调 > 抑扬
- 具体的观察 > 抽象论
- 不惧怕**间隔**（不去填补沉默）

## TTS 特别注意

### 名字读音

| 表记 | 读音 | 风险 |
|---|---|---|
| たえ | たえ | **低。因为是假名表记所以不会误读** |
| 花園 | はなぞの | 中。不是「その」而是「ぞの」 |

**利点**：名字是**假名**，所以没有 `燈` 或 `愛音` 那样的误读风险。
称呼表里也写作 `たえ` `おたえ` 这样的假名，因此在 TTS 层面是安全的。

### 语调平坦。这正是特征

她的台词**抑扬很小**。在 TTS 层面：

- 多用 `！` **不适合**。她不喊叫
- 用 `。` 沉稳收尾的句子很多
- `……` 可以当作**沉默**使用（与灯含义不同。灯是「说不出口」，たえ是「没有必要说」）

→ **在 `adapters/gpt-sovits.md` 的验证清单 C（标点停顿）** 中，
这是想确认 `。` 与 `！` 的差异能否充分体现的角色。

### 断句

**她的台词本来就短，通常不需要切。** 但注意：

- 她**会说较长的、有道理的话**（条目里的引用就是长句）。
- 那种场面**不要为了 TTS 切碎**——她的话语有完整性，
  条目的引用显示她说话时是**连贯**的。

```text
❌ 五个人、在一起、才是、Popipa
✅ 私たち五人でいてこその、Popipa なんだよ
```

## examples

### 例 1：平淡地说出重话 —— 本角色的标志

```text
角色：花園たえ
场景：乐队的话题
中文：  有 Popipa 和你们在，真的太好了。我很喜欢大家。
AI：    ポピパのみんながいてくれて、本当に良かったです。みんなのことが大好きです。
```

```text
✅ ポピパがいてくれて、ほんと良かった。みんなのこと、大好きだよ。
```

| 改动 | 层 | 理由 |
|---|---|---|
| 〜です → 〜だよ | character + sentence_ending | 常体。她不使用敬体 |
| 本当に → ほんと | character | 口语形。不过**与香澄的「ほんっとに」不同**（不加促音） |
| 大好きです → 大好きだよ | character | **坦然地说**。既不害羞也不夸张 |
| 「ポピパ」表记 | character | 她有把乐队名用简称来称呼的场面（需确认） |

> **重要**：**不要**让这句台词**带害羞感**。她会坦率、平淡地说。
> 构图是周围（尤其是有咲）害羞。

### 例 2：天然 + 洞察 —— 看似脱线却直击本质

```text
角色：花園たえ
场景：有咲在烦恼
中文：  有咲，你想太多了吧。你喜欢香澄不就好了吗？
AI：    有咲さん、考えすぎだと思いますよ。香澄が好きならそれでいいじゃないですか。
```

```text
✅ 有咲、考えすぎだよ。香澄のこと好きなんでしょ？　それでいいんだよ。
```

| 改动 | 层 | 理由 |
|---|---|---|
| 有咲さん → 有咲 | character | **直呼其名** |
| 〜だと思いますよ → 〜だよ | character | 常体。也不委婉。**直接断言** |
| 〜じゃないですか → 〜でしょ？ | character | 确认形。直击核心 |
| 加「それでいいんだよ」 | character | **用平叙摆出结论**。这就是知性的表现方式 |

> **这就是「天然 + 知性」的写法。** 内容是正论，
> 说法并不脱线，但**没有铺垫**（所以周围会惊讶）。

### 例 3：兔子 —— 应该注意不过度

```text
角色：花園たえ
场景：日常会话
中文：  我家兔子的小欧今天也很可爱。
AI：    うちのうさぎの小欧は今日もかわいいです。
```

```text
✅ うちの小欧ね、今日もかわいかったよ。
```

| 改动 | 层 | 理由 |
|---|---|---|
| 〜です → 〜だよ | character | 常体 |
| 加「ね」 | character | **间隔的处理方式**。她平坦的讲述 |
| 省略「うさぎの」 | character | 在语境中自明。她不做说明 |

> **注意**：不要**多用**兔子梗。条目显示它是重要设定，
> 但每句台词都拿出来就是刻板模仿（`rules/global.md` G2 的精神）。
