## speech_style

### 定位：这是一个「说慢、说少、但每句都有分量」的角色

条目原文对她的评语：

> 「大多数人初见外表以为会是正经的冰山美人 or 温柔知性沉稳的大姐姐，
> 见识了之后才发现是个**思维异于常人、脑回路很清奇的天然**。
> 但其论本质来说毋庸置疑确实是个很温柔知性的大姐姐，
> **从来没有向任何人发过脾气也不和任何人闹别扭**，也总是表现的很安静，
> 是个**情绪非常稳定**的人，温柔又情感独立，**总是知道该要为他人怎么做，
> 总是准确洞察问题本质**」

→ 两个特质必须**同时**成立：**天然（脱线）+ 知性（洞察）**。
只写"天然呆"会变成傻子，只写"知性"会变成说教角色。**两者都写**。

### formality

**常体のみ。** 对谁都用常体（条目未显示她用です・ます）。

- 先輩にも常体 + `〜先輩` 称呼
- 但**对前辈很有礼貌**（条目原文：「对待前辈都很有礼貌」）——
  礼貌靠**称呼与措辞**体现，不靠敬体

### sentence_endings

**说话方式独特**（其他 PPP 成员的条目也注明「たえの口調は独特」）。
但条目未给出语尾清单，因此**此处只写可确证的部分**：

| 句尾 | 用例 |
|---|---|
| `〜ね` | 共感・確認。`そうだね` |
| `〜よ` | 告知。`おいしいよ` |
| `〜かな` | 自問・提案 |
| `〜でしょ` | 軽い確認 |
| `〜んだ` | 発見・説明 |

> **未确证的部分**：她的具体口癖（是否有独特的语尾、是否有
> 独特的节奏）条目没有系统整理。**不要凭印象补**（G8）。
> 需要在真实台词语料中确认后回填。

### vocabulary

**高频（条目可确证）**：

```text
うさぎ / ラビット   兔子。核心中的核心
おいしい           她对食物兴趣极高
ギター             音乐
ブルー / 青い       最喜欢的颜色
お風呂             兴趣（泡澡）
ランニング         兴趣（跑步）
```

**食物相关的表现特别丰富**：条目原文说她
「喜欢的食物是汉堡肉（**无比的肉食爱好者**）、年糕红豆粥、
**能吃的都喜欢**，讨厌的食物**好像是没有**」。

→ **"什么都吃"本身是角色特征。** 她对食物的反应是少数会显露情绪的地方。

### interjections

她的感叹词**少**。条目说「总是表现的很安静」。

```text
あ           轻い発見
ああ         納得
うん         肯定
（無言）      観察している
```

**不要给她加多感叹词。** 她不是安静地没情绪，而是**情绪不靠声音表达**。

### emotional_style

**核心：情绪极稳定，几乎不波动。温柔但独立。**

条目原文：「情绪非常稳定」「从来没有向任何人发过脾气也不和任何人闹别扭」。

| 情绪 | たえ的表达方式 |
|---|---|
| 兴奋 | **几乎不外露**。`いいね` `おいしい`。声は上げない |
| 惊讶 | `あ` / `へえ`。短い |
| 害羞 | 概念が薄い。**平然と言ってのける**ので、周囲が照れる |
| 悲伤 | **不表现**。ただし**空気として静かになる** |
| 生气 | **条目明言「没有向任何人发过脾气」** → **怒らせない** |
| 疑问 | `どうして？` / `なんで？`。素直に聞く |
| 犹豫 | `うーん` / `……そうだね` |
| 洞察 | **素の平叙で核心を突く**。これが最大の特徴（下記） |

**关键区分 1：天然与知性同时出现**

条目原文：「总是**准确洞察问题本质**」「总是会讲出**非常有道理又让人共鸣的话**」。

→ 她的脱线发言**往往正是正解**。写法上：

```text
❌ ただの頓珍漢な発言（＝天然だけ）
✅ 一見ズレた言い方だが、内容は本質を突いている
```

**关键区分 2：不透支「不生气」设定**

条目明言她从不发脾气。**不要为了戏剧效果让她生气**。
她表达不赞同的方式是**安静地说出事实**，而不是发怒。

**关键区分 3：对朋友的看法要说出来**

条目引用了她的原话（很有代表性）：

```text
「对我来说，Popipa 的大家都很重要。都是陪在我身边的、我最喜欢的朋友」
「乐队真的很厉害呢。组乐队后，我也交到了许多朋友」
「有 Popipa 和大家在，真的是太好了，香澄、沙绫、里美和有咲，我都非常喜欢。
  我们五个人在一起才是 Popipa 呢」
```

→ **她会直接把这种话说出口**，而且说得**平淡**——
不羞涩、不煽情。这种"平淡地说出重话"是本角色的标志。

## preferred

```text
共感     → 〜ね / いいね
食事     → おいしい / （無言で食べる）
音楽     → ギター / いい音
核心をつく → 素の平叙で短く
友情     → 平然と「大好き」「大事」と言う
```

**句式倾向**：

- 短い平叙 > 長い説明
- 平坦な語調 > 抑揚
- 具体的な観察 > 抽象論
- **間**を恐れない（沈黙を埋めない）

## avoid

```text
❌ ただの天然呆      洞察を落とすと別人になる
❌ 怒らせる          条目明言「从不发脾气」
❌ 多弁              彼女は静か。台詞量そのものが表現
❌ 過度な敬体        先輩にも常体（礼儀は称呼と措辞で示す）
❌ 感嘆詞を増やす    `わーい` `やったー` は使わない
❌ 恥じらい          友情を語る時も平然と

❌ 兔子ネタの乱用    好きだが、全台詞に出すのは刻板模倣
```

## TTS 特别注意

### 名字读音

| 表记 | 读音 | 风险 |
|---|---|---|
| たえ | たえ | **低。仮名表記なので誤読しない** |
| 花園 | はなぞの | 中。「その」ではなく「ぞの」 |

**利点**：名前が**假名**なので、`燈` や `愛音` のような誤読リスクがない。
称呼表でも `たえ` `おたえ` と仮名で書かれるため、TTS 的に安全。

### 語調は平坦。それが特徴

彼女の台詞は**抑揚が小さい**。TTS 的には：

- `！` の多用が**似合わない**。彼女は叫ばない
- `。` で落ち着いて終わる文が多い
- `……` は**沈黙**として使える（灯とは意味が違う。灯は「言えない」、たえは「言う必要がない」）

→ **`adapters/gpt-sovits.md` の検証清单 C（标点停顿）** で、
`。` と `！` の差が十分に出るか確認したいキャラクター。

### 断句

**她的台词本来就短，通常不需要切。** 但注意：

- 她**会说较长的、有道理的话**（条目里的引用就是长句）。
- 那种场面**不要为了 TTS 切碎**——她的话语有完整性，
  条目的引用显示她说话时是**连贯**的。

```text
❌ 五个人、在一起、才是、Popipa
✅ 私たち五人でいてこその、Popipa なんだよ
```

## examples

### 例 1：平淡地说出重话 —— 本角色的标志

```text
角色：花園たえ
场景：バンドの話
中文：  有 Popipa 和你们在，真的太好了。我很喜欢大家。
AI：    ポピパのみんながいてくれて、本当に良かったです。みんなのことが大好きです。
```

```text
✅ ポピパがいてくれて、ほんと良かった。みんなのこと、大好きだよ。
```

| 改动 | 层 | 理由 |
|---|---|---|
| 〜です → 〜だよ | character + sentence_ending | 常体。彼女は敬体を使わない |
| 本当に → ほんと | character | 口语形。ただし**香澄の「ほんっとに」とは違う**（促音を入れない） |
| 大好きです → 大好きだよ | character | **平然と言う**。照れも誇張もない |
| 「ポピパ」表記 | character | 彼女はバンド名を略称で呼ぶ場面がある（要確認） |

> **重要**：この台詞を**照れさせない**。彼女は素直に、平坦に言う。
> 周囲（特に有咲）が照れるのが構図。

### 例 2：天然 + 洞察 —— 一見ズレて本質を突く

```text
角色：花園たえ
场景：有咲が悩んでいる
中文：  有咲，你想太多了吧。你喜欢香澄不就好了吗？
AI：    有咲さん、考えすぎだと思いますよ。香澄が好きならそれでいいじゃないですか。
```

```text
✅ 有咲、考えすぎだよ。香澄のこと好きなんでしょ？　それでいいんだよ。
```

| 改动 | 层 | 理由 |
|---|---|---|
| 有咲さん → 有咲 | character | **呼び捨て** |
| 〜だと思いますよ → 〜だよ | character | 常体。婉曲もしない。**断言する** |
| 〜じゃないですか → 〜でしょ？ | character | 確認形。核心を突く |
| 加「それでいいんだよ」 | character | **結論を平叙で置く**。これが知性の出し方 |

> **これが「天然 + 知性」の書き方。** 内容は正論、
> 言い方はズレていないが**前置きがない**（だから周囲が驚く）。

### 例 3：兔子 —— 应该注意不过度

```text
角色：花園たえ
场景：日常会話
中文：  我家兔子的小欧今天也很可爱。
AI：    うちのうさぎの小欧は今日もかわいいです。
```

```text
✅ うちの小欧ね、今日もかわいかったよ。
```

| 改动 | 层 | 理由 |
|---|---|---|
| 〜です → 〜だよ | character | 常体 |
| 加「ね」 | character | **間の取り方**。彼女の平坦な語り |
| 「うさぎの」省略 | character | 文脈上自明。彼女は説明しない |

> **注意**：兔子ネタは**多用しない**。条目显示它是重要设定，
> 但全台詞に出すのは刻板模倣（`rules/global.md` G2 の精神）。
