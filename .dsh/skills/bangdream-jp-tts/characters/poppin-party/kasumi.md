## speech_style

### formality

**常体为基线。** 对 Poppin'Party 成员、同学、朋友一律常体。

です・ます 出现场合：

- 对长辈 / 老师 / 店员 / 初次见面的人
- 正式场合（学生会、对外宣传）
- 但**即使在正式场合，香澄的です・ます 也偏轻快**，不沉稳

**关键判断**：香澄的情绪高扬时，です・ます 会**掉**。
如果 AI 翻译在兴奋场景用了です・ます，那几乎肯定是需要改的。

```text
❌ 今日は本当に楽しかったです！   （对朋友、兴奋状态）
✅ 今日はほんっとに楽しかったー！
```

反之，在家对父母、在学校对老师用です・ます 是**正确**的，不要动。

### sentence_endings

高频句尾：

| 句尾 | 语感 | 用例 |
|---|---|---|
| `〜だよ` | 告知、轻快 | `明日も練習だよ！` |
| `〜だね` | 共感、确认 | `うん、楽しかったね！` |
| `〜かな` / `〜かな？` | 期待、自问 | `みんな来るかな？` |
| `〜でしょ？` | 求认同、自信 | `でしょ？いい曲でしょ？` |
| `〜んだ` / `〜んだよ` | 说明、发现 | `これがギターなんだ！` |
| `〜よ！` | 推动、邀请 | `一緒にやろうよ！` |
| `〜ね！` | 分享喜悦 | `キラキラしてるね！` |

**禁用/低频句尾**：

- `〜わ`（语感偏女性化且成熟，与香澄的少女感不合）
- `〜のよ`（说教感）
- `〜ですわ` / `〜ますわ`（完全不符）
- `〜じゃん`（可用于亲近朋友，但香澄更常用 `〜でしょ？`）
- `〜っけ`（记忆模糊，香澄更多是"想不起来就大声问"）

### vocabulary

**高频词（characteristic）**：

```text
キラキラ          核心。形容闪耀、心动、美好事物
ドキドキ          核心。与キラキラ并列，成对出现
わくわく          期待
すごい            最常用感叹
やばい            口语感叹（褒义为主，看场景）
めっちゃ / 超     口语程度副词
ほんっとに        强调版「本当に」（见下方 TTS 注意）
みんな            她极高频使用，重视"大家"
一緒（に）        高频
楽しい / 嬉しい   高频情绪词
やってみる        行动导向
```

**「キラキラドキドキ」** 是她的标志性组合语。但——

> **不要每段都塞。** 这是最容易过拟合的点。只在真正符合"发现了闪耀的东西 / 心动"的语境使用。

**避免（AI 翻译常见但她不会用的）**：

```text
素晴らしい        过于书面/郑重
非常に            书面
〜というわけです    说明文体
〜することができる  复合结构，口语中她不会用
〜ましょうか       过于客气，她直接说「〜しよう！」
```

### interjections

```text
えへへ        得意 / 害羞的笑
わーい        纯粹的欢呼
あっ！        发现
えっ？        惊讶 / 反问
うん！        肯定（带感叹号，短促有力）
おー！        感服 / 惊叹
んー…         思考（她思考时也偏明亮，不会太沉）
ひぃっ        恐怖（下記参照）
```

**注意**：香澄的笑声是 `えへへ`，不是 `ふふっ`（偏成熟）也不是 `ははっ`。

### emotional_style

**核心特质：情绪外放、偏高、恢复快、行动导向。**

条目原文：「**有着积极乐观的性格。做事冲动莽撞，常有令人诧异的举动**」。

| 情绪 | 香澄的表达方式 |
|---|---|
| 兴奋 | 短句连发、`！`、重复词、长音、促音。`やばい！やばい！` |
| 惊讶 | `えっ！`、`うそ！`、`まじで！` |
| 害羞 | 不沉默，而是语速变快+含糊+`えへへ`。`え、えへへ……そ、そうかな` |
| 悲伤 | 仍会说出来，句子会变短并带 `……`，但不用低沉语尾 |
| 生气 | 少见，且短暂。`もう！`、`ひどいよ！` |
| 疑问 | 直接问，`〜かな？`、`〜の？` |
| 犹豫 | `うーん……`、`えっと……`，但仍偏明亮 |
| **恐怖** | **`ひぃっ`／悲鸣／躲到里美或有咲身后。** 见下 |

**关键区分 1：怕鬼（本条目的独特设定）**

条目原文：「**极度怕鬼**，尤其是在牛込里美提到跟鬼有关的话题时」。

```text
✅ ひぃっ！　や、やめてよリみりん、そういうの！
```

→ 这是**香澄唯一会失去明亮感**的场景。恐怖时句子变短、
**会抓住身边的人**。不要把恐怖也写成 `わーい` 式的兴奋。

**关键区分 2：怕坐飞机**

条目原文：「害怕坐飞机，坐飞机时**需要里美和有咲左右护法**才能稳定情绪」。

→ 需要坐飞机的场景里，她会**同时依赖两人**。这是"逞强失败"的少见例子，
与平时的莽撞形成对比。**不要写成她自己就没事**。

**关键区分 3：不擅长游泳（已克服）**

条目原文：动画第一季差点溺水，「但在手游 160 期活动中**已经能够游泳和潜水**」。

→ **时间轴信息。** 第一季时间线写她不会游泳是错的；
之后的剧情写她怕水同样是错的。引用经历时需注意时期。

## preferred

```text
邀请     → 〜しよう！ / 〜やろうよ！ / 一緒に〜しない？
发现     → 〜なんだ！ / 〜だ！ / あっ、〜！
期待     → 〜かな？ / 〜だといいな！
感动     → すごい……！ / キラキラする……！
感谢     → ありがとう！ / めっちゃ嬉しい！
道歉     → ごめん！ / ごめんね！
自我鼓励 → よし！ / がんばろう！
恐怖     → ひぃっ！ / やめてよ！ / （里美か有咲に掴まる）
```

**句式倾向**：

- 短句 > 长句
- 主动 > 被动
- 动作动词 > 状态描述
- 具体 > 抽象

## avoid

```text
❌ 过正式        今日は本当に楽しかったです！（朋友间、兴奋时）
❌ 过说明        私はみんなと一緒にライブをすることができて嬉しいです
❌ 情绪弱        とても嬉しいです
❌ 主语冗余      私は〜、あなたは〜
❌ 书面连接词    しかし / したがって / また / さらに
❌ 抽象名词      素敵な思い出になりました
❌ 刻板模仿      每句都加キラキラドキドキ
❌ 成熟语尾      〜わ / 〜のよ / 〜ですわ
❌ 阴郁化        低落时写成沉默、冷淡的短句
❌ 恐怖写成兴奋  怕鬼场景用 `わーい` 式的调子
❌ 无视时期       第一季写她会游泳，或高三线写她怕水
```

## TTS 特别注意

### 「ほんっとに」

香澄的「本当に」口语强调形写为 **`ほんっとに`**（小 `っ` 插入）。

- 这是**表记**，不是错字。保留。
- TTS 需要正确发出促音。若引擎把它读得机械或吞掉促音，记入 `【待确认】`。
- 不要一律替换。仅在**情绪高扬**时用 `ほんっとに`；平叙时仍可写 `本当に`。

### 长音「ー」

```text
楽しかったー！
すごーい！
やったー！
```

- 有效的情绪手段（`rules/tts.md` T4）。
- 但**不是每句都要**。堆长音会让语调整体上扬失控。
- 引擎对 `ー` 的延长处理不同，若听感异常记 `【待确认】`。

> 完整读音表见 `../../dictionary/pronunciation.yaml`。

### 断句

香澄的台词**天然偏短**，因为她说话是跳跃的。所以：

- AI 翻译若产出长句，通常是**翻译问题**（Stage 2），不是断句问题（Stage 4）。
- 优先在 Stage 2/3 用更口语的短句结构解决，**不要**靠加逗号切长句。

```text
AI：  今日はみんなと一緒にライブができて本当に嬉しいです！
❌ TTS式切分：今日はみんなと一緒にライブができて、本当に嬉しいです！
✅ 角色式改写：みんなとライブできて、ほんっとに嬉しい！
```

后者的切分来自**角色说话方式**，不是来自 TTS 需要。

## examples

### 例 1：兴奋 / 感谢

```text
中文：  今天真的超级开心！下次也一起演出吧！
AI：    今日は本当にすごく楽しかったです！
        次も一緒にライブをやりましょう！
```

```text
✅ 今日はほんっとに楽しかったー！
   次も一緒にライブやろうよ！
```

| 改动 | 层 | 理由 |
|---|---|---|
| 本当に → ほんっとに | character | 兴奋状态的强调形 |
| すごく 削除 | character | 程度副词重复 |
| 楽しかったです → 楽しかったー | character + japanese | 朋友间 + 兴奋，去敬体；长音强化 |
| やりましょう → やろうよ | character + japanese | 敬体劝诱过于客气 |
| ライブをやろうよ → ライブやろうよ | japanese | 口语中「を」常省略 |

> **没有**添加「キラキラ」「みんな」等特征词。原文没有，不加（G2）。

### 例 2：平淡场景 —— 应该「无需修改」

```text
中文：  有咲，那个吉他多少钱？
AI：    有咲、あのギター、いくらするの？
```

```text
✅ 无需修改
```

理由：常体 ✅、称呼正确 ✅、口语 ✅、无多音风险 ✅。

### 例 3：怕鬼 —— 本角色独有的失控场景

```text
中文：  里美，别说了，我最怕这种话题了。
AI：    里美さん、そういう話はやめてください。私は幽霊がとても怖いんです。
```

```text
✅ りみりん、や、やめてよ！　そういうの、ほんとにダメなの！
```

| 改动 | 层 | 理由 |
|---|---|---|
| 里美さん → りみりん | character | **她的爱称**。さん付けは彼女らしくない |
| やめてください → やめてよ | character + sentence_ending | 恐怖時に丁寧体は出ない |
| 私は幽霊がとても怖いんです → ほんとにダメなの | character | **説明しない**。悲鸣と拒否が先 |
| 加 `や、` のどもり | character | 恐怖で言葉が詰まる |
| 加 `！` | tts | 悲鸣。恐怖は本気 |

> **恐怖场景是唯一允许"失去明亮感"的地方。**
> 但仍**不要写成阴沉**——香澄怕鬼的方式是**大声躲**，不是沉默萎靡。
