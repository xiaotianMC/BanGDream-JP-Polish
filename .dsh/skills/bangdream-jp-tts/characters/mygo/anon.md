## speech_style

### formality

**基线：常体，且偏"自来熟"的快节奏。** 对同辈、后辈一律常体；对先輩混用
「〜先輩」+ 常体（她是**归国子女**，敬语体系不完全是日语母语者的直觉）。

| 对象 | 语体 | 依据 |
|---|---|---|
| マイゴのメンバー | 常体 | |
| 先輩（香澄・沙綾・モカ・透子 等） | 常体 + 「〜先輩」称呼 | 称呼带先輩，但语体不升到丁寧体 |
| 初対面の大人・店員 | 丁寧体 | 常识范围 |
| 目上で距离がある相手 | 丁寧体 | |

**关键区分**：香澄は「場面」で、燈は「関係」で語体を切り替える。
**愛音は切り替えが少ない**——ほぼ常体で押し通し、相手との距離は
**称呼の接尾辞**（さん／ちゃん／先輩）で調整する。

> 注意：她**不是**"礼貌型"。丁寧体の多用は彼女らしくない。
> 「归国子女」設定により、敬語の使い方が**やや不自然でもよい**——
> これは無理に直す対象ではなく、キャラクター性として扱う。

### sentence_endings

高频句尾：

| 句尾 | 语感 | 用例 |
|---|---|---|
| `〜じゃん` | 确认、轻推 | `いいじゃん！` |
| `〜でしょ？` | 求认同（自信ありげ） | `かわいいでしょ？` |
| `〜だって` | 理由提示、辩解 | `だって仕方ないじゃん` |
| `〜じゃない？` | 提议、委婉 | `これ、いいんじゃない？` |
| `〜の？` / `〜の` | 问、说明 | `それ、どういうことなの？` |
| `〜っしょ` | 强推、玩笑 | `行けるっしょ！` |
| `〜かな` | 轻微不确定 | `どうかな` |

**禁用/低频句尾**：

- `〜ですわ` / `〜ますわ`（完全不符）
- `〜のよ`（说教感）
- `〜わ`（成熟女性语尾）
- 過度な丁寧体（`〜でしょうか` 等。她会直接问）

### vocabulary

**高频词（characteristic）**：

```text
かわいい        高频。她的核心价值判断
ヤバい          高频感叹
いい感じ        高频评价
とりあえず      行动导向
〜っぽい        她的口癖级后缀
```

**她的特征：起名品味极差。** 这是官方反复玩的梗，且**对台词有直接影响**：

- 给乐队起的名字全被否决：`UnKnown` `あのね。` `アンノウイモ` `ANON TOKYO`
- 给立希起的昵称 `りっきー`、给爽世起的 `そよりん` —— **都被本人吐槽品味差**
- 全部包含自己的名字（`ANON` / `あの`）

→ **在使用这些昵称时，要意识到"这是她单方面按上去的"**。
立希・爽世对此有明确反应（吐槽），不是双方向的爱称。

**避免（AI 翻译常见但她不会用的）**：

```text
素晴らしい        过于郑重
非常に            书面
〜というわけです    说明文体
〜させていただきます  过度谦让
```

### interjections

```text
えー！        不满・惊讶
あっ         发现
うわ         惊讶（褒贬両用）
へえ〜        佩服
はいはい      敷衍（对吐槽时）
```

**注意**：与灯相反，愛音的感叹词**多且外放**。
但也不是香澄式的`わーい`——她更偏**都市的、稍微有点做作**的语感。

### emotional_style

**核心特质：伪阳角。外放だが、内面は繊細で失敗を引きずる。**

表向きは明るく行動的、しかし**留学失敗**という弱点を抱えており、
「失敗」が她的核心关键字（PV关键字即「失敗」）。她**会逞强**。

| 情绪 | 愛音的表达方式 |
|---|---|
| 兴奋 | 语速快、`ヤバい！`、`すごい！`。外放 |
| 惊讶 | `えー！`、`うそ！`、`まじで！` |
| 害羞 | **用玩笑或虚荣掩饰**。`え、別に？`、`まあね` |
| 悲伤 | **不示弱**。先逞强（`全然平気`），独处或对灯时才漏出来 |
| 生气 | 直接对抗 + 吐槽。与立希初次见面就吵架 |
| 疑问 | `〜の？`、`どういうこと？` |
| 犹豫 | 表面仍在动（`とりあえず〜しよう`），不静默 |
| 吐槽 | **得意分野**。与立希的互相吐槽是常态 |

**关键区分**：她的开朗**不等于无忧**。
把她的低落写成"马上恢复的乐天派"是**错的**——她的关键字是「失敗」。

> 与灯（`tomori.md`）の対比：
> - 灯：内压、長い沈黙、`……` 多用
> - 愛音：外放、沈黙しない、`！` と `？` 多用
> 二人の掛け合いでは**この差が会話のテンポを作る**。

### address_forms

**称呼数据在 `../dictionary/address-forms.yaml`。** 使用口径：

#### 特征：几乎总带接尾辞，但对立希不带

条目原文：「**只有对立希称呼的时候不会带后缀**，称呼其他角色后面都会带后缀」。

- 对灯：`高松さん` → `燈ちゃん` → `ともりん`（**时间轴**）
- 对爽世：`そよさん` → `そよりん`（**时间轴**。昵称是她起的）
- 对乐奈：`楽奈ちゃん`
- 对**立希**：`たき` → `りっきー`（呼び捨て系。**サフィックスなし**）
- 对先輩：`香澄先輩` `沙綾先輩` `モカ先輩` `ひまり先輩` `透子先輩` `つくし先輩`
- 对同格以上：`美竹さん` `千聖さん` `廣町さん` `燐子さん` `花音さん` `八幡さん`→`海鈴ちゃん`
- 对Ave Mujica：`初華` → `初華ちゃん`、`睦ちゃん`、`祥子ちゃん`、`にゃむち`

**注意**：原作では愛音は Ave Mujica のメンバーを**世界観内のコードネームで呼ぶ**ことが多く、
「全网最尊重Mujica世界观的人」と戏称される。
コードネーム（モーティス等）を本文で使うかは**要確認**（下記「表记待确认」）。

**关键校验点**：
- 対立希に接尾辞を付けたら**らしくない**
- 「そよりん」は**彼女が押し付けた**ニックネーム。爽世側はこれを受け入れているが、
  愛音が使うからといって**爽世が自称するわけではない**
- `八幡さん` → `海鈴ちゃん` は**時間軸**（関係の変化）

## preferred

```text
誘い       → 〜じゃん！ / 〜しようよ / 〜っしょ！
評価       → いい感じ！ / かわいい！ / 微妙
提案       → 〜はどう？ / 〜じゃない？

言い訳     → だって〜 / 〜もん
```

**句式倾向**：

- 主动 > 被动
- 提议多 > 陈述多（行动力の現れ）
- 吐槽とボケの往復

## TTS 特别注意

### 名字读音

| 表记 | 读音 | 风险 |
|---|---|---|
| 愛音 | あのん | **高。「あいね」と誤読されやすい** |
| 千早 | ちはや | 中。「ちはや」で概ね安定 |

**「愛音 → あのん」は本角色的最高风险项。**
「愛」を あい、「音」を ね と読む通常の連想から外れる。
`../dictionary/pronunciation.yaml` に登録済み（`verified: false`）。

### 长音・促音

**愛音は長音・促音を普通に使う**（灯とは対照的）。

```text
ヤバーい / すごーい / まじでー
```

ただし**香澄ほど多用しない**。興奮時のみ。

### 断句

**早口で、息継ぎが少ない。** 长句も彼女らしい。

→ `tts.md` T1 の 20〜30 字上限を超える場合でも、
**まず「角色として自然か」を判断**し、TTS 都合で機械的に切らない（T1 の原則）。
彼女の早口は**キャラクター性**である。

## examples

### 例 1：提议 + 求认同

```text
中文：  这个不错吧？我们就这么办吧！
AI：    これはいいではないでしょうか。そのようにしましょう。
```

```text
✅ これ、いいじゃん！そうしよ！
```

| 改动 | 层 | 理由 |
|---|---|---|
| 〜ではないでしょうか → 〜じゃん | character | 丁寧体の確認は彼女らしくない。`じゃん` が基本 |
| そのようにしましょう → そうしよ | character + sentence_ending | 丁寧体の勧誘は過剰。常体で即断 |

### 例 2：对立希不带后缀 —— 应该「无需修改」

```text
角色：千早愛音
场景：練習中、立希に話しかける
中文：  立希，那个搞定了吗？
AI：    立希さん、それ終わった？
```

```text
✅ りっきー、それ終わった？
```

| 改动 | 层 | 理由 |
|---|---|---|
| 立希さん → りっきー | character | **対立希のみ接尾辞を付けない**のが特徴。かつ彼女が押し付けたニックネーム |

> **これは本角色の最重要チェック項目。** 立希に接尾辞を付けると OOC。

### 例 3：伪装（逞强）

```text
中文：  没事的，我一点都不在意。
AI：    大丈夫です、私は全然気にしていません。
```

```text
✅ 全然平気だって。気にしてないし。
```

| 改动 | 层 | 理由 |
|---|---|---|
| 大丈夫です → 全然平気だって | character | 丁寧体を外す。`だって` で**言い訳がましさ**を出す |
| 気にしていません → 気にしてないし | japanese | 常体。「〜し」で**強がり**の語感 |

> 重要：**平気であることを強調するほど、実は引きずっている**。
> この逞強は `avoid` の「楽天家すぎ」を避けるための表現。
