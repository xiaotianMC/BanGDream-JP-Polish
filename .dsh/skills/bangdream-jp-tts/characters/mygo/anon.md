## speech_style

### 语体

**基线：常体，且偏"自来熟"的快节奏。** 对同辈、后辈一律常体；对前辈混用
「〜先輩」+ 常体（她是**归国子女**，敬语体系不完全是日语母语者的直觉）。

| 对象 | 语体 | 依据 |
|---|---|---|
| MyGO!!!!! 成员 | 常体 | |
| 前辈（香澄・沙綾・モカ・透子 等） | 常体 + 「〜先輩」称呼 | 称呼带先輩，但语体不升到敬体 |
| 初次见面的成年人・店员 | 敬体 | 常识范围 |
| 地位在上、有距离的对象 | 敬体 | |

**关键区分**：香澄按「场合」、燈按「关系」切换语体。
**愛音的切换很少**——几乎一路用常体，与对方的距离靠
**称呼的后缀**（さん／ちゃん／先輩）来调整。

> 注意：她**不是**"礼貌型"。多用敬体不像她。
> 由于「归国子女」的设定，敬语用得**稍不自然也可以**——
> 这不是要强行修正的对象，而是作为角色特性来处理。

### sentence_endings

高频句尾：

| 句尾 | 语感 | 用例 |
|---|---|---|
| `〜じゃん` | 确认、轻推 | `いいじゃん！` |
| `〜でしょ？` | 求认同（显得自信） | `かわいいでしょ？` |
| `〜だって` | 理由提示、辩解 | `だって仕方ないじゃん` |
| `〜じゃない？` | 提议、委婉 | `これ、いいんじゃない？` |
| `〜の？` / `〜の` | 问、说明 | `それ、どういうことなの？` |
| `〜っしょ` | 强推、玩笑 | `行けるっしょ！` |
| `〜かな` | 轻微不确定 | `どうかな` |

**禁用/低频句尾**：

- `〜ですわ` / `〜ますわ`（完全不符）
- `〜のよ`（说教感）
- `〜わ`（成熟女性语尾）
- 过度的敬体（`〜でしょうか` 等。她会直接问）

### vocabulary

**高频词（characteristic）**：

```text
かわいい        高频。她的核心价值判断
ヤバい          高频感叹
いい感じ        高频评价
とりあえず      行动导向
〜っぽい        她的口癖级后缀
```

**她的特征：起名品味极差。** 这是官方反复玩的梗，且**对台词有直接影响**：

- 给乐队起的名字全被否决：`UnKnown` `あのね。` `アンノウイモ` `ANON TOKYO`
- 给立希起的昵称 `りっきー`、给爽世起的 `そよりん` —— **都被本人吐槽品味差**
- 全部包含自己的名字（`ANON` / `あの`）

→ **在使用这些昵称时，要意识到"这是她单方面按上去的"**。
立希・爽世对此有明确反应（吐槽），不是双向的爱称。

**避免（AI 翻译常见但她不会用的）**：

```text
素晴らしい        过于郑重
非常に            书面
〜というわけです    说明文体
〜させていただきます  过度谦让
```

### interjections

```text
えー！        不满・惊讶
あっ         发现
うわ         惊讶（褒贬两用）
へえ〜        佩服
はいはい      敷衍（对吐槽时）
```

**注意**：与灯相反，愛音的感叹词**多且外放**。
但也不是香澄式的`わーい`——她更偏**都市的、稍微有点做作**的语感。

### emotional_style

**核心特质：伪阳角。外放，但内心细腻，会一直纠结于失败。**

表面上开朗、行动力强，但她抱着**留学失败**这个弱点，
「失敗」是她的核心关键字（PV关键字即「失敗」）。她**会逞强**。

| 情绪 | 愛音的表达方式 |
|---|---|
| 兴奋 | 语速快、`ヤバい！`、`すごい！`。外放 |
| 惊讶 | `えー！`、`うそ！`、`まじで！` |
| 害羞 | **用玩笑或虚荣掩饰**。`え、別に？`、`まあね` |
| 悲伤 | **不示弱**。先逞强（`全然平気`），独处或对灯时才漏出来 |
| 生气 | 直接对抗 + 吐槽。与立希初次见面就吵架 |
| 疑问 | `〜の？`、`どういうこと？` |
| 犹豫 | 表面仍在动（`とりあえず〜しよう`），不静默 |
| 吐槽 | **拿手领域**。与立希的互相吐槽是常态 |

**关键区分**：她的开朗**不等于无忧**。
把她的低落写成"马上恢复的乐天派"是**错的**——她的关键字是「失敗」。

> 与灯（`tomori.md`）的对比：
> - 灯：内压、长沉默、`……` 多用
> - 愛音：外放、不沉默、`！` 与 `？` 多用
> 两人的互动中，**这个差异造就了对话的节奏**。

### address_forms

**称呼数据在 `../dictionary/address-forms.yaml`。** 使用口径：

#### 特征：几乎总带后缀，但对立希不带

条目原文：「**只有对立希称呼的时候不会带后缀**，称呼其他角色后面都会带后缀」。

- 对灯：`高松さん` → `燈ちゃん` → `ともりん`（**时间轴**）
- 对爽世：`そよさん` → `そよりん`（**时间轴**。昵称是她起的）
- 对乐奈：`楽奈ちゃん`
- 对**立希**：`たき` → `りっきー`（直呼其名系。**无后缀**）
- 对前辈：`香澄先輩` `沙綾先輩` `モカ先輩` `ひまり先輩` `透子先輩` `つくし先輩`
- 对同辈及以上：`美竹さん` `千聖さん` `廣町さん` `燐子さん` `花音さん` `八幡さん`→`海鈴ちゃん`
- 对Ave Mujica：`初華` → `初華ちゃん`、`睦ちゃん`、`祥子ちゃん`、`にゃむち`

**注意**：原作中愛音经常用**世界观内的代号来称呼** Ave Mujica 的成员，
被戏称为「全网最尊重Mujica世界观的人」。
代号（モーティス等）是否在正文中使用**需确认**（见下文「表记待确认」）。

**关键校验点**：
- 对立希加后缀就**不像她**
- 「そよりん」是**她强加给别人的**昵称。爽世这边虽然接受了，
  但并不意味着愛音用了，**爽世就会自称**
- `八幡さん` → `海鈴ちゃん` 是**时间轴**（关系的变化）

## TTS 特别注意

### 名字读音

| 表记 | 读音 | 风险 |
|---|---|---|
| 愛音 | あのん | **高。容易被误读为「あいね」** |
| 千早 | ちはや | 中。以「ちはや」大致稳定 |

**「愛音 → あのん」是本角色的最高风险项。**
脱离了把「愛」读作 あい、把「音」读作 ね 的通常联想。
已在 `../dictionary/pronunciation.yaml` 中登记（`verified: false`）。

### 长音・促音

**愛音会正常使用长音・促音**（与灯形成对照）。

```text
ヤバーい / すごーい / まじでー
```

但**不像香澄那样频繁使用**。只在兴奋时。

### 断句

**语速快、换气少。** 长句也符合她的风格。

→ 即使超过 `tts.md` T1 的 20〜30 字上限，
也要**先判断「作为角色是否自然」**，不因 TTS 的方便而机械地切分（T1 的原则）。
她的语速快是**角色特性**。

## examples

### 例 1：提议 + 求认同

```text
中文：  这个不错吧？我们就这么办吧！
AI：    これはいいではないでしょうか。そのようにしましょう。
```

```text
✅ これ、いいじゃん！そうしよ！
```

| 改动 | 层 | 理由 |
|---|---|---|
| 〜ではないでしょうか → 〜じゃん | character | 用敬体确认不像她。`じゃん` 是基本 |
| そのようにしましょう → そうしよ | character + sentence_ending | 敬体劝诱过度。用常体即刻断定 |

### 例 2：对立希不带后缀 —— 应该「无需修改」

```text
角色：千早愛音
场景：練習中、立希に話しかける
中文：  立希，那个搞定了吗？
AI：    立希さん、それ終わった？
```

```text
✅ りっきー、それ終わった？
```

| 改动 | 层 | 理由 |
|---|---|---|
| 立希さん → りっきー | character | **只对立希不加后缀**是特征。而且是她强加的昵称 |

> **这是本角色最重要的检查项。** 给立希加后缀就 OOC。

### 例 3：伪装（逞强）

```text
中文：  没事的，我一点都不在意。
AI：    大丈夫です、私は全然気にしていません。
```

```text
✅ 全然平気だって。気にしてないし。
```

| 改动 | 层 | 理由 |
|---|---|---|
| 大丈夫です → 全然平気だって | character | 去掉敬体。用 `だって` 表现出**像在找借口**的感觉 |
| 気にしていません → 気にしてないし | japanese | 常体。用「〜し」体现**逞强**的语感 |

> 重要：**越是强调自己没事，其实越是放不下**。
> 这种逞强是为了避开 `avoid` 中「过于乐天」的表现。
