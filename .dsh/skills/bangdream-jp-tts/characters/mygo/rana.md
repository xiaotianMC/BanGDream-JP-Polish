## speech_style

### 语体

**只用常体。不使用敬语。**

- 无论对方是谁都用常体
- 对前辈（香澄・友希那・リサ等）也直呼其名
- 敬体**完全不出现**

**重要**：这不是"不礼貌"，而是**她根本不区分上下关系**。
和猫不挑对象是同一个原理，**她不因对象而改变语体**。

### sentence_endings

**极短。** 条目原文：「**话很少，讲出来的每句话都很短，用词也很简单**」。

| 句尾 | 用例 |
|---|---|
| `〜`（体言止め） | `抹茶バフェ` |
| `〜だね` | `おもしろいね` |
| `〜？`（短促的疑问） | `やる？` |
| `〜ない` | `わかんない` |
| `〜けど` | `眠いけど` |

**没有长句。** 她的"长句"也不超过 15 字左右。

**禁用**：

- 敬语整体
- 冗长的说明
- 用接续词连接的复句
- `〜じゃん` `〜っしょ`（愛音的词汇）
- 用 `〜から` `〜ので` 说明理由（她不说理由）

### vocabulary

**极简。** 核心词汇量很小，且**以具体名词为中心**。

```text
おもしろい      她的最高评价（「有趣的女人」）
抹茶（バフェ）   最喜欢的食物。可作动机使用
そば            喜欢
猫              爱好
ねむい          高频状态
おなかすいた    高频状态
```

**对食物的反应是她最"多话"的时候。**

**避免**：

```text
抽象词汇          她不会说「運命」「絆」这类词
感情说明          不直接说「嬉しい」「寂しい」
敬语
附和过长
```

### interjections

```text
ん？        对呼唤的反应
ふーん      兴趣
（無言）     最多的「回答」
```

**她的默认反应是沉默或极短的反应。**
作为台词什么都不写，或者只写「……」，这种处理**有时是正确的**。

### emotional_style

**核心特质：猫。按自己的节奏，捉摸不透，对有兴趣的事专注，对没兴趣的事立刻失去兴趣。**

条目原文：「**有着像是猫一般捉摸不透的个性，总是按照自己的步调行动**」。

| 情绪 | 楽奈的表达方式 |
|---|---|
| 兴奋 | **几乎不表现**。顶多 `おもしろい` |
| 惊讶 | 只有 `ん？` |
| 害羞 | 没有这个概念 |
| 悲伤 | 不表现。但有时会**默不作声地离开** |
| 生气 | 不高兴时会**睡觉**或**去别的地方** |
| 疑问 | `ん？` / `なに？` |
| 犹豫 | 没有。决断要么即时，要么就失去兴趣 |
| 兴趣 | `おもしろい`。这是最大的赞美 |

**关键区分**：
- 楽奈的沉默**与灯的沉默是两回事**。
  灯是「想说却说不出」，楽奈是「不觉得有必要说」。
- 楽奈的不关心**并非冷淡**。只是**优先顺序不同**而已。

> **把她当猫来写。** 行动就如猫一般——
> 在暖炉旁蜷成一团、在长凳・屋顶・树上睡午觉、下雨前挠脸、
> 玩毛线、被叫名字也看心情决定无视。
> 台词的量本身就是角色表现。

### address_forms

**称呼数据在 `../dictionary/address-forms.yaml`。**

#### 特征 1：称呼**几乎全用假名，且无语尾**

条目原文：「在游戏台词中，**对他人的称呼均写作假名形式而不是汉字**」。

| 对象 | 楽奈的称呼方式 |
|---|---|
| 高松燈 | `ともり` |
| 千早愛音 | `あのん` |
| 長崎そよ | `そよ` |
| 椎名立希 | `りっきー` |
| 戸山香澄 | `かすみ` |
| 花園たえ | `たえ` |
| 山吹沙綾 | `さーや` |
| 湊友希那 | `ゆきな` |
| 今井リサ | `りさ` |

**全部直呼其名，没有后缀，几乎全用平假名。**
不用汉字表记（是 `ともり` 而不是 `燈`）。

→ **TTS 的正面影响**：假名表记 = 读音确定。
像灯（`燈`）和愛音（`愛音`）那样的误读风险**在她的台词中不会发生**。
这意味着楽奈的台词在 TTS 上是**最安全的**。

#### 特征 2：自称是 `わたし`

#### 特征 3：称呼的次数本身就少

条目原文：「虽然猫猫喊人名字的**次数屈指可数**」。
不叫名字只说事情，或者默不作声地靠近，这样更自然。

#### 他人对她的称呼方式

- `楽奈ちゃん`（灯・愛音・爽世・沙綾・香澄 等）
- `楽奈`（たえ・リサ・益木）
- `りっきー` 是**愛音强加**的昵称。立希则叫她 `野良猫、楽奈`
- `らーちゃん`（育美）、`楽奈さん`（令王那）、`要さん`（友希那・麻弥）

**只有立希叫她 `野良猫`。** 这与其说是爱称，不如说是**对待方式**。

## preferred

```text
兴趣     → おもしろい
要求     → 〜（体言止め） 例：抹茶バフェ
拒绝     → いや / 〜ない
不关心   → （無言） / ん？ / ふーん
```

**句式倾向**：

- 体言止め > 句子
- 单词 > 短语
- 沉默 > 发言

## TTS 特别注意

### 名字读音

| 表记 | 读音 | 风险 |
|---|---|---|
| 楽奈 | らーな | **高。容易被误读为「らくな」** |
| 要 | かなめ | 中。以「かなめ」稳定 |

**「楽奈 → らーな」需要注意。** 把「楽」读作 らく、「奈」读作 な 就会变成「らくな」。
正确的是 **らーな**（长音）。已在 `../dictionary/pronunciation.yaml` 中登记。

> 条目的读音表记是「楽奈（らーな）」——**带长音符**。
> 是「らーな」，不是「らな」。

### 她的台词是 TTS 最安全的一类

理由：
1. **人名几乎都用平假名写** → 不会发生难读汉字的误读
2. **台词短** → 不会产生断句问题
3. **没有敬语** → 不需要检查语体的一致性

→ 反过来说，**如果楽奈的台词出现 TTS 错误，原因几乎就是
`らーな` 的长音，或叙述部分的人名汉字**。

### 断句

**她的台词不需要切分。** 本来就短。

**不要写成长台词。** 如果 AI 翻译输出长台词，
那是**翻译的问题**（Stage 2），不是用 TTS 切分的问题（T1 的原则）。

```text
❌ わたしは、抹茶バフェが、食べたい、です
✅ 抹茶バフェ
```

## examples

### 例 1：要求（体言止め）

```text
中文：  我想吃抹茶巴菲。
AI：    私は抹茶バフェが食べたいです。
```

```text
✅ 抹茶バフェ。
```

| 改动 | 层 | 理由 |
|---|---|---|
| 全文 → 体言止め | character | 她只说事情。`私は` 和 `食べたいです` 都不需要 |
| 删除敬体 | character + japanese | 楽奈不使用敬语 |

> **信息并没有丢失。** 只要说「抹茶バフェ」，在语境上「食べたい」是自明的。
> 这不是违反 G1，而是**作为日语的省略是正当的**。

### 例 2：最高级别的赞美

```text
中文：  灯，你真是个有趣的人。
AI：    燈さん、あなたは本当に面白い人ですね。
```

```text
✅ ともり。おもしろい。
```

| 改动 | 层 | 理由 |
|---|---|---|
| 燈さん → ともり | character | **平假名・直呼其名**。她的表记原则 |
| あなたは本当に面白い人ですね → おもしろい | character | 太长了。她只用 `おもしろい` 一句就够 |
| 删除敬体 | character | — |
| 分割（用 `。` 分成两句） | character + tts | 短的两句。她的说话方式 |

> 原作的「有趣的女人（おもしろい女）」是她的**最大赞美**。
> 不要让她过度夸奖。

### 例 3：不关心 —— 应该「无需修改」

```text
角色：要楽奈
场景：練習に誘われる
中文：  乐奈，来练习吧。
AI：    楽奈ちゃん、練習来る？
```

```text
✅ ん？
```

> **这是正确的。** 她的「ん？」既不是拒绝也不是同意，
> 而是**保留判断**的状态。这种暧昧正是角色性。
>
> 如果这里改成 `はい、行きます！` 或 `いや、行かない`，
> **就会失去猫的感觉**。强迫她二选一就是 OOC。
