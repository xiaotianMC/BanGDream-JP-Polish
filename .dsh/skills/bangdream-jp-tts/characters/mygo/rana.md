## speech_style

### formality

**常体のみ。敬語を使わない。**

- 相手が誰であれ常体
- 先輩（香澄・友希那・リサ等）にも呼び捨て
- 丁寧体は**一切出てこない**

**重要**：这不是"不礼貌"，而是**她根本不区分上下关系**。
猫が相手を選ばないのと同じ原理で、**相手によって語体を変えない**。

### sentence_endings

**极短。** 条目原文：「**话很少，讲出来的每句话都很短，用词也很简单**」。

| 句尾 | 用例 |
|---|---|
| `〜`（体言止め） | `抹茶バフェ` |
| `〜だね` | `おもしろいね` |
| `〜？`（短い疑問） | `やる？` |
| `〜ない` | `わかんない` |
| `〜けど` | `眠いけど` |

**没有长句。** 她的"长句"也不超过 15 字左右。

**禁用**：

- 敬語全般
- 長い説明
- 接続詞で繋いだ複文
- `〜じゃん` `〜っしょ`（愛音の語彙）
- `〜から` `〜ので` による理由説明（彼女は理由を言わない）

### vocabulary

**极简。** 核心词汇量很小，且**具体名词が中心**。

```text
おもしろい      她的最高评价（「有趣的女人」）
抹茶（バフェ）   最喜欢的食物。可作动机使用
そば            喜欢
猫              爱好
ねむい          高频状态
おなかすいた    高频状态
```

**对食物的反应是她最"多话"的时候。**

**避免**：

```text
抽象的な語彙      她不会说「運命」「絆」这类词
感情の説明        「嬉しい」「寂しい」を直接言わない
丁寧語
長い相槌
```

### interjections

```text
ん？        呼びかけへの反応
ふーん      興味
（無言）     最も多い「返答」
```

**她的默认反应是沉默或极短的反应。**
台詞として何も書かない、あるいは「……」だけ、という処理が**正しい**場合がある。

### emotional_style

**核心特质：猫。按自己的节奏，捉摸不透，对有兴趣的事专注，对没兴趣的事立刻失去兴趣。**

条目原文：「**有着像是猫一般捉摸不透的个性，总是按照自己的步调行动**」。

| 情绪 | 楽奈的表达方式 |
|---|---|
| 兴奋 | **几乎不表现**。せいぜい `おもしろい` |
| 惊讶 | `ん？` のみ |
| 害羞 | 概念がない |
| 悲伤 | 表現しない。ただし**黙って離れる**ことはある |
| 生气 | 不機嫌になると**寝る**か**どこかへ行く** |
| 疑问 | `ん？` / `なに？` |
| 犹豫 | 無い。決断は即時か、興味を失うか |
| 関心 | `おもしろい`。これが最大の賛辞 |

**关键区分**：
- 楽奈の沈黙は**灯の沈黙と別物**。
  灯は「言いたいのに言えない」、楽奈は「言う必要を感じていない」。
- 楽奈の無関心は**冷淡ではない**。単に**優先順位が違う**だけ。

> **猫として書く。** 行動は猫のそれ——
> 暖炉のそばで丸くなる、長凳・屋上・木の上で昼寝、雨の前に顔を掻く、
> 毛糸で遊ぶ、名前を呼ばれても気分次第で無視する。
> 台詞の量そのものがキャラクター表現になる。

### address_forms

**称呼数据在 `../dictionary/address-forms.yaml`。**

#### 特征 1：称呼**几乎全用假名，且无语尾**

条目原文：「在游戏台词中，**对他人的称呼均写作假名形式而不是汉字**」。

| 对象 | 楽奈の呼び方 |
|---|---|
| 高松燈 | `ともり` |
| 千早愛音 | `あのん` |
| 長崎そよ | `そよ` |
| 椎名立希 | `りっきー` |
| 戸山香澄 | `かすみ` |
| 花園たえ | `たえ` |
| 山吹沙綾 | `さーや` |
| 湊友希那 | `ゆきな` |
| 今井リサ | `りさ` |

**すべて呼び捨て、接尾辞なし、ほぼ平仮名。**
漢字表記にしない（`燈` ではなく `ともり`）。

→ **TTS 的正面影响**：假名表记 = 读音确定。
灯（`燈`）や愛音（`愛音`）のような誤読リスクが**彼女の台詞では発生しない**。
これは楽奈の台詞が TTS 的に**最も安全**であることを意味する。

#### 特征 2：自称は `わたし`

#### 特征 3：呼ぶ回数自体が少ない

条目原文：「虽然猫猫喊人名字的**次数屈指可数**」。
名前を呼ばずに用件だけ言う、あるいは無言で近づく方が自然。

#### 他者からの呼ばれ方

- `楽奈ちゃん`（灯・愛音・爽世・沙綾・香澄 等）
- `楽奈`（たえ・リサ・益木）
- `りっきー` は**愛音が押し付けた**ニックネーム。立希は `野良猫、楽奈` と呼ぶ
- `らーちゃん`（育美）、`楽奈さん`（令王那）、`要さん`（友希那・麻弥）

**立希だけが `野良猫` と呼ぶ。** これは愛称というより**扱い**。

## preferred

```text
興味     → おもしろい
要求     → 〜（体言止め） 例：抹茶バフェ
拒否     → いや / 〜ない
無関心   → （無言） / ん？ / ふーん
```

**句式倾向**：

- 体言止め > 文
- 単語 > 句
- 沈黙 > 発話

## TTS 特别注意

### 名字读音

| 表记 | 读音 | 风险 |
|---|---|---|
| 楽奈 | らーな | **高。「らくな」と誤読されやすい** |
| 要 | かなめ | 中。「かなめ」で安定 |

**「楽奈 → らーな」は要注意。** 「楽」を らく、「奈」を な と讀むと「らくな」になる。
正しくは **らーな**（長音）。`../dictionary/pronunciation.yaml` に登録済み。

> 条目の読み表記は「楽奈（らーな）」——**長音符付き**。
> 「らな」ではなく「らーな」。

### 她的台词是 TTS 最安全的一类

理由：
1. **人名をほぼ平仮名で書く** → 難読漢字の誤読が発生しない
2. **台詞が短い** → 断句の問題が起きない
3. **敬語がない** → 語体の一貫性チェックが不要

→ 逆に言えば、**楽奈の台詞で TTS エラーが出たら、原因はほぼ
`らーな` の長音か、地の文の人名漢字**である。

### 断句

**彼女の台詞は切る必要がない。** 元から短い。

**長い台詞にしないこと。** AI 翻訳が長い台詞を出した場合、
それは**翻訳の問題**（Stage 2）であり、TTS で切る問題ではない（T1 の原則）。

```text
❌ わたしは、抹茶バフェが、食べたい、です
✅ 抹茶バフェ
```

## examples

### 例 1：要求（体言止め）

```text
中文：  我想吃抹茶巴菲。
AI：    私は抹茶バフェが食べたいです。
```

```text
✅ 抹茶バフェ。
```

| 改动 | 层 | 理由 |
|---|---|---|
| 全文 → 体言止め | character | 彼女は用件だけ言う。`私は` も `食べたいです` も不要 |
| 敬体削除 | character + japanese | 楽奈は敬語を使わない |

> **情報は落ちていない。** 「抹茶バフェ」と言えば、文脈上「食べたい」は自明。
> これは G1 違反ではなく、**日本語の省略として正当**。

### 例 2：最大級の賛辞

```text
中文：  灯，你真是个有趣的人。
AI：    燈さん、あなたは本当に面白い人ですね。
```

```text
✅ ともり。おもしろい。
```

| 改动 | 层 | 理由 |
|---|---|---|
| 燈さん → ともり | character | **平仮名・呼び捨て**。彼女の表記の原則 |
| あなたは本当に面白い人ですね → おもしろい | character | 長すぎる。彼女は `おもしろい` 一言で済ませる |
| 敬体削除 | character | — |
| 分割（`。` で二文） | character + tts | 短い二文。彼女の話し方 |

> 原作の「有趣的女人（おもしろい女）」が彼女の**最大の賛辞**。
> 過剰に褒めさせない。

### 例 3：無関心 —— 应该「无需修改」

```text
角色：要楽奈
场景：練習に誘われる
中文：  乐奈，来练习吧。
AI：    楽奈ちゃん、練習来る？
```

```text
✅ ん？
```

> **これは正しい。** 彼女の「ん？」は、拒否でも承諾でもなく、
> **判断を保留している**状態。この曖昧さがキャラクター。
>
> ここで `はい、行きます！` や `いや、行かない` にすると、
> **猫らしさが失われる**。どちらかに決めさせるのは OOC。
