## speech_style

### 语体

**两层结构。这是本角色的核心。**

| 层 | 语体 | 对象 |
|---|---|---|
| **对外** | 敬体。柔和、有包容力的「大姐姐」 | 初次见面・长辈・外部的人・后辈 |
| **对内** | 常体。本来的口吻。略显辛辣，也会毒舌 | MyGO!!!!! 的成员（尤其是愛音） |

条目原文：「**如同具有安稳气氛的大姐姐一般的存在**，经常被周围的人所依赖，
不过**在和MyGO!!!!!队友在一起的时候会露出平时不会示人的那一面**」。

→ **同一个人会因场面而彻底改变。** 只写其中一面就会 OOC。

**重要**：她的敬体是**真的**（不是演技），
但**常体的一面也是真的**。两者兼具才是这个角色。

### sentence_endings

**对外（敬体）**：

| 句尾 | 用例 |
|---|---|
| `〜ですわ` | **不使用**（大小姐语尾是别的角色） |
| `〜ですね` | `そうですね` |
| `〜ですよ` | `大丈夫ですよ` |
| `〜ましょうか` | `手伝いましょうか` |
| `〜のよ` | 有时会轻微使用 |

**对内（常体）**：

| 句尾 | 语感 | 用例 |
|---|---|---|
| `〜じゃない` | 冷静的指摘 | `それ、違うじゃない` |
| `〜けど` | 带有含意 | `そういうつもりじゃないけど` |
| `〜わよ` | 较强・讽刺 | `知らないわよ` |
| `〜のよ` | 说明・含意 | `そういうことなのよ` |
| `〜かしら` | 装傻・讽刺 | `そうかしら` |
| `〜って` | 引用・推开 | `〜だって` |

**禁用**：

- `〜ですわ` / `〜ますわ`（**大小姐语尾。她虽然是月ノ森但不用**）
- `〜じゃん` `〜っしょ`（愛音的语汇）
- 过度随便的年轻人用语

### vocabulary

**高频词**：

```text
あら          轻微的惊讶（敬体一侧）
まあ          同上
〜みたい       比喻・含糊
べつに         掩饰害羞・拒绝
そう          附和（多用）
紅茶          喜欢。能流畅说出很长的商品名
```

**特征 1：红茶的名字异常地长**

条目原文：「**能轻易说出长到离谱的红茶商品名**，以至于被立希误认为是在咏唱咒语」。

→ 在台词中出现点红茶场面的场合，让她**故意流畅地说出很长的商品名**，
才符合原作。立希吐槽「呪文かよ」是固定桥段。

**特征 2：名字的由来**

「そよ」在日语中是「**清风徐来**」之意。是带有诗意语感的名字。

**避免**：

```text
ですわ / ますわ      不使用大小姐语尾
じゃん / っしょ      愛音的语汇
过于诗性的语汇       「運命」「絆」是灯的语汇
直接的表达感情       她不直接说出真心话
```

### interjections

```text
あら        对外的轻微惊讶
まあ        同上
ええ        肯定（敬体一侧）
うん        肯定（常体一侧）
ふふ        笑（带有含意的笑）
```

**注意**：她的笑容**多半带有含意**。
`ふふ` 既用于本来的笑，也用于讽刺。

### emotional_style

**核心特质：外热内冷。看起来精于算计，其实也有单纯的一面。**

条目原文：「**外热内冷**」、
「虽然长期被解读为"工于心计"，但依照漫画版的心理塑造来看，
**爽世的思想可能比较单纯**，对他人的言行仅停留在解读推理而并不会特意算计」。

| 情绪 | そよ的表达方式 |
|---|---|
| 兴奋 | **不外露**。只有 `まあ` `あら` 的程度 |
| 惊讶 | `あら` `まあ`。在敬体一侧保持平静 |
| 害羞 | **转移话题**或**带有含意的笑**。`ふふ` |
| 悲伤 | **独自处理**。表面平静。崩溃时会**慌乱**（下述） |
| 生气 | **冷静、安静地刺**。不提高嗓门。`そう` |
| 疑问 | `あら、どうして？`（敬体）/ `なんで？`（常体） |
| 犹豫 | 摆弄指尖（用**行动**表示） |
| 真心话 | 平时不说。**被逼到绝境才漏出来** |

**关键区分 1：崩坏**

她平时冷静，但**超过极限就会慌乱**。
原作第 8 话的「**なんで『春日影』やったの？！**」是其代表——
有**敬体崩坏、感情喷涌而出**的瞬间。

→ 在台词设计上，可能存在**「敬体 → 常体 → 感情爆发」的阶段**。
如果把她写成始终冷静的角色，就会失去这个重要侧面。

**关键区分 2：指尖的习惯**

条目原文：「思考事情和慌神的时候会有**拨弄指尖的习惯**，
思考重要事情（**包括算计别人**）的时候会摆出**碇司令一样的手势**」。

→ 这**不是台词而是行动**，
但作为剧本的舞台指示有参考价值。

**关键区分 3：看不透**

条目原文：「游戏剧情中……**扑克脸**」。

→ 内心与外在表现**不一致**。她台词的含义，
**按字面理解会出错**。需要读出讽刺・含意。

## preferred

```text
对外     → 〜ですよ / 〜ましょうか / あら / まあ
对内     → 〜じゃない / 〜けど / 〜のよ / そう
讽刺     → 〜かしら / 〜わよ / ふふ
体贴     → 〜大丈夫？ / 無理しないで
红茶     → 流畅地说出长商品名（段子）
```

**句式倾向**：

- 语体会**随对象完全切换**
- 不直接说真心话。要带**含意**
- 冷静的指摘 > 感情化的责难

## avoid

```text
❌ 大小姐语尾       `ですわ` `ますわ` 不使用（虽是月ノ森但另当别论）
❌ 始终敬体         不要丢掉与 MyGO 成员之间本来的口吻
❌ 始终常体         不要丢掉对外的敬体
❌ 愛音的语汇       `じゃん` `っしょ` `ヤバい`
❌ 直接表达感情     不让她坦率说出「悲しい」「寂しい」
```

## TTS 特别注意

### 名字读音

| 表记 | 读音 | 风险 |
|---|---|---|
| そよ | そよ | **低。因为是假名表记，不会误读** |
| 長崎 | ながさき | 中。与地名同形。以「ながさき」稳定 |

**「そよ」是假名，所以在 TTS 上安全。**
但**使用汉字表记「爽世」的场合**会产生误读风险
（`そうせい` `そうよ` 等）。

→ **本文中使用假名「そよ」**既符合原作又对 TTS 安全。
与 `../dictionary/proper-nouns.yaml` 的 `canonical: 長崎そよ` 一致。

> **重要**：据条目原文，名字**原本就是假名表记的「そよ」**，
> 「爽世」是动画编剧后来选定的汉字名。
> **中文圈里「素世」「爽世」两种表记混用**。
> 在日语本文中**假名「そよ」才是正确的**。

### 两层语体与 TTS

她的语体切换**直接关系到 TTS 的语调设计**：

- **敬体**：语调平坦而平稳。`、` 的间隔较短
- **常体**：稍快，语尾下降
- **崩坏时**：`！` `？` 进入，句子被切得很短

→ `../adapters/gpt-sovits.md` 的验证清单 C（标点停顿）在
**そよ的台词中尤其重要**。即使是同一句话，也需要按语体改变读法。

### 断句

**敬体的长句可以切分**（很长的商品名等）。
**常体的短而带刺的句子不切分。**

```text
（对外・长）
アニバーサリーフレーバーアイスリフレッシュメント、
シトラスミントアンドトロピカルフルーツティー、ですね。

（对内・短）
それ、違うじゃない。
```

## examples

### 例 1：对外（敬体）

```text
中文：  没关系，我来帮你吧。
AI：    大丈夫、手伝ってあげる。
```

```text
✅ 大丈夫ですよ。手伝いましょうか？
```

| 改动 | 层 | 理由 |
|---|---|---|
| 大丈夫 → 大丈夫ですよ | character | **对外是敬体**。`〜ですよ` 是她的柔和 |
| 手伝ってあげる → 手伝いましょうか | character + sentence_endings | `〜てあげる` 有强加于人的感觉。`〜ましょうか` 是**把选择交给对方**的形式 |

### 例 2：对内（常体）—— 应该「无需修改」

```text
角色：長崎そよ
场景：MyGO!!!!! の練習中、愛音に対して
中文：  爱音，那个音弹错了吧？
AI：    愛音ちゃん、その音、違うじゃない。
```

```text
✅ 无需修改
```

理由：称呼 `愛音ちゃん` ✅（对内加「ちゃん」）、常体 ✅（对内）、
`〜じゃない` 是**冷静的指摘**的固定模式 ✅。

> **注意**：如果这里改成敬体（`違いますよ`），
> **就会失去对内的本来口吻**。这是本角色最重要的检查项。

### 例 3：崩坏（敬体 → 常体 → 爆发）

```text
中文：  为什么演奏春日影了？！
AI：    どうして「春日影」を演奏したんですか。
```

```text
✅ なんで「春日影」やったの？！
```

| 改动 | 层 | 理由 |
|---|---|---|
| どうして → なんで | character | **敬体正在崩坏**。被逼到绝境的场面 |
| 演奏したんですか → やったの | character + japanese | `演奏` 太生硬。感情泄漏的场面用 `やる` |
| `。` → `？！` | tts + character | 感情的爆发。**这个场面里 `！` 是正当的** |

> **这是她并非「始终冷静」的证据。**
> `avoid` 里的「始终冷静」会把这个场面压死。

### 例 4：红茶段子

```text
中文：  那款红茶怎么样？
AI：    あの紅茶はどうですか。
```

```text
✅ あぁ、それなら——
    エクストラクラシック、エクストラアイス、エクストラベリーホイップ……
    のカスタマイズもオススメだよ～
```

| 改动 | 层 | 理由 |
|---|---|---|
| 加长商品名 | character | **符合原作**。条目中有实例 |
| `です` → `だよ` | character | 聊红茶时**本来的口吻会出来**（兴趣话题） |
| `〜もオススメだよ～` | character | 条目实例原样 |

> 立希吐槽「呪文かよ」是固定桥段。**不要单独使用**。
