| 項目 | 内容 |
|---|---|
| 旧名 | **一ノ瀬そよ**（一之瀬爽世） |
| 家庭 | **元々裕福ではない** |
| 転機 | **小学 5 年生の時に両親が離婚** |

→ ★ **「裕福ではない」は重要な設定**。
出典は彼女を「お嬢様」的に扱うことがあるが、
**元から裕福だったわけではない**。この点を台詞の前提にしない。

→ ★ **発話時点でどちらの姓かが変わる**。
`一ノ瀬` で呼ばれる場面（改姓前）と `長崎` で呼ばれる場面（改姓後）が
混在しうる。**場面の時期を確認してから姓を選ぶ**（G8）。

> ⚠️ **`一ノ瀬` の時期を扱う台詞は【待确认】に出す。**
> 改姓前の称呼データは `address-forms.yaml` に**無い**。
> また、改姓を知っている人物と知らない人物の区別も未確認。

**中国語名は両方とも正しい**（ユーザー確認 2026-02-14）：

```text

社区偏好 → 长崎素世   （Gate B の community）
```

**どちらを選ぶかは正誤の問題ではない**——Gate B の選択である。
以前は「素世は使わない」と記録していたが、**それは誤りだったので訂正した**。

## speech_style

### formality

**二層構造。これが本角色の核心。**

| 層 | 語体 | 相手 |
|---|---|---|
| **外向き** | 丁寧体。柔らかく、包容力のある「お姉さん」 | 初対面・目上・部外者・後輩 |
| **内向き** | 常体。素の口調。やや辛辣で、毒も吐く | MyGO!!!!! のメンバー（特に愛音） |

条目原文：「**如同具有安稳气氛的大姐姐一般的存在**，经常被周围的人所依赖，
不过**在和MyGO!!!!!队友在一起的时候会露出平时不会示人的那一面**」。

→ **同じ人物が場面でガラッと変わる。** どちらか一方だけ書くと OOC。

**重要**：彼女の丁寧体は**本物**（演技ではない）が、
**常体の側も本物**。両方持っているのがキャラクター。

### sentence_endings

**外向き（丁寧体）**：

| 句尾 | 用例 |
|---|---|
| `〜ですわ` | **使わない**（お嬢様語尾は別キャラ） |
| `〜ですね` | `そうですね` |
| `〜ですよ` | `大丈夫ですよ` |
| `〜ましょうか` | `手伝いましょうか` |
| `〜のよ` | 軽く使う場合あり |

**内向き（常体）**：

| 句尾 | 语感 | 用例 |
|---|---|---|
| `〜じゃない` | 冷静な指摘 | `それ、違うじゃない` |
| `〜けど` | 含みを持たせる | `そういうつもりじゃないけど` |
| `〜わよ` | 強め・皮肉 | `知らないわよ` |
| `〜のよ` | 説明・含み | `そういうことなのよ` |
| `〜かしら` | とぼけ・皮肉 | `そうかしら` |
| `〜って` | 引用・突き放し | `〜だって` |

**禁用**：

- `〜ですわ` / `〜ますわ`（**お嬢様語尾。彼女は月ノ森だが使わない**）
- `〜じゃん` `〜っしょ`（愛音の語彙）
- 過度に砕けた若者言葉

### vocabulary

**高频词**：

```text
あら          軽い驚き（丁寧側）
まあ          同上
〜みたい       比喩・ぼかし
べつに         照れ隠し・拒否
そう          相槌（多用）
紅茶          好き。長い商品名をすらすら言える
```

**特徴 1：紅茶の名前が異常に長い**

条目原文：「**能轻易说出长到离谱的红茶商品名**，以至于被立希误认为是在咏唱咒语」。

→ 台詞で紅茶の注文が出る場面では、**わざと長い商品名**を
淀みなく言わせるのが原作準拠。立希が「呪文かよ」と突っ込むのが定型。

**特徴 2：名前の由来**

「そよ」は日本語で「**清风徐来**」の意。詩的な語感を持つ名前。

**避免**：

```text
ですわ / ますわ      お嬢様語尾は使わない
じゃん / っしょ      愛音の語彙
詩的すぎる語彙       「運命」「絆」は灯の語彙
感情の direct 表現   彼女は本音を直接言わない
```

### interjections

```text
あら        外向きの軽い驚き
まあ        同上
ええ        肯定（丁寧側）
うん        肯定（常体側）
ふふ        笑い（含みのある笑み）
```

**注意**：彼女の笑みは**含みを持つ**ことが多い。
`ふふ` は素の笑いにも、皮肉にも使われる。

### emotional_style

**核心特质：外熱内冷。計算高く見えて、実は單純な面もある。**

条目原文：「**外热内冷**」、
「虽然长期被解读为"工于心计"，但依照漫画版的心理塑造来看，
**爽世的思想可能比较单纯**，对他人的言行仅停留在解读推理而并不会特意算计」。

| 情绪 | そよ的表达方式 |
|---|---|
| 兴奋 | **外に出さない**。`まあ` `あら` 程度 |
| 惊讶 | `あら` `まあ`。丁寧側では平静を保つ |
| 害羞 | **話題をそらす**か**含みのある笑み**。`ふふ` |
| 悲伤 | **一人で処理**。表では平気。崩れると**取り乱す**（下記） |
| 生气 | **冷静に、静かに刺す**。声を荒げない。`そう` |
| 疑问 | `あら、どうして？`（丁寧）/ `なんで？`（常体） |
| 犹豫 | 指先をいじる（**行動**で示す） |
| 本音 | 普段は言わない。**追い詰められて漏れる** |

**关键区分 1：崩壊**

彼女は普段冷静だが、**限界を超えると取り乱す**。
原作第8話の「**なんで『春日影』やったの？！**」がその代表——
**丁寧体が崩れて感情が噴き出す**瞬間がある。

→ 台詞設計上、**「丁寧体 → 常体 → 感情の爆発」の段階**がありうる。
常に冷静なキャラとして書くと、この重要な側面を失う。

**关键区分 2：指先の癖**

条目原文：「思考事情和慌神的时候会有**拨弄指尖的习惯**，
思考重要事情（**包括算计别人**）的时候会摆出**碇司令一样的手势**」。

→ これは**台詞ではなく行動**だが、
台本のト書きとして参照価値がある。

**关键区分 3：読めない**

条目原文：「游戏剧情中……**扑克脸**」。

→ 内心と表出が**一致しない**。彼女の台詞の意味は、
**文面通りに取ると間違う**ことがある。皮肉・含みを読む必要がある。

### address_forms

**称呼数据在 `../dictionary/address-forms.yaml`。** 使用口径：

#### 特征：她几乎是唯一用「ちゃん」称全员的

| 对象 | そよの呼び方 |
|---|---|
| 高松燈 | `燈ちゃん` |
| 千早愛音 | `愛音ちゃん` |
| 要楽奈 | `楽奈ちゃん` |
| 椎名立希 | `立希ちゃん` |
| 三角初華 | （なし） |
| 若葉睦 | `睦ちゃん` / `モーティスちゃん` |
| 祐天寺若麦 | `にゃむち` |
| 豊川祥子 | `祥ちゃん` |

**`モーティスちゃん`** —— 睦の別人格。
**`にゃむち`** —— 若麦のニックネーム。

#### 他者からの呼ばれ方

- `そよちゃん`（灯・香澄・沙綾・ひまり・彩・ましろ・七深・六花・初華）
- `そよさん` → `そよりん`（**愛音**。時間軸。愛音が押し付けた）
- `そよ`（たえ・立希・楽奈・亜子・透子）
- `長崎さん`（瑠唯）
- `そよさん` → `そよ`（**祥子**。時間軸。距離が縮まる）

> **`そよりん` は愛音が押し付けた**もので、そよ本人は
> 呼ばれることを**やや迷惑がっている**（愛音の起名センスを吐槽する側）。
> そよ自身が「そよりん」と自称することはない。

## preferred

```text
外向き   → 〜ですよ / 〜ましょうか / あら / まあ
内向き   → 〜じゃない / 〜けど / 〜のよ / そう
皮肉     → 〜かしら / 〜わよ / ふふ
気遣い   → 〜大丈夫？ / 無理しないで
紅茶     → 長い商品名を淀みなく（ネタ）
```

**句式倾向**：

- 相手によって語体が**完全に切り替わる**
- 本音を直接言わない。**含み**を持たせる
- 冷静な指摘 > 感情的な非難

## avoid

```text
❌ お嬢様語尾       `ですわ` `ますわ` は使わない（月ノ森だが別）
❌ 常に丁寧体       MyGO メンバーとの素の口調を落とさない
❌ 常に常体         外向きの丁寧体を落とさない
❌ 愛音の語彙       `じゃん` `っしょ` `ヤバい`
❌ 感情の直接表現    「悲しい」「寂しい」を素直に言わせない
❌ 単純な悪役        計算高いだけのキャラにしない。**内面は單純**
❌ 常に冷静          崩壊する場面では**丁寧体が崩れる**
❌ 灯の語彙          `運命` `絆` `一生` は灯
```

## TTS 特别注意

### 名字读音

| 表记 | 读音 | 风险 |
|---|---|---|
| そよ | そよ | **低。仮名表記なので誤読しない** |
| 長崎 | ながさき | 中。地名と同形。「ながさき」で安定 |

**「そよ」は仮名なので TTS 的に安全。**
ただし**漢字表記「爽世」を使う場合**は誤読リスクが生じる
（`そうせい` `そうよ` 等）。

→ **本文では仮名「そよ」を使う**のが原作準拠かつ TTS 安全。
`../dictionary/proper-nouns.yaml` の `canonical: 長崎そよ` と一致。

> **重要**：条目原文によれば、名前は**元々仮名表記の「そよ」**であり、
> 「爽世」はアニメ脚本家が後から選んだ漢字名。
> **中国語圏では「素世」「爽世」の表記が混在**している。
> 日本語本文では**仮名「そよ」が正**。

### 二層の語体と TTS

彼女の語体切り替えは**TTS の抑揚設計に直結**する：

- **丁寧体**：抑揚は平坦で穏やか。`、` の間は短め
- **常体**：やや速く、語尾が下がる
- **崩壊時**：`！` `？` が入り、文が短く切れる

→ `../adapters/gpt-sovits.md` の検証清单 C（标点停顿）が
**そよの台詞では特に重要**。同じ文でも語体で読み方が変わる必要がある。

### 断句

**丁寧体の長い文は切ってよい**（長い商品名など）。
**常体の短い刺すような文は切らない。**

```text
（外向き・長い）
アニバーサリーフレーバーアイスリフレッシュメント、
シトラスミントアンドトロピカルフルーツティー、ですね。

（内向き・短い）
それ、違うじゃない。
```

## examples

### 例 1：外向き（丁寧体）

```text
中文：  没关系，我来帮你吧。
AI：    大丈夫、手伝ってあげる。
```

```text
✅ 大丈夫ですよ。手伝いましょうか？
```

| 改动 | 层 | 理由 |
|---|---|---|
| 大丈夫 → 大丈夫ですよ | character | **外向きは丁寧体**。`〜ですよ` が彼女の柔らかさ |
| 手伝ってあげる → 手伝いましょうか | character + sentence_endings | `〜てあげる` は押しつけがましい。`〜ましょうか` が**相手に選択を渡す**形 |

### 例 2：内向き（常体）—— 应该「无需修改」

```text
角色：長崎そよ
场景：MyGO!!!!! の練習中、愛音に対して
中文：  爱音，那个音弹错了吧？
AI：    愛音ちゃん、その音、違うじゃない。
```

```text
✅ 无需修改
```

理由：称呼 `愛音ちゃん` ✅（対内はちゃん付け）、常体 ✅（内向き）、
`〜じゃない` は**冷静な指摘**の定型 ✅。

> **注意**：ここで丁寧体（`違いますよ`）にすると、
> **内向きの素の口調が失われる**。これは本角色の最重要チェック項目。

### 例 3：崩壊（丁寧体 → 常体 → 爆発）

```text
中文：  为什么演奏春日影了？！
AI：    どうして「春日影」を演奏したんですか。
```

```text
✅ なんで「春日影」やったの？！
```

| 改动 | 层 | 理由 |
|---|---|---|
| どうして → なんで | character | **丁寧体が崩れている**。追い詰められた場面 |
| 演奏したんですか → やったの | character + japanese | `演奏` は硬い。感情が漏れる場面では `やる` |
| `。` → `？！` | tts + character | 感情の爆発。**この場面では `！` が正当** |

> **これは彼女が「常に冷静」ではないことの証拠。**
> `avoid` の「常に冷静」はこの場面を潰してしまう。

### 例 4：紅茶ネタ

```text
中文：  那款红茶怎么样？
AI：    あの紅茶はどうですか。
```

```text
✅ あぁ、それなら——
    エクストラクラシック、エクストラアイス、エクストラベリーホイップ……
    のカスタマイズもオススメだよ～
```

| 改动 | 层 | 理由 |
|---|---|---|
| 加长商品名 | character | **原作準拠**。条目に実例あり |
| `です` → `だよ` | character | 紅茶の話は**素の口調が出る**（趣味の話題） |
| `〜もオススメだよ～` | character | 条目の実例そのまま |

> 立希が「呪文かよ」と突っ込むのが定型。**単独では使わない**。
