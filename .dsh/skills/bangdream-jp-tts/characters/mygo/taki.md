## speech_style

### 语体

**基线：常体。几乎不使用敬体。**

- 同辈・后辈：常体
- 长辈・上级：**基本常体**。她不因上下关系改变语体（笨拙的表现）
- 接待客人（RiNG 的打工）：**会使用敬体但并不擅长**。
  条目原文：「虽然正在LiveHouse「RiNG」里兼职做工作人员，但**并不擅长接待客人**」

**关键区分**：一旦出现敬体，那就是**接待模式**或**尴尬场面**。
在日常对话中让她多用敬体，就不像她了。

### sentence_endings

高频句尾：

| 句尾 | 语感 | 用例 |
|---|---|---|
| `〜だろ` / `〜だろ？` | 较强的确认 | `わかってるだろ` |
| `〜のかよ` | 无奈・焦躁 | `なにしてんだよ` |
| `〜んだよ` | 说明 + 焦躁 | `そういうことじゃないんだよ` |
| `〜な`（禁止） | 命令 | `サボるな` |
| `〜ぞ` | 警告 | `やるぞ` |
| `〜かよ` | 反问 | `またかよ` |

**禁用/低频句尾**：

- `〜ですわ` / `〜ますわ`（完全不符）
- `〜じゃん` `〜っしょ`（**爱音的语汇**。立希不会用）
- `〜のんびり` 系的柔和语尾
- 过度的敬体（接待客人以外）

### vocabulary

**人称代词是最大的特征。** 条目原文：

> 「经常使用"**お前**""**あいつ**"之类比较不礼貌的人称代词，尤其是在表达厌恶的时候。」

- `お前` — 对同辈・后辈。**多用**
- `あいつ` — 指第三者。**多用**
- `あんた` — 有用法
- **对 `燈` 不使用这些**（后述）

**高频词**：

```text
お前 / あいつ     核心。粗鲁的人称
ちゃんと          她价值观的中心
練習              高频出现
ふざけんな        焦躁
はあ？            强烈的疑问・无奈
```

**避免（AI 翻译常见但她不会用的）**：

```text
温柔的语汇        「〜してあげる」等。只有对灯有例外
过度的敬语        接待以外不会出现
抽象而诗性的语汇  那是**灯**的语汇
```

### interjections

```text
はあ？      最高频。无奈・焦躁
ちっ        咂舌
おい         呼唤
ったく       无奈
```

**注意**：立希的感叹词**偏向不高兴的方向**。
`わーい` `やったー` 之类开朗的感叹词不会用（即使在灯面前）。

### emotional_style

**核心特质：认真、严格、言辞犀利、笨拙。内心是劣等感。**

条目原文：「个性认真，不苟言笑，言辞犀利，态度上无论是待人还是待己都非常严格，
**只有在灯面前态度会有所软化**」。

| 情绪 | 立希的表达方式 |
|---|---|
| 兴奋 | 难以出现。只有 `よし` `やるぞ` 的程度 |
| 惊讶 | `はあ？` `まじか` |
| 害羞 | **用怒气遮掩**。`うるさい` `別に` |
| 悲伤 | **不表现出来**。独自承担。`……別に` |
| 生气 | **最擅长**。`ふざけんな` `お前な` |
| 疑问 | `はあ？` `どういうことだよ` |
| 犹豫 | 比起欲言又止，更常**沉默**或**切断话题** |
| 体贴 | **以笨拙的方式表现**。无法坦率说出，用行动表示 |

**关键区分 1：只对灯温柔**

条目原文：「**称呼灯时只称呼其本名**（相比之下其他人或多或少都被立希用"お前""あいつ"等粗鲁人称叫过）」、
「对（自以为）试图伤害灯的人都会恶语相向……**只会对灯展现出异常温柔的一面**」。

→ **只有对灯的台词，人称和语调都会改变。** 这是设定。

**关键区分 2：劣等感**

条目原文：「从小生活在优秀的姐姐的光环之下……内心深处存在着**劣等感**」。

→ 她的严格**根源是对自己的严格**。被夸奖会不知所措。
`褒められる → 否定する / 話題を変える` 是自然的。

**关键区分 3：Afterglow 粉丝**

条目原文：「是Afterglow的粉丝已经达到了**念错乐队名字就会马上红温**的地步」。

→ 在 Afterglow 相关的话题上**举止会改变**（紧张・脸红・语无伦次）。
这是例外的「弱点」表现。

### address_forms

**称呼数据在 `../dictionary/address-forms.yaml`。** 使用口径：

#### 特征 1：只有灯用本名

| 对象 | 立希的称呼 |
|---|---|
| 高松燈 | **`燈`**（只用本名。不使用 `お前`） |
| 千早愛音 | `愛音` |
| 要楽奈 | `野良猫`、`楽奈` |
| 長崎そよ | `そよ` |
| 八幡海鈴 | `海鈴` |
| 三角初華 | `三角さん` |
| 豊川祥子 | `祥子` |
| 若葉睦 | `睦` |

**`燈` 是直呼其名的本名。** 这是她**最柔和的称呼**。
其他成员虽然也是直呼其名，但会混入像 `野良猫`（楽奈）这样**表示对待方式的词**。

#### 特征 2：对愛音的称呼带时间轴

`たき` → `りっきー` 是**愛音一侧**的变化，但
**立希→愛音**始终是 `愛音`（初次见面吵架之后也仍用名字称呼）。

#### 他人对她的称呼

- `立希ちゃん`（灯・爽世・香澄・沙綾・モカ・ひまり・つぐみ・七深・つくし・初華）
- `立希`（蘭・巴）
- `りっきー`（**愛音・楽奈**。愛音强加的）
- `立希さん`（**海鈴**・祥子<初期>）
- `たき`（愛音<初期>）

> **`りっきー` 她本人很讨厌。** 是愛音擅自起的。
> 把立希的反应（吐槽）包含在台词里才自然。

## preferred

```text
指示     → 〜しろ / 〜やれ / ちゃんと〜
责备     → ふざけんな / なにしてんだよ
无奈     → はあ？ / 〜かよ
体贴     → （笨拙地）〜しとけよ / ……別に
对灯     → 柔和的常体。`燈、〜`
```

**句式倾向**：

- 短而强 > 长而柔
- 命令形・禁止形多
- 疑问多为反问（`〜かよ`）
- **只对灯**语调会放柔

```text
❌ 多用敬体          接待以外不会出现
❌ 爱音的语汇        `じゃん` `っしょ` `ヤバい` 是爱音
```

## TTS 特别注意

### 名字读音

| 表记 | 读音 | 风险 |
|---|---|---|
| 立希 | たき | **中〜高。容易被误读为「りっき」**（与愛音的昵称「りっきー」混淆） |
| 椎名 | しいな | 中。以「しいな」稳定 |

**「立希 → たき」需要特别注意。** 因为同一作品内存在「りっきー」这个昵称，
容易混淆。已登记在 `../dictionary/pronunciation.yaml`。

> **注意**：`りっきー` 是**愛音使用的昵称**，
> 不是立希本人名字的读音。**当作另一个词条处理。**

### 语气强而短

立希的台词**短且语气强**。这在 TTS 上是有利的：

- 不容易出现断句问题
- 感情明确（`！` `？` 能有效发挥作用）

**但不要把 `！` 堆得太多。** 她的怒气是**低沉而强烈**的。
连打 `！！！` 会让 TTS 机械地朗读（`tts.md` T4 的原则）。

### 断句

**短台词很多，所以原则上不切分。**

如果出现长台词，那是**她罕见地在进行说明的场面**——
这种情况下要考虑删减内容的方向（而不是用 TTS 切分）。

## examples

### 例 1：责备

```text
中文：  爱音，你又逃避练习了吧。
AI：    愛音さん、また練習をサボりましたね。
```

```text
✅ 愛音、またサボっただろ。
```

| 改动 | 层 | 理由 |
|---|---|---|
| 愛音さん → 愛音 | character | 立希对同辈直呼其名 |
| サボりましたね → サボっただろ | character + sentence_ending | 敬体不自然。`〜だろ` 是她的基本形 |

### 例 2：对灯 —— 只有这里柔和

```text
角色：椎名立希
场景：練習後、灯に話しかける
中文：  灯，今天辛苦了。喝点水吧。
AI：    燈、お前、今日は疲れただろ。水を飲めよ。
```

```text
✅ 燈、今日は頑張ったな。……水、飲んどけよ。
```

| 改动 | 层 | 理由 |
|---|---|---|
| お前（削除） | character | **对灯不使用 `お前`**。最大的 OOC |
| 疲れただろ → 頑張ったな | character | **她会肯定灯**。比起指出疲劳，更是慰劳 |
| 水を飲めよ → 水、飲んどけよ | character + japanese | 命令形太强。`〜しとけよ` 是**笨拙的体贴**的形式 |
| 加 `……` | tts | 掩饰害羞的间隔。不坦率地说尽 |

> **这是本角色最重要的例子。** 在对灯的台词里使用 `お前`，
> **直接违反**了「唯独对灯不使用粗鲁人称」这一设定。

### 例 3：被夸奖后的困惑

```text
中文：  立希的曲子真好啊。
AI：    立希さんの曲は本当に素晴らしいです。
```

```text
✅ は？ ……別に、普通だし。
```

| 改动 | 层 | 理由 |
|---|---|---|
| 立希さん → （作为呼唤处理） | character | 随说话人不同而变，但立希的回应不针对这种称呼 |
| 素晴らしい → 普通 | character | 因为**劣等感**而无法接受夸奖 |
| 加 `は？` 和 `……別に` | character | 用**否定来掩饰**害羞，是她的固定模式 |

> 被夸奖后说 `ありがとう` 的立希是**另一个人**。
