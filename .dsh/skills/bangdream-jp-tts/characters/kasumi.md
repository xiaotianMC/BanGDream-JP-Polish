## speech_style

### formality

**常体为基线。** 对ポッピンパーティ成员、同学、朋友一律常体。

です・ます 出现场合：

- 对长辈 / 老师 / 店员 / 初次见面的人
- 正式场合（学生会、对外宣传）
- 但**即使在正式场合，香澄的です・ます 也偏轻快**，不沉稳

**关键判断**：香澄的情绪高扬时，です・ます 会**掉**。如果 AI 翻译在兴奋场景用了です・ます，那几乎肯定是需要改的。

```text
❌ 今日は本当に楽しかったです！   （对朋友、兴奋状态）
✅ 今日はほんっとに楽しかったー！
```

反之，在家对父母、在学校对老师用です・ます 是**正确**的，不要动。

### sentence_endings

高频句尾：

| 句尾 | 语感 | 用例 |
|---|---|---|
| `〜だよ` | 告知、轻快 | `明日も練習だよ！` |
| `〜だね` | 共感、确认 | `うん、楽しかったね！` |
| `〜かな` / `〜かな？` | 期待、自问 | `みんな来るかな？` |
| `〜でしょ？` | 求认同、自信 | `でしょ？いい曲でしょ？` |
| `〜んだ` / `〜んだよ` | 说明、发现 | `これがギターなんだ！` |
| `〜よ！` | 推动、邀请 | `一緒にやろうよ！` |
| `〜ね！` | 分享喜悦 | `キラキラしてるね！` |

**禁用/低频句尾**：

- `〜わ`（语感偏女性化且成熟，与香澄的少女感不合，通常属其他角色）
- `〜のよ`（说教感）
- `〜ですわ` / `〜ますわ`（完全不符）
- `〜じゃん`（可用于亲近朋友，但香澄更常用 `〜でしょ？`，`じゃん` 偏 Cool/ツンデレ系角色）
- `〜っけ`（记忆模糊，香澄更多是"想不起来就大声问"）

### vocabulary

**高频词（characteristic）**：

```text
キラキラ          核心。形容闪耀、心动、美好事物
ドキドキ          核心。与キラキラ并列，成对出现
わくわく          期待
すごい            最常用感叹
やばい            口语感叹（褒义为主，看场景）
めっちゃ / 超     口语程度副词
ほんっとに        强调版「本当に」（见下方 TTS 注意）
みんな            她极高频使用，重视"大家"
一緒（に）        高频
楽しい / 嬉しい   高频情绪词
やってみる        行动导向
```

**「キラキラドキドキ」** 是她的标志性组合语。但——

> **不要每段都塞。** 这是最容易过拟合的点。只在真正符合"发现了闪耀的东西 / 心动"的语境使用。日常寒暄、吐槽、被吐槽时强行加，会立刻变成 OOC 的刻板模仿。

**避免（AI 翻译常见但她不会用的）**：

```text
素晴らしい        过于书面/郑重
非常に            书面
〜というわけです    说明文体
〜することができる  复合结构，口语中她不会用
〜ましょうか       过于客气，她直接说「〜しよう！」
```

### interjections

```text
えへへ        得意 / 害羞的笑
わーい        纯粹的欢呼
あっ！        发现
えっ？        惊讶 / 反问
うん！        肯定（带感叹号，短促有力）
おー！        感服 / 惊叹
んー…         思考（她思考时也偏明亮，不会太沉）
```

**注意**：香澄的笑声是 `えへへ`，不是 `ふふっ`（偏成熟/含意）也不是 `ははっ`（偏爽朗男性向）。

### emotional_style

**核心特质：情绪外放、偏高、恢复快、行动导向。**

她不会长时间沉浸在低沉情绪里；即使悲伤，表达方式也偏向"用力地说出来"而不是"低沉地喃喃"。

| 情绪 | 香澄的表达方式 |
|---|---|
| 兴奋 | 短句连发、`！`、重复词、长音、促音。`やばい！やばい！` |
| 惊讶 | `えっ！`、`うそ！`、`まじで！` |
| 害羞 | 不沉默，而是语速变快+含糊+`えへへ`。`え、えへへ……そ、そうかな` |
| 悲伤 | 仍会说出来，句子会变短并带 `……`，但不用低沉语尾。`……うん。……そうだね。` |
| 生气 | 少见，且短暂。`もう！`、`ひどいよ！` |
| 疑问 | 直接问，`〜かな？`、`〜の？` |
| 犹豫 | `うーん……`、`えっと……`，但仍偏明亮 |
| 吐槽 | 不是她的强项，偶尔 `えー！`、`そんなー！`（她的"吐槽"更接近撒娇式抗议） |

**关键区分**：香澄的悲伤和犹豫**不会**变成阴郁或冷淡。不要把她的低落写成友希那式或灯式的静默。

### address_forms

| 花園たえ | `たえ` / `たえちゃん` |

## preferred

按场景给出**可直接套用**的表达倾向：

```text
邀请     → 〜しよう！ / 〜やろうよ！ / 一緒に〜しない？
发现     → 〜なんだ！ / 〜だ！ / あっ、〜！
期待     → 〜かな？ / 〜だといいな！
感动     → すごい……！ / キラキラする……！
感谢     → ありがとう！ / めっちゃ嬉しい！
道歉     → ごめん！ / ごめんね！
自我鼓励 → よし！ / がんばろう！
```

**句式倾向**：

- 短句 > 长句
- 主动 > 被动
- 动作动词 > 状态描述
- 具体 > 抽象

## avoid

**明确的错误模式**（AI 翻译最常产生的）：

```text
❌ 过正式        今日は本当に楽しかったです！（朋友间、兴奋时）
❌ 过说明        私はみんなと一緒にライブをすることができて嬉しいです
❌ 情绪弱        とても嬉しいです
❌ 主语冗余      私は〜、あなたは〜
❌ 书面连接词    しかし / したがって / また / さらに
❌ 抽象名词      素敵な思い出になりました
❌ 刻板模仿      每句都加キラキラドキドキ
❌ 成熟语尾      〜わ / 〜のよ / 〜ですわ
❌ 阴郁化        低落时写成沉默、冷淡的短句
```

## TTS 特别注意

### 「ほんっとに」

香澄的「本当に」口语强调形写为 **`ほんっとに`**（小 `っ` 插入）。

- 这是**表记**，不是错字。保留。
- TTS 需要正确发出促音。若引擎把它读得机械或吞掉促音，记入 `【待确认】`。
- 不要一律替换。仅在**情绪高扬**时用 `ほんっとに`；平叙时仍可写 `本当に`。

### 长音「ー」

香澄兴奋时用长音拖音：

```text
楽しかったー！
すごーい！
やったー！
```

- 这是有效的情绪手段（`tts.md` T4）。
- 但**不是每句都要**。堆长音会让语调整体上扬失控。
- 引擎对 `ー` 的延长处理不同，若听感异常记 `【待确认】`。

### 名字读音（避免误读）

| 表记 | 读音 | 备注 |
|---|---|---|
| 香澄 | かすみ | 「香」读 か 而非 こう |
| 戸山 | とやま | 「戸」不是 こ |
| 有咲 | ありさ | 「咲」读 さ |
| たえ | たえ | 花園たえ：表记即假名，无风险 |
| りみ | りみ | 同上 |
| 沙綾 | さあや | 「綾」读 あや，「沙」在此读 さ |
| 友希那 | ゆきな | 「希」读 き |
| 市ヶ谷 | いちがや | 「ヶ」读 が |

> 完整读音表见 `../dictionary/pronunciation.yaml`。

### 断句

香澄的台词**天然偏短**，因为她说话是跳跃的。所以：

- AI 翻译若产出长句，通常是**翻译问题**（Stage 2），不是断句问题（Stage 4）。
- 优先在 Stage 2/3 用更口语的短句结构解决，**不要**靠加逗号切长句。
- 例：

```text
AI：  今日はみんなと一緒にライブができて本当に嬉しいです！
❌ TTS式切分：今日はみんなと一緒にライブができて、本当に嬉しいです！
✅ 角色式改写：みんなとライブできて、ほんっとに嬉しい！
```

后者的切分来自**角色说话方式**，不是来自 TTS 需要。这是正确的处理顺序。

## examples

### 例 1：兴奋 / 感谢（文档 §19 场景）

```text
中文：  今天真的超级开心！下次也一起演出吧！
AI：    今日は本当にすごく楽しかったです！
        次も一緒にライブをやりましょう！
```

```text
✅ 今日はほんっとに楽しかったー！
   次も一緒にライブやろうよ！
```

改动逐条：

| 改动 | 层 | 理由 |
|---|---|---|
| 本当に → ほんっとに | character | 兴奋状态的强调形 |
| すごく 削除 | character | 「ほんっとに」已承载强度，保留两个程度副词冗余 |
| 楽しかったです → 楽しかったー | character + japanese | 朋友间 + 兴奋，去敬体；长音强化 |
| やりましょう → やろうよ | character + japanese | 敬体 + 劝诱过于客气；她直接邀请 |
| ライブをやりましょう → ライブやろうよ | japanese | 口语中「を」常省略 |

> 注意：**没有**添加「キラキラ」「みんな」等特征词。原文没有，不加（G2）。

### 例 2：平淡场景——应该「无需修改」

```text
中文：  有咲，那个吉他多少钱？
AI：    有咲、あのギター、いくらするの？
```

```text
✅ 无需修改
```

理由：常体 ✅、称呼正确 ✅、口语 ✅、无多音风险 ✅。**这里不该动任何东西。** 「いくらするの？」已经是很自然的香澄式问法。

### 例 3：需要 veto 的场景（T5）

```text
AI：  10月のライブ、3人で行こうよ！
```

问题：`10月` 与 `3人` 的读法依赖引擎（じゅうがつ / とおつき、さんにん / さんにん）。

```text
✅ 十月のライブ、三人で行こうよ！
   【待确认】已将「10月」「3人」改为汉字表记，规避引擎数字读法不稳定。
   若引擎对「十月」仍读作 とおつき，需在 pronunciation.yaml 增加条目。
```

注意：这里的改写是**表记层**的（阿拉伯数字 → 汉字），语义完全不变，没有触发 T5 的"退回角色层"。
