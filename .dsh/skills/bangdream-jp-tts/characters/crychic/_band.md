## 解散的经过（出典 `经历` 节）

**整个故事的起点**。按时间顺序整理。已确认出典（CRYCHIC）与
祥子・睦的条目中的记述一致。

| 时期 | 事件 |
|---|---|
| 初三 | **祥子的母亲・瑞穂病逝**。祥子受到巨大打击 |
| — | 在音乐祭上看到 Morfonica 后结成。创作出与 Morfonica 相似的**唯一的原创曲** |
| — | 在初演中演奏 **《春日影》**。完成度很好 |
| 之后 | **祥子逐渐淡出，开始缺席练习** |
| 6 月初 | **大雨之日**。从警察那里领回父亲的祥子**浑身湿透**出现在录音室，**宣布退团** |
| 同时 | **睦发言「自己其实并不喜欢乐队」** |
| 紧接其后 | **燈受到巨大打击**而淡出 → **立希退团** |
| 结果 | 剩下的睦和そよ无法维持，**实质解散** |

**祥子的家庭状况**（出典是作为动画《Ave Mujica》的内容记述的）：

- 父亲 **豊川清告** 遭遇**土地诈骗**，给豊川集团造成重大损失。
- 此外，清告**说服豊川定治将三角初音迎入豊川家**，因此
  清告**被逐出家族**，沉溺于酒。
- 祥子**为了追随父亲而放弃豊川家的财产**，为补贴家计
  在各处**偷偷打工**，同时照顾颓废的父亲。
  → **失去了出席活动的时间**。

> ⚠️ **`三角初音` 与 `三角初華` 是同一人物**（用户确认 2026-02-14）。
> 本名是 `三角初音`，表舞台之名是 `三角初華`（借用妹妹的名字）。
> → **正文统一为 `三角初華`**。详情见 `../ave-mujica/uika.md`。
> 出典（CRYCHIC）写作「三角初音」是因为**指的是本名那一方**。

**后日谈**（出典 `经历` 节）：

- 高一秋冬，**そよ造访了祥子父亲那荒废的住所**，
  **发现了**祥子父亲造成损失的**新闻**。其发布日期正是
  **CRYCHIC 初演的同一日**。→ **MyGO!!!!! 的成员们得知了当时的退团理由**。
- 睦本来的人格稳定之后，**そよ和立希得知了睦讨厌乐队的理由**
  ——**只是单纯觉得自己的吉他弹得差**而已。
- 5 人心结解开之后，**在 MyGO!!!!! 出演前的彩排时间里，
  5 人演奏了《想要成为人类之歌II》和《春日影》**。
- 此后，**祥子为了「让睦幸福」，向燈・立希・そよ
  提出 CRYCHIC 再结成**，但**反应冷淡**。
- 睦也去邀请燈，但**与第二人格モーティス发生冲突**。
  最终祥子实现了アヴェムジカ的再结成，**CRYCHIC 的故事就此结束**。

> ⚠️ **`经历` 节对睦的人格描写很复杂，本抽取未能把握全貌。**
> 关于モーティス的记述，与 `../ave-mujica/mutsumi.md` 的
> 「别的人格语体未确认」一并处理。

## 乐队名的由来（出典 `简介` 节）

| 要素 | 出典的记述 |
|---|---|
| `cry` | **呐喊** |
| `chic` | **优雅** |
| 颜色 | 名称中的 **`ry` 是浅蓝**、**`hi` 是浅绿** |
| 发音 | **`クライシック`**。**与 `CLASSIC`（`クラシック`）的片假名相近** → **祥子提出时，睦听错了** |
| LOGO | 大小不同的**3 个同心 C** + 其下方的**一滴泪**。3 个 C 表示 CRYCHIC 的 3 个 C |
| 偶然 | 开头 3 个字母 **`C` `R` `Y`** 与**《春日影》的拼音首字母**（Chūn Rì Yǐng）一致 |

> ★ **「睦听错了」是可用的素材**。若要写成台词，
> 可以写成 **クライシック / クラシック** 的听错。
> 不过**出典明确记载的只有「提出时睦误解了」这一点**，
> 并没有写对话的内容。**不要擅自还原对话**。
