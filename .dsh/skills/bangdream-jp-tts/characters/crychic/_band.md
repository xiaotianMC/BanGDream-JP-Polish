## 解散の経緯（出典 `经历` 節）

**物語全体の起点**。時系列順に整理する。出典（CRYCHIC）と
祥子・睦の項目で記述が一致していることを確認済み。

| 時期 | 出来事 |
|---|---|
| 初三 | **祥子の母・瑞穂が病死**。祥子は大きな打撃を受ける |
| — | 音楽祭で Morfonica を見て結成。Morfonica に似た**唯一のオリジナル曲**を作る |
| — | 初演で **《春日影》** を演奏。良い出来だった |
| その後 | **祥子が次第にフェードアウトし、練習を欠席**するようになる |
| 6月初 | **大雨の日**。警察から父を引き取ってきた祥子が**全身濡れたまま**録音室に現れ、**脱退を宣言** |
| 同時 | **睦が「自分は実はバンドが好きではなかった」と発言** |
| 直後 | **燈が大きな打撃を受け**フェードアウト → **立希が脱退** |
| 結果 | 残った睦とそよでは維持できず、**実質的に解散** |

**祥子の家庭事情**（出典はアニメ《Ave Mujica》の内容として記述）：

- 父 **豊川清告** が**土地詐欺**に遭い、豊川グループに重大な損失。
- さらに清告が**豊川定治に三角初音を豊川家へ迎えるよう説得**したことから、
  清告は**家族を追われ**、酒に溺れる。
- 祥子は**父に従うため豊川家の財産を放棄**し、家計を助けるため
  あちこちで**内緒のアルバイト**をしながら荒んだ父の世話をしていた。
  → **活動に出席する時間がなくなった**。

> ⚠️ **`三角初音` の扱いに注意。**
> 出典（CRYCHIC）は「父が定治に**三角初音**を豊川家へ迎えるよう説得した」と書く。
> `../ave-mujica/uika.md` の記録では **三角初華 / 三角初音 は
> 同一人物の二重名義**である。
> → **どちらの表記を使うかは未確定**。この場面の台詞は【待确认】に出す。

**後日談**（出典 `经历` 節）：

- 高一の秋冬、**そよが祥子の父の荒れた住居を訪ね**、
  祥子の父が損失を出した**ニュースを発見**。その配信日が
  **CRYCHIC の初演と同じ日**だった。→ **MyGO!!!!! の面々が当時の脱退理由を知る**。
- 睦の本来の人格が安定した後、**そよと立希は睦がバンドを嫌っていた理由を知る**
  ——**単に自分のギターが下手だと思っていただけ**だった。
- 5 人が心結を解いた後、**MyGO!!!!! の出演前のリハーサル時間に、
  5 人で《想要成为人类之歌II》と《春日影》を演奏**した。
- その後、**祥子が「睦を幸せにするため」に燈・立希・そよへ
  CRYCHIC 再結成を打診**するが、**反応は薄かった**。
- 睦も燈を誘うが、**第二人格モーティスと衝突**。
  最終的に祥子はアヴェムジカの再結成を果たし、**CRYCHIC の物語は終わる**。

> ⚠️ **`经历` 節の睦の人格描写は複雑で、本抽出では全体像が掴めていない。**
> モーティスに関する記述は `../ave-mujica/mutsumi.md` の
> 「別人格の語体は未確認」と併せて扱う。

## バンド名の由来（出典 `简介` 節）

| 要素 | 出典の記述 |
|---|---|
| `cry` | **呐喊** |
| `chic` | **优雅** |
| 色 | 名称中の **`ry` は浅藍**、**`hi` は浅緑** |
| 発音 | **`クライシック`**。**`CLASSIC`（`クラシック`）と片仮名が近い** → **祥子の提案時、睦が聞き間違えた** |
| ロゴ | 大きさの異なる**3 つの同心の C** + その下の**一滴の涙**。3 つの C は CRYCHIC の 3 つの C を表す |
| 偶然 | 先頭 3 字 **`C` `R` `Y`** は**《春日影》のピンイン頭文字**（Chūn Rì Yǐng）と一致 |

> ★ **「睦が聞き間違えた」は使える小ネタ**。台詞にするなら
> **クライシック / クラシック**の取り違えとして書ける。
> ただし**出典が明記するのは「提案時に睦が誤解した」ことのみ**で、
> 会話の中身は書かれていない。**勝手に会話を復元しない**。
