## speech_style

### 定位：生真面目・完璧主義。ツンデレの変種

条目原文：
- 「**认真而又神经质，不知道取巧的性格**。
  属于**过于认真反而容易吃亏**的类型」
- 「生活态度认真，**做一件事的时候一定要做得最好**，
  而为了达到这个目标会**不断磨练**」
- 「认为参加乐团的动力不应该是"**兴趣**"，而是"**成绩**"。
  **对自己和队友的要求都非常高，决不妥协**」
- 「与友希那同为乐队的**强硬派**」

→ キーワードは **「生真面目」「完璧主義」「决不妥协」「不器用」**。

### ★ 敬語の使い方が本角色の識別点

**バンド内で唯一、メンバーに「名字 + さん」を使う**（称呼一览で確認）：

| 対象 | 紗夜の称呼 | 語体 |
|---|---|---|
| 湊友希那 | `湊さん` | 丁寧体 |
| 今井リサ | `今井さん` | 丁寧体 |
| 宇田川あこ | `宇田川さん` | 丁寧体 |
| 白金燐子 | `白金さん` | 丁寧体 |

→ **バンド内で最も距離を置く呼び方**。
ただし条目は「与友希那同为乐队的**强硬派**」とも書く——
**冷たさではなく、同格のプロ同士の緊張**。

**バンド外では名字 + さん が基本**（`弦巻さん` `瀬田さん` `北沢さん` `松原さん`
`奥沢さん` `倉田さん` `桐ヶ谷さん` `二葉さん` `朝日さん` `マスキングさん` `チュチュさん` `高松さん`）。

### ★ 妹 日菜 だけが例外

`おねーちゃん` と呼ばれ、紗夜は**日菜を特別扱い**する（`姐妹` 節が独立）。

条目原文：
- 「最早只是为了**证明自己有比天才双胞胎妹妹日菜强大之处**开始弹吉他。
  **"我只有吉他了！！！"**」
- 「靠几乎日夜不停的努力取得了高超的吉他技术……
  被同队的友希那称为**自己作曲时的指针**」
- 「但曾被失望的自己吐槽为**"除了准确一无所有的无聊的声音"**」

→ **劣等感の源泉が妹**。`taki.md` の姉への劣等感と構造が似ているが、
紗夜の場合は**双子**という点が重要（比較が直接）。

### vocabulary

**条目可确证**：

```text
成績 / 興味         ★ 彼女の価値判断の軸（「兴趣ではなく成绩」）
正確さ              彼女が最も重視するもの
練習                頻出
犬                  ★ 犬派（「花咲川的狂犬」と呼ばれることも）
ポテト（フライドポテト） ★ 実は好き。隠している
```

**★ 犬派（猫派の友希那と対照）**

条目原文：
- 「**相对来说喜欢狗**。在故事初期就爱看狗狗节目。
  对狗有一定的了解，**能说出在商店街看到的小狗的品种**」
- 「在点击对话里说"如果要问我是犬派还是猫派，我的回答是**犬派**。"
  本人也有被一些玩家称作"**花咲川的狂犬**"。**和猫派的自家主唱形成对比**」
- 「第三季第六话中友希那：这是猫饼干？ 纱夜（怒）：**这是狗，虽然也有猫**」

→ **友希那が猫派、紗夜が犬派**。この対比は台詞に使える具体的な材料。

**★ ポテト好きを隠す**

条目原文：
- 「虽然不好意思承认，但其实**很喜欢垃圾食品，尤其是薯条**」
- 「纱夜先是劝诫巴"过量的盐分摄入对身体不好"，
  然后又**很诚实地问了巴"那家店在哪"**」
- 「剧情里若干次出现了纱夜因为**被队友发现喜欢吃薯条而害羞（傲娇）**的情节」
- 「燐子看见纱夜"**像审查员一样以好认真的表情在吃薯条**"」

→ **「説教 → でも気になる」のパターン**が定型。
`arisa.md` のツンデレと同種だが、**食べ物に限定**されている。

### emotional_style

**核心：生真面目。感情より基準で動く。**

| 情绪 | 紗夜の表达方式（依据等级） |
|---|---|
| 興奮 | 低（推断）。音楽の話で熱くなる（友希那と共通） |
| 惊讶 | 低（推断） |
| 害羞 | **条目に根拠**：ポテト好きを指摘されると照れる |
| 悲伤 | 低（推断）。**弱みを見せない** |
| 生气 | **条目に根拠**：基準を破る相手には厳しい |
| 疑問 | 低（推断） |
| 犬 | **饒舌になる**（条目根拠） |

**关键区分 1：説教と本音のギャップ**

条目原文の定型：「過量の塩分は体に悪い」と言った直後に
「**那家店在哪**」と聞く。

→ **この二段構えが彼女の話し方**。
建前（健康）→ 本音（食べたい）。

```text
✅ 「……塩分の摂りすぎは良くない。で、その店はどこだ」
```

**关键区分 2：NFO（ゲーム）にハマっている**

条目原文：
- 「在**被燐子和亚子邀请玩网络游戏"Neo Fantasy Online"** 创建角色时
  选的职业是**防御系的坦克**」
- 「尽管**本人极力否认**，但还是被发现**时常会登录游戏**」
- 「**一直没有弃坑**，还会积极参加 NFO 相关的线下活动，
  甚至**走火入魔到比燐子和亚子更快刷完副本**」
- 「卡面剧情甚至**直接邀请燐子一起玩游戏**」

→ **否定しながらハマる**。これも「説教と本音」と同じ構造。

**关键区分 3：雨女**

条目原文：「似乎有**雨女体质**，从小想参加什么活动的时候，天气就会变差」
「曾一度因此拒绝了香澄、心、巴、美咲等人让她一起参加庙会的请求
**最后架不住大家盛情相劝还是参加了**」。

→ **誘いを断るが押しに弱い**。

## preferred

```text
説教     → 基準を示す。曖昧にしない
本音     → 説教の直後に漏れる（二段構え）
犬       → 饒舌。品種まで語る
ゲーム   → 否定しつつ実は詳しい
音楽     → 正確さに言及
```

## examples

### 例 1：説教と本音の二段構え

```text
角色：冰川纱夜
场景：宇田川巴がハンバーガーの話をする
中文：  过量的盐分对身体不好。……那家店在哪里？
AI：    過剰な塩分は体に良くありません。……あの店はどこですか？
```

```text
✅ 塩分の摂りすぎは良くないぞ。……で、その店はどこだ。
```

| 改动 | 层 | 理由 |
|---|---|---|
| 〜ません → 〜ないぞ | character | **あこは後輩**。常体 + 軽い説教 |
| 〜ですか → 〜だ | character | 常体 |
| 加 `で、` | character | ★ **二段構えの接続**。本音が出る瞬間 |

> 条目原文の定型：説教 → 「那家店在哪」。
> **この落差が彼女の話し方**。

### 例 2：犬の話題で饒舌

```text
角色：冰川纱夜
场景：商店街で犬を見る
中文：  那是柴犬。毛色很漂亮。
AI：    あれは柴犬です。毛並みがきれいですね。
```

```text
✅ あれは柴犬だ。毛並みがいい。……ちゃんと手入れされてる。
```

| 改动 | 层 | 理由 |
|---|---|---|
| 〜です → 〜だ | character | 常体 |
| 加 `……ちゃんと手入れされてる` | character | **饒舌モード**。品種だけで終わらない |
| 〜ですね → 削除 | character | 愛想を作らない |

> 条目原文：「能说出在商店街看到的小狗的品种」。
> **犬の話では彼女が一番喋る**。

### 例 3：ゲームを否定しつつ詳しい

```text
角色：冰川纱夜
场景：NFO の話
中文：  我没在玩那种游戏。……那个副本的攻略法的话，我知道。
AI：    私はそのようなゲームはしていません。……そのダンジョンの攻略法なら知っています。
```

```text
✅ 私はそういうゲームはやらない。……あのダンジョンの攻略なら、知ってるが。
```

| 改动 | 层 | 理由 |
|---|---|---|
| 〜していません → やらない | character | 常体。**否定を強く** |
| 〜知っています → 知ってるが | character | ★ **否定しつつ詳しい**。`が` で言い淀む |
| `……` を保持 | tts + character | 矛盾を自覚している間 |

> 条目原文：「尽管本人极力否认，但还是被发现时常会登录游戏」。
