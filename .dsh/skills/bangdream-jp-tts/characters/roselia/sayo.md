## speech_style

### 定位：一本正经・完美主义。傲娇的变种

条目原文：
- 「**认真而又神经质，不知道取巧的性格**。
  属于**过于认真反而容易吃亏**的类型」
- 「生活态度认真，**做一件事的时候一定要做得最好**，
  而为了达到这个目标会**不断磨练**」
- 「认为参加乐团的动力不应该是"**兴趣**"，而是"**成绩**"。
  **对自己和队友的要求都非常高，决不妥协**」
- 「与友希那同为乐队的**强硬派**」

→ 关键词是 **「生真面目」「完璧主義」「决不妥协」「不器用」**。

### ★ 敬语用法是本角色的识别点

**是乐队内唯一对成员使用「名字 + さん」的人**（已在称呼一览中确认）：

| 对象 | 紗夜の称呼 | 语体 |
|---|---|---|
| 湊友希那 | `湊さん` | 敬体 |
| 今井リサ | `今井さん` | 敬体 |
| 宇田川あこ | `宇田川さん` | 敬体 |
| 白金燐子 | `白金さん` | 敬体 |

→ **是乐队内最有距离感的称呼方式**。
不过条目也写着「与友希那同为乐队的**强硬派**」——
**这不是冷淡，而是同级别专业人士之间的紧张感**。

**乐队外则以 名字 + さん 为基本**（`弦巻さん` `瀬田さん` `北沢さん` `松原さん`
`奥沢さん` `倉田さん` `桐ヶ谷さん` `二葉さん` `朝日さん` `マスキングさん` `チュチュさん` `高松さん`）。

### ★ 只有妹妹 日菜 是例外

被称呼为 `おねーちゃん`，紗夜**对日菜特别对待**（`姐妹` 节独立）。

条目原文：
- 「最早只是为了**证明自己有比天才双胞胎妹妹日菜强大之处**开始弹吉他。
  **"我只有吉他了！！！"**」
- 「靠几乎日夜不停的努力取得了高超的吉他技术……
  被同队的友希那称为**自己作曲时的指针**」
- 「但曾被失望的自己吐槽为**"除了准确一无所有的无聊的声音"**」

→ **自卑感的来源是妹妹**。与 `taki.md` 中对姐姐的自卑感结构相似，
但紗夜的情况**双胞胎**这一点很重要（比较更直接）。

**★ 犬派（与猫派的友希那形成对照）**

条目原文：
- 「**相对来说喜欢狗**。在故事初期就爱看狗狗节目。
  对狗有一定的了解，**能说出在商店街看到的小狗的品种**」
- 「在点击对话里说"如果要问我是犬派还是猫派，我的回答是**犬派**。"
  本人也有被一些玩家称作"**花咲川的狂犬**"。**和猫派的自家主唱形成对比**」
- 「第三季第六话中友希那：这是猫饼干？ 纱夜（怒）：**这是狗，虽然也有猫**」

→ **友希那是猫派，紗夜是犬派**。这个对比是可用于台词的具体材料。

**★ 隐瞒喜欢薯条**

条目原文：
- 「虽然不好意思承认，但其实**很喜欢垃圾食品，尤其是薯条**」
- 「纱夜先是劝诫巴"过量的盐分摄入对身体不好"，
  然后又**很诚实地问了巴"那家店在哪"**」
- 「剧情里若干次出现了纱夜因为**被队友发现喜欢吃薯条而害羞（傲娇）**的情节」
- 「燐子看见纱夜"**像审查员一样以好认真的表情在吃薯条**"」

→ **「説教 → でも気になる」的模式**已成定式。
与 `arisa.md` 的傲娇同种，但**限定在食物上**。

**关键区分 1：说教与真心话的落差**

条目原文的定式：说完「過量の塩分は体に悪い」之后立刻
就问「**那家店在哪**」。

→ **这种两段式就是她的说话方式**。
场面话（健康）→ 真心话（想吃）。

```text
✅ 「……塩分の摂りすぎは良くない。で、その店はどこだ」
```

**关键区分 2：沉迷 NFO（游戏）**

条目原文：
- 「在**被燐子和亚子邀请玩网络游戏"Neo Fantasy Online"** 创建角色时
  选的职业是**防御系的坦克**」
- 「尽管**本人极力否认**，但还是被发现**时常会登录游戏**」
- 「**一直没有弃坑**，还会积极参加 NFO 相关的线下活动，
  甚至**走火入魔到比燐子和亚子更快刷完副本**」
- 「卡面剧情甚至**直接邀请燐子一起玩游戏**」

→ **一边否定一边沉迷**。这也与「説教と本音」是同样的构造。

**关键区分 3：雨女**

条目原文：「似乎有**雨女体质**，从小想参加什么活动的时候，天气就会变差」
「曾一度因此拒绝了香澄、心、巴、美咲等人让她一起参加庙会的请求
**最后架不住大家盛情相劝还是参加了**」。

→ **会拒绝邀约，但经不住别人强推**。

## examples

### 例 1：说教与真心话的两段式

```text
角色：冰川纱夜
场景：宇田川巴がハンバーガーの話をする
中文：  过量的盐分对身体不好。……那家店在哪里？
AI：    過剰な塩分は体に良くありません。……あの店はどこですか？
```

```text
✅ 塩分の摂りすぎは良くないぞ。……で、その店はどこだ。
```

| 改动 | 层 | 理由 |
|---|---|---|
| 〜ません → 〜ないぞ | character | **あこ是后辈**。常体 + 轻微的说教 |
| 〜ですか → 〜だ | character | 常体 |
| 加 `で、` | character | ★ **两段式的连接**。真心话出现的瞬间 |

> 条目原文的定式：说教 → 「那家店在哪」。
> **这个落差就是她的说话方式**。

### 例 2：聊狗的话题时饶舌

```text
角色：冰川纱夜
场景：商店街で犬を見る
中文：  那是柴犬。毛色很漂亮。
AI：    あれは柴犬です。毛並みがきれいですね。
```

```text
✅ あれは柴犬だ。毛並みがいい。……ちゃんと手入れされてる。
```

| 改动 | 层 | 理由 |
|---|---|---|
| 〜です → 〜だ | character | 常体 |
| 加 `……ちゃんと手入れされてる` | character | **饶舌模式**。不会只讲品种就结束 |
| 〜ですね → 削除 | character | 不刻意讨好 |

> 条目原文：「能说出在商店街看到的小狗的品种」。
> **聊狗的话题时她话最多**。

### 例 3：一边否定游戏一边很了解

```text
角色：冰川纱夜
场景：NFO の話
中文：  我没在玩那种游戏。……那个副本的攻略法的话，我知道。
AI：    私はそのようなゲームはしていません。……そのダンジョンの攻略法なら知っています。
```

```text
✅ 私はそういうゲームはやらない。……あのダンジョンの攻略なら、知ってるが。
```

| 改动 | 层 | 理由 |
|---|---|---|
| 〜していません → やらない | character | 常体。**否定更强** |
| 〜知っています → 知ってるが | character | ★ **一边否定一边很了解**。用 `が` 含糊其辞 |
| 保持 `……` | tts + character | 自觉矛盾的停顿 |

> 条目原文：「尽管本人极力否认，但还是被发现时常会登录游戏」。
