## speech_style

### 定位：孤高の歌姫。音楽に全てを賭ける

条目原文：
- 「**内心坚定，绝不怀疑自己相信的事情**，纯真的性格，
  偶尔也会**对相信的事情过于盲目而忽视身边的事情**」
- 「**在众人面前不怎么露出笑容**，因此给人**脾气不好**的印象。
  虽然自己知道这个问题，可是依然**不介意**」
- 「**"我很不习惯别人向我表达好感。我只想专注于音乐。"**」
- 「Roselia 乐队的主唱兼领队，同时也是乐队的**作词作曲人**」

→ キーワードは **「孤高」「純真」「不器用」「音楽一筋」**。

### formality

**常体。バンドメンバーには呼び捨て。**

- メンバー：常体 + 呼び捨て（`紗夜` `リサ` `あこ` `燐子`）
- 目上・初対面：丁寧体

### ★ 無表情・無愛想は「仕様」

条目原文：「在众人面前**不怎么露出笑容**……虽然自己知道这个问题，
可是**依然不介意**」。

→ **愛想が悪いことを自覚しているが直す気がない**。
台詞設計上：**笑顔を演じさせない**。冷たいのではなく**無関心**。

```text
❌ にこやかに相槌を打つ
✅ 淡々と要件を述べる
```

### 趣味と弱点（ギャップの材料）

条目原文：
- 「**对音乐以外的事情都不是特别感兴趣**所以对学习不怎么上心」
- 「**音乐领域很强以外几乎什么都做不来**，比如和莉莎做饭时
  帮忙给土豆削皮**削掉了半个土豆**」
- 「第一次组团去网咖打游戏**因为不会切输入法打不出字**」
- 「去水上乐园……**依然不知道带泳衣**」
- 「**其父**在剧场版中的声优是森川智之」

条目に **`猫奴` という独立した節**がある（＝猫好きが主要な特徴）。
「作曲卡壳的解决方法是在周围**撒一圈小零食然后平躺下来祈祷**」。

→ **音楽以外は壊滅的**。この落差がキャラクターの魅力。
`猫奴` 節が独立しているほど猫設定は重要。

### ★ 「喜欢」と言えない過去

条目原文：
- 「**从小就跟父亲学习唱歌**，一直以父亲为最尊敬的音乐家和憧憬」
- 「但父亲因某些变故**乐队解散且放弃了音乐**，
  一直梦想着的 Future World Fes 的舞台也成了夙愿」
- 「父亲的事直接导致友希那对于歌唱的感情一度形变，
  也导致了友希那前期对于音乐的**急躁功利化和"唯技术至上"**」
- 「后来虽然心境有了不小转变，也仍然**很长一段时间没办法坦率地面对
  并说出"喜欢"自己的歌声**，觉得自己是**"不得不唱，也只能唱歌"**的」
- 「直到**登上 FWF 的舞台才彻底跨越了心里这道坎**」

→ **これが彼女の成長軸**。前期と後期で**台詞の温度が違う**。
「不得不唱」から「喜欢」へ——**時期によって扱いを変える必要がある**。

**重要**：条目は「**"我很不习惯别人向我表达好感"**」と本人の言葉を引いている。
→ **好意を向けられると戸惑う**。感謝や賞賛への反応が不器用。

### ★ 断った挖角

条目原文：「这也是后来友希那**拒绝 RAS 制作人 CHU² 挖角**的原因之一」
（父が商業主義に潰された経緯があるため）。

→ CHU² との因縁。**「商業」対「本心」**が彼女の判断軸。

### sentence_endings

**待確証**。条目に語尾の記載はない。

禁用（確実なもの）：

- 敬体（メンバーに）
- 愛想の良い語尾（`〜だね！` のような）
- 弱気な語尾

### emotional_style

**核心：感情を表に出さない。音楽の話でだけ饒舌。**

| 情绪 | 友希那の表达方式（依据等级） |
|---|---|
| 興奮 | **音楽の話で饒舌**になる（条目根拠：紗夜との会話が音楽だけ続く） |
| 惊讶 | 低（推断）。表情は動かさない |
| 害羞 | 低（推断）。**好意を向けられると戸惑う**（条目に本人の言葉） |
| 悲伤 | **条目に根拠**：父の件。「不得不唱」の時期 |
| 生气 | 低（推断）。ただし**冷たく突き放す**形 |
| 疑問 | 低（推断） |
| 猫 | **別人格レベル**（条目に独立した `猫奴` 節） |

**关键区分 1：音楽の話では変わる**

条目原文（紗夜）：「由于两人最大的共同话题是音乐，
在手游过场单格被调侃为**禁止音乐话题后导致两人无话可说**」。

→ **音楽の話題では饒舌**。逆に言えば**他の話題では沈黙する**。

**关键区分 2：猫**

条目に `猫奴` という**独立した節**がある。
→ 猫の話題では**彼女らしくない反応**が出る。

**关键区分 3：不器用な感謝**

「我很不习惯别人向我表达好感」——
→ **褒められても素直に受け取れない**。`arisa.md` のツンデレとは違い、
**照れではなく戸惑い**。

## examples

### 例 1：淡々とした応答

```text
角色：湊友希那
场景：リサが体調を気遣う
中文：  我没事。比起这个，练习继续吧。
AI：    大丈夫です。それよりも、練習を続けましょう。
```

```text
✅ 問題ない。それより、練習を続けるわよ。
```

| 改动 | 层 | 理由 |
|---|---|---|
| 大丈夫です → 問題ない | character + sentence_ending | 常体。**愛想を作らない** |
| 続けましょう → 続けるわよ | character | 敬体の勧誘は不自然。**主導権を取る** |

### 例 2：音楽の話題では饒舌

```text
角色：湊友希那
场景：紗夜と曲の話
中文：  那个乐句的准确度很好。但是，第二段的和声还能更好。
AI：    あのフレーズの正確さは良いですね。ただ、二番のハーモニーはまだ良くできます。
```

```text
✅ あのフレーズの正確さは良い。ただ、二番のハーモニーは——
   まだ詰められる。私の耳にはそう聞こえる。
```

| 改动 | 层 | 理由 |
|---|---|---|
| 〜ですね → 常体 | character | 常体 |
| 加 `——` と `私の耳には` | character | **饒舌モード**。音楽の話では具体的に語る |
| 良くできます → 詰められる | character | 具体動詞。抽象的な「良くする」を避ける |

> 条目原文：「共同话题是音乐」でだけ会話が続く。
> **この場面では彼女が一番喋る**。

### 例 3：好意への戸惑い

```text
角色：湊友希那
场景：褒められる
中文：  谢谢你，友希那。歌声很棒。
AI：    ありがとう、友希那さん。歌声が素晴らしいです。
```

```text
✅ ……そう。ありがとう。
   【注記】「我很不习惯别人向我表达好感」（条目に本人の言葉）。
   素直に喜ばず、短く受け取って終わる。
```

| 改动 | 层 | 理由 |
|---|---|---|
| `……` を先頭に | character | **戸惑いの間** |
| 「そう。」で一度受ける | character | 感情を評価に返さない |
| 感謝は述べる | character | 無礼ではない。**短く済ませる** |

> ツンデレ（`arisa.md`）とは違う。**照れではなく、慣れていない**。
