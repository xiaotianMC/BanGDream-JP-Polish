## speech_style

### 定位：孤高的歌姬。将一切赌在音乐上

条目原文：
- 「**内心坚定，绝不怀疑自己相信的事情**，纯真的性格，
  偶尔也会**对相信的事情过于盲目而忽视身边的事情**」
- 「**在众人面前不怎么露出笑容**，因此给人**脾气不好**的印象。
  虽然自己知道这个问题，可是依然**不介意**」
- 「**"我很不习惯别人向我表达好感。我只想专注于音乐。"**」
- 「Roselia 乐队的主唱兼领队，同时也是乐队的**作词作曲人**」

→ 关键词是 **「孤高」「純真」「不器用」「音楽一筋」**。

### 语体

**常体。对乐队成员直呼其名。**

- 成员：常体 + 直呼其名（`紗夜` `リサ` `あこ` `燐子`）
- 长辈・初次见面：敬体

### ★ 面无表情・不苟言笑是「刻意设定」

条目原文：「在众人面前**不怎么露出笑容**……虽然自己知道这个问题，
可是**依然不介意**」。

→ **她自知不讨人喜欢，却没有要改的意思**。
台词设计上：**不让她演笑脸**。不是冷淡，而是**不关心**。

```text
❌ にこやかに相槌を打つ
✅ 淡々と要件を述べる
```

### 兴趣与弱点（反差的素材）

条目原文：
- 「**对音乐以外的事情都不是特别感兴趣**所以对学习不怎么上心」
- 「**音乐领域很强以外几乎什么都做不来**，比如和莉莎做饭时
  帮忙给土豆削皮**削掉了半个土豆**」
- 「第一次组团去网咖打游戏**因为不会切输入法打不出字**」
- 「去水上乐园……**依然不知道带泳衣**」
- 「**其父**在剧场版中的声优是森川智之」

条目中有 **`猫奴` 这一独立章节**（＝喜欢猫是主要特征）。
「作曲卡壳的解决方法是在周围**撒一圈小零食然后平躺下来祈祷**」。

→ **除音乐以外全面崩坏**。这种落差正是角色的魅力。
`猫奴` 章节能独立成节，可见猫的设定有多重要。

### ★ 说不出「喜欢」的过去

条目原文：
- 「**从小就跟父亲学习唱歌**，一直以父亲为最尊敬的音乐家和憧憬」
- 「但父亲因某些变故**乐队解散且放弃了音乐**，
  一直梦想着的 Future World Fes 的舞台也成了夙愿」
- 「父亲的事直接导致友希那对于歌唱的感情一度形变，
  也导致了友希那前期对于音乐的**急躁功利化和"唯技术至上"**」
- 「后来虽然心境有了不小转变，也仍然**很长一段时间没办法坦率地面对
  并说出"喜欢"自己的歌声**，觉得自己是**"不得不唱，也只能唱歌"**的」
- 「直到**登上 FWF 的舞台才彻底跨越了心里这道坎**」

→ **这就是她的成长主轴**。前期与后期**台词的温度不同**。
从「不得不唱」到「喜欢」——**需要按时期改变处理方式**。

**重要**：条目引用了她本人的话「**"我很不习惯别人向我表达好感"**」。
→ **被表达好意时会不知所措**。对感谢与赞赏的反应很笨拙。

### ★ 拒绝过的挖角

条目原文：「这也是后来友希那**拒绝 RAS 制作人 CHU² 挖角**的原因之一」
（因为有过父亲被商业主义击垮的经历）。

→ 与 CHU² 的因缘。**「商业」对「本心」**是她的判断轴。

#### ★ 不向男性语靠拢（G11）—— 依据实际指摘

**用户指摘（2026-02-14）**：译文成稿中出现了**男性化的生硬**表达。
友希那是**女性**，而且是**凛然的说话方式**，因此
**连续使用 `〜だ` 听起来像男性语**。

| 修正后 | 原本出现 | 问题所在 |
|---|---|---|
| **わたしよ。** | `わたしだ。` | 自称时的断定 `〜だ` 男性化、生硬 |
| **このあたりよ。** | `このあたりなんだ。` | **`〜なんだ` 是男性的说明语气** |
| **ライブを行う。** | `ライブをやる。` | `やる` 太随意。郑重场合应用 `行う` |
| **（削除）** | `君たち` | ★ **`君` 是男性对下级使用的词。友希那不会用** |
| **ただ……** | `ただし……` | `ただし` 是条文・规章的书面语 |
| **いいわ。** | `よろしい。` | `よろしい` 带有教师・上级给予许可的语感。过于生硬 |
| **遅れないように。** | `遅れるな。` | **命令形 `〜な` 是男性的命令** |
| **ええ。** | `うん。` | ★ **她几乎不说 `うん`**（见下文） |

#### ★ 几乎不说 `うん` → `ええ`

**用户指摘**：友希那**几乎不用 `うん`**。

→ **回应只用 `ええ`**。
`うん` 带有**随意的亲近感**，与她**凛然的距离感**不搭。

> ⚠️ **这不是 G11（全角色共通），而是角色层的规则**。
> 其他角色可以使用 `うん`
> （例：香澄会用。燈则…比起 `うん`，更多是沉默）。
> **区分标准**：「因为她是女性」→ G11 ／「这个角色不使用这个词」→ 本文件。

#### 减少生硬感的方向

**友希那的「强」不是靠连发 `〜だ`，而是靠内容的锐利来体现**：

```text
✅ 〜よ / 〜の / 〜わ も混ぜて、断定の連続を避ける
✅ 命令は 〜ないように / 〜して の依頼形へ
✅ 相槌は ええ
❌ 〜だ。〜だ。〜だ。と畳みかける   ← 男性的に聞こえる
❌ 〜するな / 〜しろ              ← 明確な男性語
❌ 〜だぜ / 〜だぞ / 〜かい        ← 明確な男性語
```

> ★ **不要机械地加 `〜わ`**（G11 的过度修正条目）。
> 友希那**既不是大小姐，也不带戏剧腔**，所以
> `〜ですわ` `〜ますわ` 会**变成另一个人**。
> 停留在凛然的常体 + `〜よ` `〜の` 的程度。

### emotional_style

**核心：不把感情表露在外。只有聊音乐时才多话。**

| 情绪 | 友希那的表达方式（依据等级） |
|---|---|
| 兴奋 | **聊音乐时变得多话**（条目根据：与紗夜的对话只有音乐能持续） |
| 惊讶 | 低（推断）。表情不动 |
| 害羞 | 低（推断）。**被表达好意时会不知所措**（条目中有本人的话） |
| 悲伤 | **条目中有根据**：父亲的事。「不得不唱」的时期 |
| 生气 | 低（推断）。但采取**冷淡推开**的形式 |
| 疑问 | 低（推断） |
| 猫 | **另一人格的程度**（条目中有独立的 `猫奴` 章节） |

**关键区分 1：聊音乐时会变**

条目原文（紗夜）：「由于两人最大的共同话题是音乐，
在手游过场单格被调侃为**禁止音乐话题后导致两人无话可说**」。

→ **聊音乐话题时多话**。反过来说，**在其他话题上会沉默**。

**关键区分 2：猫**

条目中有 `猫奴` 这一**独立章节**。
→ 聊到猫的话题时会出现**不像她的反应**。

**关键区分 3：笨拙的感谢**

「我很不习惯别人向我表达好感」——
→ **被夸奖也无法坦率接受**。与 `arisa.md` 的傲娇不同，
**不是害羞，而是不知所措**。

## examples

### 例 1：平淡的应答

```text
角色：湊友希那
场景：リサが体調を気遣う
中文：  我没事。比起这个，练习继续吧。
AI：    大丈夫です。それよりも、練習を続けましょう。
```

```text
✅ 問題ない。それより、練習を続けるわよ。
```

| 改动 | 层 | 理由 |
|---|---|---|
| 大丈夫です → 問題ない | character + sentence_ending | 常体。**不营造讨好的态度** |
| 続けましょう → 続けるわよ | character | 敬体的劝诱不自然。**掌握主导权** |

### 例 2：聊音乐话题时多话

```text
角色：湊友希那
场景：紗夜と曲の話
中文：  那个乐句的准确度很好。但是，第二段的和声还能更好。
AI：    あのフレーズの正確さは良いですね。ただ、二番のハーモニーはまだ良くできます。
```

```text
✅ あのフレーズの正確さは良い。ただ、二番のハーモニーは——
   まだ詰められる。私の耳にはそう聞こえる。
```

| 改动 | 层 | 理由 |
|---|---|---|
| 〜ですね → 常体 | character | 常体 |
| 加 `——` 与 `私の耳には` | character | **饶舌模式**。聊音乐时会具体地说 |
| 良くできます → 詰められる | character | 具体动词。避免抽象的「良くする」 |

> 条目原文：「共同话题是音乐」，只有这一点能让对话持续。
> **在这个场景中她话最多**。

### 例 3：面对好意的不知所措

```text
角色：湊友希那
场景：褒められる
中文：  谢谢你，友希那。歌声很棒。
AI：    ありがとう、友希那さん。歌声が素晴らしいです。
```

```text
✅ ……そう。ありがとう。
   【注记】「我很不习惯别人向我表达好感」（条目中有本人的话）。
   不坦率地表现出高兴，简短接受后结束。
```

| 改动 | 层 | 理由 |
|---|---|---|
| 在开头加 `……` | character | **不知所措的停顿** |
| 用「そう。」先接一次 | character | 不把感情当作对评价的回应 |
| 仍表达感谢 | character | 并非无礼。**简短了结** |

> 与傲娇（`arisa.md`）不同。**不是害羞，而是不习惯**。
