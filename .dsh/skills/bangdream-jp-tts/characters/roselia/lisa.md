## examples

### 例 1：通訳（他バンドの変な言葉）

```text
角色：今井リサ
场景：香澄の支離滅裂な発言を通訳する
中文：  也就是说，香澄想办演唱会，对吧？
AI：    つまり、香澄はライブをしたいということですね。
```

```text
✅ つまりさ、香澄はライブやりたいってことだよね。
```

| 改动 | 层 | 理由 |
|---|---|---|
| 〜ですね → 〜だよね | character + sentence_ending | 常体。**相手に確認を取る** |
| 加 `さ` | character | 辣妹系の軽い語感（条目「打扮花俏」） |
| `つまり` を保持 | character | ★ **通訳の定型**。条目明記の能力 |

> 条目原文：「能够明白 Poppin Party 香澄的キラキラ☆ドキドキ」。
> **リサは通訳できる唯一の人物**。

### 例 2：世話焼き

```text
角色：今井リサ
场景：練習室が散らかっている
中文：  真是的，你们把这里弄得一团糟。来，一起收拾吧。
AI：    もう、みんな散らかしすぎですよ。さあ、一緒に片付けましょう。
```

```text
✅ もう、なんでこんな散らかってんの。ほら、一緒に片付けるよ。
```

| 改动 | 层 | 理由 |
|---|---|---|
| 〜ですよ → 〜なんで…の | character | 常体。**呆れつつも面倒を見る** |
| 片付けましょう → 片付けるよ | character | 敬体の勧誘は不自然。**主導権を取る** |
| 加 `ほら` | character | ★ **世話焼きの語彙**。条目原文の「带着大家收拾」 |

### 例 3：過剰な謙遜

```text
角色：今井リサ
场景：演奏を褒められる
中文：  谢谢。但是，我的技术还差得远……会拖累大家的。
AI：    ありがとうございます。でも、私の技術はまだまだで……みんなに迷惑をかけています。
```

```text
✅ え、そんなことないよ。……ううん、私なんか、まだまだだし。
```

| 改动 | 层 | 理由 |
|---|---|---|
| 〜ございます → 常体 | character | 常体 |
| 加 `え、そんなことないよ` | character | **まず否定する**（謙遜の第一段） |
| `……ううん、私なんか` | character | ★ **過剰な自己評価の低さ**（条目明記） |

> 条目原文：「莉莎经常会担心自己是不是在拖累其他队员，
> 甚至在一次 Live 以后因为这件事在休息室里哭泣」。
> **実際には有能**——弱いキャラにしないこと。
