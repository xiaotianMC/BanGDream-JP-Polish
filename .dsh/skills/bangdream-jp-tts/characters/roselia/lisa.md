### 名字读音

因为「开朗」，**语调要偏明亮**。
虽然不像 `kasumi.md` 那样跳跃，但**不会变得阴郁**。

## examples

### 例 1：翻译（其他乐队的奇怪话语）

```text
角色：今井リサ
场景：香澄の支離滅裂な発言を通訳する
中文：  也就是说，香澄想办演唱会，对吧？
AI：    つまり、香澄はライブをしたいということですね。
```

```text
✅ つまりさ、香澄はライブやりたいってことだよね。
```

| 改动 | 层 | 理由 |
|---|---|---|
| 〜ですね → 〜だよね | character + sentence_ending | 常体。**向对方确认** |
| 加 `さ` | character | 辣妹系的轻快语感（条目「打扮花俏」） |
| 保持 `つまり` | character | ★ **翻译的定式**。条目明确记载的能力 |

> 条目原文：「能够明白 Poppin Party 香澄的キラキラ☆ドキドキ」。
> **リサ是唯一能翻译的人物**。

### 例 2：爱照顾人

```text
角色：今井リサ
场景：練習室が散らかっている
中文：  真是的，你们把这里弄得一团糟。来，一起收拾吧。
AI：    もう、みんな散らかしすぎですよ。さあ、一緒に片付けましょう。
```

```text
✅ もう、なんでこんな散らかってんの。ほら、一緒に片付けるよ。
```

| 改动 | 层 | 理由 |
|---|---|---|
| 〜ですよ → 〜なんで…の | character | 常体。**虽然无奈但会照顾** |
| 片付けましょう → 片付けるよ | character | 敬体的劝诱不自然。**掌握主导权** |
| 加 `ほら` | character | ★ **爱照顾人的词汇**。条目原文的「带着大家收拾」 |

### 例 3：过度的谦逊

```text
角色：今井リサ
场景：演奏を褒められる
中文：  谢谢。但是，我的技术还差得远……会拖累大家的。
AI：    ありがとうございます。でも、私の技術はまだまだで……みんなに迷惑をかけています。
```

```text
✅ え、そんなことないよ。……ううん、私なんか、まだまだだし。
```

| 改动 | 层 | 理由 |
|---|---|---|
| 〜ございます → 常体 | character | 常体 |
| 加 `え、そんなことないよ` | character | **首先否定**（谦逊的第一步） |
| `……ううん、私なんか` | character | ★ **过度的自我评价过低**（条目明确记载） |

> 条目原文：「莉莎经常会担心自己是不是在拖累其他队员，
> 甚至在一次 Live 以后因为这件事在休息室里哭泣」。
> **实际上很有能力**——不要写成弱角色。
