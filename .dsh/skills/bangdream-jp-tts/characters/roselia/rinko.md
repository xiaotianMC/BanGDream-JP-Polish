## speech_style

### ★ 定位：以 0.5 倍速说话。这是最大的语言特征

条目原文：
- 「**平时说话为 0.5 倍速，字幕中有大量省略号隔开**」
- 「但是**和亚子玩网游时打字很快而且颜文字用得很溜**。

  不过**若是决定要钻研一件事就会做到极致**」

→ ★★ **「0.5 倍速 + 大量省略号」是条目明确记载的语言特征**。

台词的媒介（口头，还是聊天）会让**速度改变**。

## TTS 特别注意

### ★ 语速就是角色性

**条目明确记载「0.5 倍速」**。这对 TTS 而言是**最重要的信息**。

- 用普通语速读出来会**变成另一个人**
- 减少 `……` 的数量会**让拖长的感觉消失**
- 不过**是在引擎侧降低语速，还是用文本表现**是另一个问题

→ 在 `adapters/gpt-sovits.md` 的验证清单中，
这是想确认**能否使用语速参数**的项目。
如果不能使用，就只能**靠 `……` 和读点来争取停顿**。

**参考音频（reference audio）的影响也很大**：
燐子**说话很慢**，所以如果参考音频是语速快的说话者，可能难以再现
（adapter 的 D 类）。

### 名字读音

| 表记 | 读音 | 风险 |
|---|---|---|
| 燐子 | りんこ | **高。「燐」是不在常用汉字表内的难读字** |
| 白金 | **しろかね** | **最高。容易被误读为「しろがね」「はっきん」等** |

★★ **「白金」是本条目中风险最高的**。
「しろかね」是**金属名的读音**，但**「はっきん」的联想很强**。

登録済み（`../../dictionary/pronunciation.yaml`）。**優先実測対象**。

### 在线/面对面的切换

同一个人**语速会发生很大变化**。对 TTS 而言：
- 面对面：慢 + 多用 `……`
- 聊天：快 + 颜文字

**把聊天的台词音频化时**，如何处理颜文字需要确认
（是否需要去除 `＾＾` 等以免被读出来）。

## examples

### 例 1：面对面的 0.5 倍速

```text
角色：白金燐子
场景：あこに話しかけられる
中文：  啊，那个……今天也，一起玩游戏吗……？
AI：    あ、あの、今日も一緒にゲームをしませんか？
```

```text
✅ あ、……あの、きょうも……いっしょに、ゲーム……しますか……？
```

| 改动 | 层 | 理由 |
|---|---|---|
| 多用 `……` | character + tts | ★ 条目明确记载「字幕中有大量省略号隔开」 |
| 把词断开 | character | **0.5 倍速**。换气会变多 |
| 维持敬体 | character | 燐子以敬体为基础 |

> **这种停顿之多正是本角色的核心**。与 `taki.md` 的 `……`（说不出口）不同，
> 是**物理上的慢**。

### 例 2：在线时很快

```text
角色：白金燐子
场景：NFO のチャット
中文：  了解了！我马上过去！
AI：    了解しました。すぐに行きます。
```

```text
✅ りょうかいです！＾＾ すぐいきますー！
   【注记】聊天场面。条目原文「和亚子玩网游时打字很快而且颜文字用得很溜」。
   颜文字的处理需要 `adapters/gpt-sovits.md` 的验证。
```

| 改动 | 层 | 理由 |
|---|---|---|
| **删除** `……` | character | ★ **在线时很快**（条目明确记载） |
| 添加颜文字 `＾＾` | character | 条目原文「颜文字用得很溜」 |
| 用 `ー` 表现轻快 | character | 与面对面的落差 |

> **依媒介而像变了个人**。这就是条目明确记载的两面性。
> **TTS 中如何处理颜文字需要实测**。

### 例 3：钢琴（成长轴）

```text
角色：白金燐子
场景：ピアノの話
中文：  我有一段时期放弃了钢琴。……但是现在，能弹了。
AI：    私はピアノを諦めていた時期があります。……でも、今は弾けます。
```

```text
✅ わたし、……ピアノ、やめていたときも、あって。……でも、いまは、弾けます。
```

| 改动 | 层 | 理由 |
|---|---|---|
| `私` → `わたし` | character | ★ **平假名的第一人称**（遵循原表记） |
| 增加 `……` 与读点 | character | 0.5 倍速 |
| 「でも、いまは、弾けます」 | character | **把成长简短地说到底**（她自己的坚强） |

> 条目原文：「决定直面幼时的心理阴影……**超越了当年的自己**」。
> **不要写成只会示弱的角色**——这是她成长的证明。
