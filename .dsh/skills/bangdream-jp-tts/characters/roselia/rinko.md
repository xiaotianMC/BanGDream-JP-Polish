## TTS 特别注意

### ★ 話速がキャラクター

**条目が「0.5 倍速」と明記**している。これは TTS にとって**最も重要な情報**。

- 通常の話速で読ませると**別人になる**
- `……` の数を減らすと**間延び感が消える**
- ただし**エンジン側で話速を下げるのか、テキストで表現するのか**は別問題

→ `adapters/gpt-sovits.md` の検証清单で、
**話速パラメータが使えるか**を確認したい項目。
使えない場合、**`……` と読点で間を稼ぐ**しかない。

**参考音频（reference audio）の影響も大きい**：
燐子は**ゆっくり話す**ので、参考音声が速い話者だと再現しにくい可能性がある
（adapter の D 類）。

### 名字读音

| 表記 | 读音 | 风险 |
|---|---|---|
| 燐子 | りんこ | **高。「燐」は常用漢字表に無い難読字** |
| 白金 | **しろかね** | **最高。「しろがね」「はっきん」等と誤読されやすい** |

★★ **「白金」は本項目で最もリスクが高い**。
「しろかね」は**金属名の読み**だが、**「はっきん」の連想が強い**。

登録済み（`../../dictionary/pronunciation.yaml`）。**優先実測対象**。

### オンライン/対面の切り替え

同一人物で**話速が大きく変わる**。TTS 的には：
- 対面：遅い + `……` 多用
- チャット：速い + 顔文字

**チャットの台詞を音声化する場合**、顔文字をどう扱うかは要確認
（`＾＾` などを読み上げないよう除去が必要か）。

## examples

### 例 1：対面の 0.5 倍速

```text
角色：白金燐子
场景：あこに話しかけられる
中文：  啊，那个……今天也，一起玩游戏吗……？
AI：    あ、あの、今日も一緒にゲームをしませんか？
```

```text
✅ あ、……あの、きょうも……いっしょに、ゲーム……しますか……？
```

| 改动 | 层 | 理由 |
|---|---|---|
| `……` を多用 | character + tts | ★ 条目明記「字幕中有大量省略号隔开」 |
| 語を区切る | character | **0.5 倍速**。息継ぎが多くなる |
| 丁寧体を維持 | character | 燐子は丁寧体ベース |

> **この間の多さが本角色の核**。`taki.md` の `……`（言えない）とは違い、
> **物理的に遅い**。

### 例 2：オンラインでは速い

```text
角色：白金燐子
场景：NFO のチャット
中文：  了解了！我马上过去！
AI：    了解しました。すぐに行きます。
```

```text
✅ りょうかいです！＾＾ すぐいきますー！
   【注記】チャット場面。条目原文「和亚子玩网游时打字很快而且颜文字用得很溜」。
   顔文字の扱いは adapters/gpt-sovits.md の検証が必要。
```

| 改动 | 层 | 理由 |
|---|---|---|
| `……` を**削除** | character | ★ **オンラインでは速い**（条目明記） |
| 顔文字 `＾＾` を追加 | character | 条目原文「颜文字用得很溜」 |
| `ー` で軽さを出す | character | 対面との落差 |

> **媒体によって別人のように変わる**。これが条目明記の二面性。
> **TTS で顔文字をどう扱うかは要実測**。

### 例 3：ピアノ（成長軸）

```text
角色：白金燐子
场景：ピアノの話
中文：  我有一段时期放弃了钢琴。……但是现在，能弹了。
AI：    私はピアノを諦めていた時期があります。……でも、今は弾けます。
```

```text
✅ わたし、……ピアノ、やめていたときも、あって。……でも、いまは、弾けます。
```

| 改动 | 层 | 理由 |
|---|---|---|
| `私` → `わたし` | character | ★ **平仮名の一人称**（出典準拠） |
| `……` と読点を増やす | character | 0.5 倍速 |
| 「でも、いまは、弾けます」 | character | **成長を短く言い切る**（彼女なりの強さ） |

> 条目原文：「决定直面幼时的心理阴影……**超越了当年的自己**」。
> **弱いだけのキャラにしない**——ここが彼女の成長の証。
