条目原文：「一直以来因为**母亲只因为她努力就不停夸奖她**而不满，

## examples

### 例 1：成功時の口癖

```text
角色：珠手知由
场景：レコーディングが上手くいった
中文：  完美！这个音乐是最强的！
AI：    完璧です！この音楽が最強です！
```

```text
✅ スウィート！エクセレント！アンストッパブル！
   これがワタシの最高の音楽よ！
   【待确认】口癖の正式な表記・読みが未確認。上記は片仮名転写の一案。
```

| 改动 | 层 | 理由 |
|---|---|---|
| 口癖を追加 | character | **条目明記**の口癖。成功時の定型 |
| です → 常体 + `よ` | character + sentence_ending | 常体。断定 |
| `私` → `ワタシ` | character | **片仮名の一人称** |
| 【待确认】 | — | **原表記が未確定のため断定しない** |

### 例 2：プロ意識 —— 態度が変わる場面

```text
角色：珠手知由
场景：六花が編集の腕を褒める
中文：  洛克，你的剪辑感觉不错。值得一谈。
AI：    ロック、あなたの編集センスは悪くないですね。話しましょう。
```

```text
✅ ロック、その編集……悪くないわ。ねえ、ちょっと聞かせて。
```

| 改动 | 层 | 理由 |
|---|---|---|
| 〜ですね → 常体 | character | 常体。ただし**敬意は保つ** |
| 「あなた」削除 | japanese | 日本語では不要（J2-2） |
| `……` + `悪くないわ` | character | **認めている**が素直に褒めない |
| `ねえ、ちょっと聞かせて` | character | **プロとして興味を持った**態度（条目明記） |

> 条目原文：「在六花**称赞自己的剪辑观念时，好声好气地答复对方
> 甚至与她侃侃而谈**」。
> **プロと認めた相手には態度が柔らかくなる**——この差が本角色の判断基準。

### 例 3：怒りと公徳心

```text
角色：珠手知由
场景：誘いを断られる
中文：  什么啊，真让人火大。……算了。
AI：    何よ、ムカつく。……もういいわ。
```

```text
✅ はあ！？　ふざけんな……って、あ。
   （ゴミ箱を蹴って、すぐに拾い直しながら）
```

| 改动 | 层 | 理由 |
| --- | --- | --- |
| 加 `はあ！？` | character | 傲慢な怒り方 |
| 加 `って、あ。` | character | **公徳心**。怒りが引く瞬間 |
| ト書きで拾い直しを表現 | character | 条目明記の行動。**台詞だけでは表せない** |

> **この「怒る → すぐ戻る」が彼女の人間味**。
> 単なる悪役にしないための具体例。
