## speech_style

### 定位：成熟的职业人。保持距离感

条目原文：
- 「**不管什么歌都能唱的专业歌姬**」
- 「**言行成熟，会与人保持距离感**」
- 「虽然是一个看起来相当有威压感的角色**容易被别人叫成姐**，但其实**相当温柔**」
- 「拥有**为了身边的人可以放弃自身愿望的勇气**，内心相对地强大」

→ 关键词是 **「成熟」「距離感」「温柔」「自己犠牲」**。
看起来高压，内里却很柔软，这种**反差**才是本体。

### 语体

**以常体为基础 + 礼貌的措辞。** 因为「言行成熟」，所以
不用粗鲁的措辞。但**不升到敬体**（对同辈・后辈）。

- 同乐队・同辈：常体
- 后辈（六花等）：常体但**柔和**
- 长辈・初次见面：敬体

### 「距離感」的展现方式

条目明确写到的「与人保持距离感」，**并非冷淡疏远**。
她通过**不把自己的感情摆到前面**来制造距离。

```text
✅ そうだね。……うん、大丈夫。
❌ 私、実はすごく心配してて……
```

**不谈论自己的内心**是基本。但**会说体谅对方的话**。

**关键区分：不哭的约定**

条目原文：「小时候搬家时因为看到多惠的眼泪而**决定再回来**。
与多惠约定了**不会哭泣**，即使心里感到难过，也**没有掉一滴眼泪**。
**佐藤益木帮她哭了**」。

→ **这是她的核心**。为了**约定而压抑**悲伤。
在台词设计上：她悲伤的场面会**以沉默代替眼泪**。
而**益木会替她表达感情**——这种分工就是原作的构图。

```text

✅ レイヤが黙る／平静を装う。益木が怒るか泣く
```

**关键区分：武道馆的经历**

## examples

### 例 1：关心与克制

```text
角色：和奏レイヤ
场景：六花が落ち込んでいる
中文：  洛克，不要勉强自己。我一直在你身边。
AI：    ロック、無理しないでください。私はずっとそばにいます。
```

```text
✅ ロック、無理しなくていいよ。……大丈夫、こっちにいるから。
```

| 改动 | 层 | 理由 |
|---|---|---|
| 〜ください → 〜ていいよ | character + sentence_ending | 六花是后辈。不升到敬体 |
| そばにいます → こっちにいるから | character + japanese | 常体。用 `から` **附上理由**的柔和感 |
| 加 `……` | tts + character | **距離感**。不把话说完，留出间隔 |

### 例 2：压抑感情 —— 本角色的核心

```text
角色：和奏レイヤ
场景：たえとの別れの場面
中文：  我很难过。但是，我答应过不哭。
AI：    悲しいです。でも、泣かないと約束しました。
```

```text
✅ ……悲しくないわけ、ないけど。約束したから。
```

| 改动 | 层 | 理由 |
|---|---|---|
| 悲しいです → 悲しくないわけ、ないけど | character | **用双重否定透出真心**。不直接说「悲しい」 |
| でも → 删除、用 `から` 连接 | character | 转折连词过于说明性。**只留下理由** |
| 約束しました → 約束したから | character + sentence_ending | 常体。**不把话说完，以理由收尾** |
| 加 `……` 在开头 | tts + character | 代替眼泪的沉默 |

> **在这个场面她不会哭。** 条目明记的约定。
> 取而代之**由益木来表达感情**，这是原作的构图——
> 若写成单独的台词，就用 `……` 和双重否定来展示内心。
