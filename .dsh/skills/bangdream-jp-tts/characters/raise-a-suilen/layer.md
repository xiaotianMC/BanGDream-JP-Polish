## speech_style

### 定位：成熟したプロ。距離感を保つ

条目原文：
- 「**不管什么歌都能唱的专业歌姬**」
- 「**言行成熟，会与人保持距离感**」
- 「虽然是一个看起来相当有威压感的角色**容易被别人叫成姐**，但其实**相当温柔**」
- 「拥有**为了身边的人可以放弃自身愿望的勇气**，内心相对地强大」

→ キーワードは **「成熟」「距離感」「温柔」「自己犠牲」**。
高圧的に見えるが中身は柔らかい、という**ギャップ**が本体。

### formality

**常体ベース + 丁寧な措辞。** 「言行成熟」なので、
乱暴な言葉遣いはしない。ただし**敬体には上げない**（同輩・後輩に）。

- 同バンド・同輩：常体
- 後輩（六花など）：常体だが**柔らかい**
- 目上・初対面：丁寧体

### 「距离感」の出し方

条目が明言する「与人保持距离感」は、**よそよそしさではない**。
彼女は**自分の感情を前に出さない**ことで距離を作る。

```text
✅ そうだね。……うん、大丈夫。
❌ 私、実はすごく心配してて……
```

**自分の内面を語らない**のが基本。ただし**相手を気遣う発言はする**。

### sentence_endings

**待確証**。条目に語尾の記載はない。
「成熟」「温柔」から**落ち着いた常体**と推定できるが、
具体形は**推測で作らない**（G8）。

禁用（確実なもの）：

- 若者言葉（`じゃん` `っしょ` `やばい`）——「成熟」に反する
- 過度な敬体——同輩後輩には使わない
- 感情的な絶叫

**核心：内に秘める。強さは「我慢」の形で出る。**

**关键区分：泣かなかった約束**

条目原文：「小时候搬家时因为看到多惠的眼泪而**决定再回来**。
与多惠约定了**不会哭泣**，即使心里感到难过，也**没有掉一滴眼泪**。
**佐藤益木帮她哭了**」。

→ **これが彼女の核心**。悲しみを**約束のために抑える**。

そして**益木が代わりに感情を出す**——この分業が原作の構図。

```text
❌ レイヤが号泣する
✅ レイヤが黙る／平静を装う。益木が怒るか泣く
```

**关键区分：武道館の経験**

条目原文：「动画第三季第十二话中，多惠透露 **LAYER 曾有在武道馆演出过的经历**」。

→ **キャリアが長い**。同じ「武道館」を夢として語る他バンドのキャラとは
**温度が違う**。彼女にとっては**通過点**。

## examples

### 例 1：気遣いと抑制

```text
角色：和奏レイヤ
场景：六花が落ち込んでいる
中文：  洛克，不要勉强自己。我一直在你身边。
AI：    ロック、無理しないでください。私はずっとそばにいます。
```

```text
✅ ロック、無理しなくていいよ。……大丈夫、こっちにいるから。
```

| 改动 | 层 | 理由 |
|---|---|---|
| 〜ください → 〜ていいよ | character + sentence_ending | 六花は後輩。敬体には上げない |
| そばにいます → こっちにいるから | character + japanese | 常体。`から` で**理由を添える**柔らかさ |
| 加 `……` | tts + character | **距離感**。言い切らずに間を置く |

### 例 2：感情を抑える —— 本角色の核心

```text
角色：和奏レイヤ
场景：たえとの別れの場面
中文：  我很难过。但是，我答应过不哭。
AI：    悲しいです。でも、泣かないと約束しました。
```

```text
✅ ……悲しくないわけ、ないけど。約束したから。
```

| 改动 | 层 | 理由 |
|---|---|---|
| 悲しいです → 悲しくないわけ、ないけど | character | **二重否定で本音をにじませる**。直接「悲しい」と言わない |
| でも → 削除、`から` で結ぶ | character | 逆接の接続詞は説明的。**理由だけを残す** |
| 約束しました → 約束したから | character + sentence_ending | 常体。**言い切らず理由で止める** |
| 加 `……` 冒頭 | tts + character | 涙の代わりの沈黙 |

> **この場面で彼女は泣かない。** 条目明記の約束。
> 代わりに**益木が感情を出す**のが原作の構図——
> 単独の台詞として書くなら、`……` と二重否定で内側を見せる。
