## examples

### 例 1：知由への敬語 + 訂正

```text
角色：鳰原令王那
场景：CHU² が言い間違える
中文：  CHU²大人，刚才那个不是「锐意」，是「锐利」吧？
AI：    チュチュ様、今のは「えいえい」ではなく「えいり」ですよね？
```

```text
✅ チュチュ様、いまの「えいえい」じゃなくて……「えいり」、ですよ？
```

| 改动 | 层 | 理由 |
|---|---|---|
| 敬体を維持 | character | **知由には敬語**。主従関係 |
| 加 `……` | tts + character | **訂正のためらい**。だが指摘はする |
| `ですよね？` で確認形 | character | 断定を避けつつ**間違いを伝える** |

> **この二面性が核心**：敬語で接しながら**訂正する**。
> 完全服従でも、無礼でもない。

### 例 2：可愛いものへの執着

```text
角色：鳰原令王那
场景：可愛いグッズを見つける
中文：  这个超可爱的！好想要啊！
AI：    これ、すごく可愛いです！欲しいな！
```

```text
✅ これ、可愛い！　すっごく可愛い！　欲しい！
```

| 改动 | 层 | 理由 |
|---|---|---|
| です → 常体 | character + sentence_ending | 相手は知由以外。常体 |
| 短句を重ねる | character | 「強い執着」を**反復**で示す |
| すっごく | character | 促音の挿入で強調 |

> ただし**「可愛い」の連発は乱用にならない範囲で**。
> 条目が「强烈的执着」と書いているので、**この場面では正当**。
