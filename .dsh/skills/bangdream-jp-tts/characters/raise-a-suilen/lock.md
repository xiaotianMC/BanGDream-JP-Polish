## speech_style

### 定位：内向的な努力家。ギターを持つと変わる

条目原文：
- 「虽然是**饱尝艰辛的幸运 E**，但**总是什么事都全力以赴**」
- 「在性格上**略有内向**，然而**拿起吉他的时候感觉更像是变了一个人**」
- 「平常戴着的眼镜和发带是**能力限制器**，当摘下眼镜和发带时则是**能力全开**」
- 「**Poppin'Party 的铁粉**」

→ キーワードは **「内向」「全力」「ギターで変身」「PPP ファン」**。

### formality

**常体 + 「〜さん」称呼。** ★ **RAS で唯一、全員に敬称を付ける**。

| 対象 | 六花の称呼 |
|---|---|
| 和奏レイヤ | `レイヤさん` |
| 佐藤益木 | `ますきさん` |
| 鳰原令王那 | `パレオさん` |
| 珠手知由 | `チュチュさん` |
| 高松燈 | `燈ちゃん` |
| 長崎そよ | `そよちゃん` |

→ 益木・令王那は他メンバーを呼び捨てにするが、**六花は全員に「さん」**。
これは**後輩であり内向的**であることの現れ。**この敬称を落とさない**。

### ★ 岐阜弁 —— 本角色最重要的语言特征

**出典の `轶事` に明記**：

> 「因为**出身岐阜县**的关系，朝日六花在**情绪激动时会说出方言**。
> 台湾的代理商木棉花在翻译时选择以同样作为在地语言的闽南语来重现，
> 其中最知名的是在加入 RAS 时的台词
> 「乐团实在...**五告赞**（棒呆啦）！」」

→ **条件触发**。平常は標準語、**感情が高ぶると岐阜弁が出る**。

| 状態 | 言語 |
|---|---|
| 平常 | 標準語 |
| **情緒激動**（興奮・感激・驚き） | **岐阜弁が混ざる** |

**⚠️ りみ と同じ種類のリスク**：条目は「方言が出る」としか書いておらず、
**具体語彙は 1 例（「五告赞」）しかない**。しかもそれは**台湾訳の閩南語**であって、
**日本語の岐阜弁そのものではない**。

→ **処理**：岐阜弁が必要な場面では**先在 `【待确认】` 里问**。
具体形を創作しない（G8）。`rimi.md` の関西弁と同じ扱い。

### sentence_endings

**待確証**。条目に語尾の記載はない。

「内向的」から**柔らかい常体**と推定できるが、具体形は推測しない。

禁用（確実なもの）：

- `じゃん` `っしょ`（陽キャの語彙。内向的な彼女に合わない）
- 過度な敬体（同輩に）
- 命令形

### vocabulary

**条目可确证**：

```text
ポッピンパーティ    ★ 铁粉。話題にすると挙動が変わる
ギター            本業
ギャラクシー       バイト先のライブハウス
商店街青年部       所属
```

**`ポッピンパーティ` への反応が最大の特徴**

条目原文：「**Poppin'Party 的铁粉**」。
→ 香澄たちへの言及では**ファンとしての挙動**（緊張・興奮）が出る。
これは `arisa.md` の Afterglow ファン設定と同じ構造。

**好きなもの**：条目は「喜欢的东西：**Poppin'Party**」と書いている——
**好物ではなくバンド名が「好きなもの」欄に来ている**。それほどの鉄粉。

### emotional_style

**核心：内向的だが、ギターと仲間の前では全力。**

| 情绪 | 六花の表达方式（依据等级） |
|---|---|
| 兴奋 | **方言が出る**（条目明記）。標準語が崩れる |
| 惊讶 | 低（推断） |

| 疑問 | 低（推断） |
| PPP の話題 | **ファンとして挙動が変わる**（条目明記） |

**关键区分 1：能力限制器**

条目原文：「**平常戴着的眼镜和发带是能力限制器**，
当摘下眼镜和发带时则是**能力全开**」。

→ これは**演出上の比喩**だが、台詞設計に使える：
**普段は控えめ、演奏や本気の場面で豹変**。

**关键区分 2：努力の人**

条目原文：
- 「虽然是**特待生**，但其实在**读书上并不在行**，连运动其实也并不擅长，
  **吉他是她唯一努力练下来的东西**」
- 「从这些地方可以看出，为了梦想六花会**努力付出**，是个相当有**行动力**的女孩」

→ **才能ではなく努力**。`天才` 系の台詞は似合わない。

**关键区分 3：学号 1 番**

条目原文：「因为名字开头为**あ**，因而学号被编排在 1 号」。

→ ネタ。本文で使うかは要判断。

## TTS 特别注意

### 名字读音

| 表记 | 读音 | 风险 |
|---|---|---|
| 六花 | ろっか | **高。「りっか」「ろくはな」等と誤読されやすい** |
| 朝日 | あさひ | 低〜中（一般語だが人名） |

**「六花 → ろっか」は要注意**。`../../dictionary/pronunciation.yaml` に登録済み。

### 通称の揺れ

`ロック`（通称）と `六花`（本名）が**発話者によって使い分けられる**。
TTS としては両方とも読みは安定（ロック / ろっか）。

**ただし `六花` は漢字なので誤読リスクがある**——
Afterglow が `六花` と呼ぶ場面で `りっか` と読まれる可能性。

### 方言のTTSリスク

岐阜弁を書く場合、`rimi.md` の関西弁と同じ問題が起きる：
**ピッチアクセントが標準語と異なる**ため、標準語の参考音声では不自然になりうる。

→ 方言を使う前に `adapters/gpt-sovits.md` の D 類（参考音频影响）を確認。
**未検証のまま積極採用しない。**

## examples

### 例 1：内向的な普段の台詞

```text
角色：朝日六花
场景：レイヤに相談する
中文：  那个……莱雅小姐，我可以问一下吗？
AI：    あの、レイヤさん、聞いてもいいですか？
```

```text
✅ あの……レイヤさん、ちょっと聞いてもいいかな？
```

| 改动 | 层 | 理由 |
|---|---|---|
| いいですか → いいかな？ | character + sentence_ending | 常体。**内向的なので断定を避ける** |
| 加 `……` | tts + character | 言い淀み。内向さの表現 |
| 加「ちょっと」 | character | 押しつけない前置き |

### 例 2：情緒激動で方言 —— 【待确认】が必要な例

```text
角色：朝日六花
场景：RAS 加入が決まった瞬間
中文：  乐队实在太棒了！
AI：    バンド、本当に最高です！
```

```text
✅ バンド、ほんとに……もう、たまらん！
   【待确认】岐阜弁の具体形が未確証。
   上記「たまらん」は標準語の強調形で回避した。
   岐阜弁を使う場合、方言の種類・強度を指定してください。
```

| 改动 | 层 | 理由 |
|---|---|---|
| 最高です → たまらん | character | 敬体を外す。**感情が高ぶっている** |
| 加 `……もう` | character | 言葉が続かない。激動の表現 |
| 方言は**回避** | — | **具体形が未確証のため創作しない**（G8） |

> **この例が示す判断の型**：方言を使うべき場面でも、
> **具体形が分からなければ標準語で代用し、【待确认】に出す**。
> 出典の「五告赞」は**台湾訳の閩南語**であって日本語の岐阜弁ではないため、
> そのまま使うことはできない。
