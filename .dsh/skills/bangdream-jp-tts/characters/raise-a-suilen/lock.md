## speech_style

### 定位：内向的努力家。拿起吉他就会改变

条目原文：
- 「虽然是**饱尝艰辛的幸运 E**，但**总是什么事都全力以赴**」
- 「在性格上**略有内向**，然而**拿起吉他的时候感觉更像是变了一个人**」
- 「平常戴着的眼镜和发带是**能力限制器**，当摘下眼镜和发带时则是**能力全开**」
- 「**Poppin'Party 的铁粉**」

→ 关键词是 **「内向」「全力」「靠吉他变身」「PPP 粉」**。

### 语体

**常体 + 「〜さん」称呼。** ★ **RAS 中唯一对所有人都加敬称的人**。

| 对象 | 六花的称呼 |
|---|---|
| 和奏レイヤ | `レイヤさん` |
| 佐藤益木 | `ますきさん` |
| 鳰原令王那 | `パレオさん` |
| 珠手知由 | `チュチュさん` |
| 高松燈 | `燈ちゃん` |
| 長崎そよ | `そよちゃん` |

→ 益木・令王那对其他成员直呼其名，而**六花对所有人都加「さん」**。
这是她**既是后辈又内向**的体现。**不要丢掉这个敬称**。

### ★ 岐阜腔 —— 本角色最重要的语言特征

**出处 `轶事` 中明确记载**：

> 「因为**出身岐阜县**的关系，朝日六花在**情绪激动时会说出方言**。
> 台湾的代理商木棉花在翻译时选择以同样作为在地语言的闽南语来重现，
> 其中最知名的是在加入 RAS 时的台词
> 「乐团实在...**五告赞**（棒呆啦）！」」

→ **条件触发**。平时是标准语，**情绪高涨时岐阜腔会冒出来**。

| 状态 | 语言 |
|---|---|
| 平常 | 標準語 |
| **情绪激动**（兴奋・感激・惊讶） | **岐阜腔会混入** |

**⚠️ 与 rimi 同类型的风险**：条目只写了「会说方言」，
**具体词汇只有 1 例（「五告赞」）**。而且那还是**台湾译本的闽南语**，
**并非日语的岐阜腔本身**。

→ **处理**：需要岐阜腔的场面，**先在 `【待确认】` 里问**。
不创作具体形式（G8）。与 `rimi.md` 的关西腔同样处理。

### emotional_style

**核心：虽然内向，但在吉他和伙伴面前会全力以赴。**

| 情绪 | 六花的表达方式（依据等级） |
|---|---|
| 兴奋 | **方言会冒出来**（条目明记）。标准语会崩塌 |
| 惊讶 | 低（推断） |
| 害羞 | 低（推断）。因为内向所以容易出现 |
| 悲伤 | 低（推断） |
| 生气 | 低（推断）。**不会怒吼** |
| 疑问 | 低（推断） |
| PPP 的话题 | **作为粉丝举止会改变**（条目明记） |
| 吉他 | **会「变身」**（条目明记） |

**关键区分 1：能力限制器**

条目原文：「**平常戴着的眼镜和发带是能力限制器**，
当摘下眼镜和发带时则是**能力全开**」。

→ 这虽是**演出上的比喻**，但可用于台词设计：
**平时克制，在演奏或认真的场面中骤变**。

**关键区分 2：努力之人**

条目原文：
- 「虽然是**特待生**，但其实在**读书上并不在行**，连运动其实也并不擅长，
  **吉他是她唯一努力练下来的东西**」
- 「从这些地方可以看出，为了梦想六花会**努力付出**，是个相当有**行动力**的女孩」

→ **不是才能，而是努力**。`天才` 系的台词不适合她。

**关键区分 3：学号 1 番**

条目原文：「因为名字开头为**あ**，因而学号被编排在 1 号」。

→ 梗。是否用于正文需要判断。

## TTS 特别注意

### 名字读音

| 表记 | 读音 | 风险 |
|---|---|---|
| 六花 | ろっか | **高。容易被误读为「りっか」「ろくはな」等** |
| 朝日 | あさひ | 低〜中（虽是普通词但是人名） |

**「六花 → ろっか」需要特别注意**。已登记在 `../../dictionary/pronunciation.yaml`。

### 通称的摇摆

`ロック`（通称）与 `六花`（本名）**会被按说话者分别使用**。
对 TTS 来说两者的读音都稳定（ロック / ろっか）。

**不过 `六花` 是汉字，所以有误读风险**——
在 Afterglow 称她 `六花` 的场面，有可能被读成 `りっか`。

### 方言的 TTS 风险

写岐阜腔时，会出现与 `rimi.md` 的关西腔相同的问题：
**音高重音与标准语不同**，因此用标准语的参考音频可能变得不自然。

→ 使用方言前请确认 `adapters/gpt-sovits.md` 的 D 类（参考音频影响）。
**不要在未验证的情况下积极采用。**

## examples

### 例 1：内向的日常台词

```text
角色：朝日六花
场景：レイヤに相談する
中文：  那个……莱雅小姐，我可以问一下吗？
AI：    あの、レイヤさん、聞いてもいいですか？
```

```text
✅ あの……レイヤさん、ちょっと聞いてもいいかな？
```

| 改动 | 层 | 理由 |
|---|---|---|
| いいですか → いいかな？ | character + sentence_ending | 常体。**因为内向而避免断定** |
| 加 `……` | tts + character | 语塞。内向的表现 |
| 加「ちょっと」 | character | 不强加于人的铺垫 |

### 例 2：情绪激动时说方言 —— 需要【待确认】的例子

```text
角色：朝日六花
场景：RAS 加入が決まった瞬間
中文：  乐队实在太棒了！
AI：    バンド、本当に最高です！
```

```text
✅ バンド、ほんとに……もう、たまらん！
   【待确认】岐阜弁の具体形が未確証。
   上記「たまらん」は標準語の強調形で回避した。
   岐阜弁を使う場合、方言の種類・強度を指定してください。
```

| 改动 | 层 | 理由 |
|---|---|---|
| 最高です → たまらん | character | 去掉敬体。**情绪正高涨** |
| 加 `……もう` | character | 话接不下去。激动的表现 |
| 方言**回避** | — | **具体形式未确证，因此不创作**（G8） |

> **这个例子展示的判断范式**：即使是应当使用方言的场面，
> **只要不知道具体形式，就用标准语代用，并放进【待确认】**。
> 出处的「五告赞」是**台湾译本的闽南语**，并非日语的岐阜腔，
