## speech_style

### 定位：最年长而可靠的大姐头。但是「狂犬」

条目原文：
- 「**RAS 成员中最年长者**」
- 「虽然**性格坚定可靠**，但**沉醉于演奏时会即兴制造非常喧闹的高难度声音**，
  十分可怕而被称为**"狂犬"**。**脸部表情也很可怕**」
- 「看起来**性格强硬**，其实**对可爱的东西也很感兴趣**，
  偶尔会被激发不太符合性格的好奇心」
- 「**小时候经常跟父亲和他的乐队成员们一起混**，耳濡目染地学到了许多
  玩音乐、玩乐团该有的**精神品质**。也因此先后开导过 RAS 大概除了 PAREO 的所有成员」

→ 关键词是 **「大姐头」「狂犬」「照顾人」「喜欢可爱的东西」**。

### 语体

**常体。粗糙但不粗暴。** 因为是大姐头，
所以用**带领后辈的说法**。

- 同辈・后辈：常体
- 年下（六花・令王那）：常体，有时是**指导的口吻**
- 「开导过除 PAREO 外的所有成员」→ **说教・建议会自然而然地出来**

### 两面性是核心

条目反复强调**反差**：

| 外侧 | 内侧 |
|---|---|
| 脸很可怕 | 喜欢可爱的东西 |
| 被称为「狂犬」的演奏 | 很会照顾人 |
| 看起来性格强硬 | 会被激起好奇心 |
| 上贵族学校 | 在拉面店里当厨师 |

→ **只写其中一面就会变成另一个人**。与 `tae.md` 的「天然 + 知性」要求同一种结构。

### 「狂犬」是演奏中的事

**重要**：仔细读条目原文，「狂犬」是
**「沉醉于演奏时会」**——也就是说**是演奏中的状态**。
**并非平时性格就粗暴**。

```text
❌ 常に威圧的で乱暴
✅ 普段は頼れる姉御。演奏に入ると豹変する
```

## TTS 特别注意

### 名字读音

| 表记 | 读音 | 风险 |
|---|---|---|
| ますき | ますき | 低（**假名**） |
| 佐藤 | さとう | 低〜中。以「さとう」稳定 |
| マスキング | マスキング | 低（片假名） |

**因为名字是假名，所以在 TTS 上是安全的**。与 `りみ` `たえ` 具有同样的优点。
唯一的汉字是姓「佐藤」，而这个不易误读。

### 狂犬模式与通常模式的语调差

**对 TTS 很重要的特征**：她**语调的音域很宽**。

- 通常：沉着的大姐头
- 演奏中：「狂犬」＝又高又激烈

→ 这是在 `adapters/gpt-sovits.md` 的验证清单 C 中，
想要确认**同一说话人能否表现出如此大的抑扬差**的项目。
参考音频的选法可能会影响结果（adapter 的 D 类）。

## examples

### 例 1：作为大姐头的建议

```text
角色：佐藤益木
场景：六花が悩んでいる
中文：  洛克，你在烦恼什么呢？说出来吧。
AI：    ロック、何を悩んでいるんですか？話してください。
```

```text
✅ ロック、何悩んでんだよ。言ってみろよ。
```

| 改动 | 层 | 理由 |
|---|---|---|
| 〜んですか → 〜んだよ | character + sentence_ending | 常体。作为年长者**踏进去** |
| 話してください → 言ってみろよ | character | **接近命令形的催促**。大姐头的说法 |
| 加 `よ` | character | 不是强加于人，而是**邀请**的语感 |

### 例 2：关于可爱东西的话题

```text
角色：佐藤益木
场景：可愛いグッズを見つける
中文：  啊，这个好可爱……不、不是我喜欢的风格。
AI：    あ、これ可愛い……いえ、私の好みではないです。
```

```text
✅ あ、これ可愛い……って、べ、別にそういうんじゃねーよ。
```

| 改动 | 层 | 理由 |
|---|---|---|
| 〜ではないです → 〜じゃねーよ | character | 常体。**掩饰的说法** |
| 加 `って、べ、` | character | **动摇时的口吃**。逞强崩塌的瞬间 |
| 加 `そういうんじゃ` | character | 辩解的固定说法 |

> **两面性的写法**：对可爱的东西有反应，同时**逞强**。
> 这是条目原文「看起来性格强硬，其实对可爱的东西也很感兴趣」的直接表现。
