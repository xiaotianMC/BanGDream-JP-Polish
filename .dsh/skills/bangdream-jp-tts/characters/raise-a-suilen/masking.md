## speech_style

### 定位：最年長の頼れる姉御。ただし「狂犬」

条目原文：
- 「**RAS 成员中最年长者**」
- 「虽然**性格坚定可靠**，但**沉醉于演奏时会即兴制造非常喧闹的高难度声音**，
  十分可怕而被称为**"狂犬"**。**脸部表情也很可怕**」
- 「看起来**性格强硬**，其实**对可爱的东西也很感兴趣**，
  偶尔会被激发不太符合性格的好奇心」
- 「**小时候经常跟父亲和他的乐队成员们一起混**，耳濡目染地学到了许多
  玩音乐、玩乐团该有的**精神品质**。也因此先后开导过 RAS 大概除了 PAREO 的所有成员」

→ キーワードは **「姉御」「狂犬」「面倒見」「可愛いもの好き」**。

### formality

**常体。粗いが乱暴ではない。** 「姉御」なので、
**後輩を引っ張る言い方**をする。

- 同輩・後輩：常体
- 年下（六花・令王那）：常体、時に**指導する口調**
- 「开导过除 PAREO 外的所有成员」→ **説教・助言が自然に出る**

### 二面性が核心

条目が繰り返し**ギャップ**を強調している：

| 外側 | 内側 |
|---|---|
| 顔が怖い | 可愛いもの好き |
| 「狂犬」と呼ばれる演奏 | 面倒見が良い |
| 性格強硬に見える | 好奇心を刺激される |
| 貴族学校に通う | ラーメン店で料理人 |

→ **片方だけ書くと別人**。`tae.md` の「天然 + 知性」と同じ構造の要求。

### 「狂犬」は演奏中の話

**重要**：条目原文をよく読むと「狂犬」は
**「沉醉于演奏时会」**——つまり**演奏中の状態**。
**普段から荒い性格なのではない**。

```text
❌ 常に威圧的で乱暴
✅ 普段は頼れる姉御。演奏に入ると豹変する
```

## TTS 特别注意

### 名字读音

| 表记 | 读音 | 风险 |
|---|---|---|
| ますき | ますき | 低（**仮名**） |
| 佐藤 | さとう | 低〜中。「さとう」で安定 |
| マスキング | マスキング | 低（片仮名） |

**名前が仮名なので TTS 的に安全**。`りみ` `たえ` と同じ利点。
唯一の漢字は姓「佐藤」で、これは誤読しにくい。

### 狂犬モードと通常モードの語調差

**TTS 的に重要な特徴**：彼女は**語調のレンジが広い**。

- 通常：落ち着いた姉御
- 演奏中：「狂犬」＝高く激しい

→ `adapters/gpt-sovits.md` の検証清单 C で、
**同じ話者でここまで抑揚の差が出せるか**を確認したい項目。
参考音声の選び方が結果を左右する可能性がある（adapter の D 類）。

## examples

### 例 1：姉御としての助言

```text
角色：佐藤益木
场景：六花が悩んでいる
中文：  洛克，你在烦恼什么呢？说出来吧。
AI：    ロック、何を悩んでいるんですか？話してください。
```

```text
✅ ロック、何悩んでんだよ。言ってみろよ。
```

| 改动 | 层 | 理由 |
|---|---|---|
| 〜んですか → 〜んだよ | character + sentence_ending | 常体。年長者として**踏み込む** |
| 話してください → 言ってみろよ | character | **命令形に近い促し**。姉御の言い方 |
| 加 `よ` | character | 押しつけではなく**誘い**の語感 |

### 例 2：可愛いものの話題

```text
角色：佐藤益木
场景：可愛いグッズを見つける
中文：  啊，这个好可爱……不、不是我喜欢的风格。
AI：    あ、これ可愛い……いえ、私の好みではないです。
```

```text
✅ あ、これ可愛い……って、べ、別にそういうんじゃねーよ。
```

| 改动 | 层 | 理由 |
|---|---|---|
| 〜ではないです → 〜じゃねーよ | character | 常体。**取り繕う言い方** |
| 加 `って、べ、` | character | **動揺のどもり**。強がりが崩れる瞬間 |
| 加 `そういうんじゃ` | character | 言い訳の定型 |

> **二面性の書き方**：可愛いものに反応しつつ、**強がる**。
> 条目原文の「看起来性格强硬，其实对可爱的东西也很感兴趣」の直接の表現。
