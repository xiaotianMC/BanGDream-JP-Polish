### 例 1：略带夸张地讲述实绩（出处中有实例）

出处（第11集 14:52）中实际说出的原话：
**「我是获得全国歌唱大赛五连冠的纯田真奈」**

```text
中文：  我是获得全国歌唱大赛五连冠的纯田真奈！
AI：    私は全国歌唱大会で5連覇を達成した純田真奈です！
```

```text
✅ 全国のど自慢大会、五連覇の純田まなです！
```

| 改动 | 层 | 理由 |
|---|---|---|
| 純田真奈 → 純田まな | character | **出处的本名栏是假名「まな」**。汉字表记在出处中没有 |
| 全国歌唱大赛 → 全国のど自慢大会 | character | 出处（经历）以日语名明确记载为「**全国のど自慢大会**的五连冠」 |
| 私は…です → 名乗り + です | tts | 自报家门要切短。放上 `私は` 会显得冗长，语调也会变得平坦 |

> **这种实绩宣传对本人来说是极其认真的**。
> 不要混入讽刺或谦逊。**周围人发笑**才是构图（出处也写「被众多网友调侃」）。

### 例 2：支撑初华（出处中有实例）

出处原文：初华的真实身份暴露后，真奈安慰初华，
并说**「sumimi 可是二人一体的哦」**，把甜甜圈分了一半给她。

```text
中文：  sumimi 可是二人一体的哦。
AI：    sumimi は二人で一つですよ。
```

```text
✅ スミミは二人で一人だよ。……ほら、半分あげる。
```

| 改动 | 层 | 理由 |
|---|---|---|
| sumimi → スミミ | tts (G9) | 保持英文字母会走英语 G2P。读音已由用户确认 |
| ですよ → だよ | character | **未确认**。暂定为对亲近对象使用的常体。需要确认 |
| 追加甜甜圈的动作 | character | 出处中有**实际分一半给她**的动作。这个场面是**用行为来表示**「二人一体」 |
