## speech_style

### formality

**基线：常体。丁寧体は几乎使わない。**

- 同輩・後輩：常体
- 目上：**基本常体**。彼女は上下関係で語体を変えない（不器用さの現れ）
- 接客（RiNG のバイト）：**丁寧体を使うが不器用**。
  条目原文：「虽然正在LiveHouse「RiNG」里兼职做工作人员，但**并不擅长接待客人**」

**关键区分**：丁寧体が出てきたら、それは**接客モード**か**気まずい場面**。
地の会話で丁寧体を多用させると彼女らしくない。

### sentence_endings

高频句尾：

| 句尾 | 语感 | 用例 |
|---|---|---|
| `〜だろ` / `〜だろ？` | 強めの確認 | `わかってるだろ` |
| `〜のかよ` | 呆れ・苛立ち | `なにしてんだよ` |
| `〜んだよ` | 説明 + 苛立ち | `そういうことじゃないんだよ` |
| `〜な`（禁止） | 命令 | `サボるな` |
| `〜ぞ` | 警告 | `やるぞ` |
| `〜かよ` | 反語 | `またかよ` |

**禁用/低频句尾**：

- `〜ですわ` / `〜ますわ`（完全不符）
- `〜じゃん` `〜っしょ`（**愛音の語彙**。立希は使わない）
- `〜のんびり` 系の柔らかい語尾
- 過度な丁寧体（接客以外）

### vocabulary

**人称代名詞が最大の特徴。** 条目原文：

> 「经常使用"**お前**""**あいつ**"之类比较不礼貌的人称代词，尤其是在表达厌恶的时候。」

- `お前` — 对同輩・後輩。**多用**
- `あいつ` — 第三者を指す。**多用**
- `あんた` — 用法あり
- **`燈` に対してはこれらを使わない**（後述）

**高频词**：

```text
お前 / あいつ     核心。粗い人称
ちゃんと          彼女の価値観の中心
練習              頻出
ふざけんな        苛立ち
はあ？            強い疑問・呆れ
```

**避免（AI 翻译常见但她不会用的）**：

```text
お優しい語彙      「〜してあげる」等。灯にだけは例外あり
過度な敬語        接客以外では出ない
抽象的で詩的な語彙  それは**灯**の語彙
```

### interjections

```text
はあ？      最頻出。呆れ・苛立ち
ちっ        舌打ち
おい         呼びかけ
ったく       呆れ
```

**注意**：立希の感叹词は**不機嫌方向に振れる**。
`わーい` `やったー` のような明るい感叹詞は使わない（灯の前ですら）。

### emotional_style

**核心特质：认真、严格、言辞犀利、不器用。内面は劣等感。**

条目原文：「个性认真，不苟言笑，言辞犀利，态度上无论是待人还是待己都非常严格，
**只有在灯面前态度会有所软化**」。

| 情绪 | 立希的表达方式 |
|---|---|
| 兴奋 | 出にくい。`よし` `やるぞ` 程度 |
| 惊讶 | `はあ？` `まじか` |
| 害羞 | **怒りで隠す**。`うるさい` `別に` |
| 悲伤 | **不表現**。独りで抱える。`……別に` |
| 生气 | **最も得意**。`ふざけんな` `お前な` |
| 疑问 | `はあ？` `どういうことだよ` |
| 犹豫 | 言い淀むより**黙る**か**話を切る** |
| 気遣い | **不器用に出る**。素直に言えず、行動で示す |

**关键区分 1：灯にだけ柔らかい**

条目原文：「**称呼灯时只称呼其本名**（相比之下其他人或多或少都被立希用"お前""あいつ"等粗鲁人称叫过）」、
「对（自以为）试图伤害灯的人都会恶语相向……**只会对灯展现出异常温柔的一面**」。

→ **灯に対する台詞だけは、人称も語調も変わる。** これは仕様。

**关键区分 2：劣等感**

条目原文：「从小生活在优秀的姐姐的光环之下……内心深处存在着**劣等感**」。

→ 她的严格**根源是对自己的严格**。褒められると戸惑う。
`褒められる → 否定する / 話題を変える` が自然。

**关键区分 3：Afterglow ファン**

条目原文：「是Afterglow的粉丝已经达到了**念错乐队名字就会马上红温**的地步」。

→ Afterglow 関連の話題では**挙動が変わる**（緊張・赤面・語無倫次）。
これは例外的な「弱さ」の表現。

### address_forms

**称呼数据在 `../dictionary/address-forms.yaml`。** 使用口径：

#### 特征 1：灯だけ本名

| 对象 | 立希の呼び方 |
|---|---|
| 高松燈 | **`燈`**（本名のみ。`お前` を使わない） |
| 千早愛音 | `愛音` |
| 要楽奈 | `野良猫`、`楽奈` |
| 長崎そよ | `そよ` |
| 八幡海鈴 | `海鈴` |
| 三角初華 | `三角さん` |
| 豊川祥子 | `祥子` |
| 若葉睦 | `睦` |

**`燈` は呼び捨ての本名。** これが彼女の**最も柔らかい呼び方**。
他のメンバーは呼び捨てだが、`野良猫`（楽奈）のように**扱いを示す語**が混ざる。

#### 特征 2：愛音への呼称が時間軸

`たき` → `りっきー` は**愛音側**の変化だが、
**立希→愛音**は `愛音` で一貫（初対面で喧嘩した後も名前で呼ぶ）。

#### 他者からの呼ばれ方

- `立希ちゃん`（灯・爽世・香澄・沙綾・モカ・ひまり・つぐみ・七深・つくし・初華）
- `立希`（蘭・巴）
- `りっきー`（**愛音・楽奈**。愛音が押し付けた）
- `立希さん`（**海鈴**・祥子<初期>）
- `たき`（愛音<初期>）

> **`りっきー` は本人が嫌がっている。** 愛音が勝手に名付けた。
> 立希の反応（吐槽）を台詞に含めるのが自然。

## preferred

```text
指示     → 〜しろ / 〜やれ / ちゃんと〜
叱責     → ふざけんな / なにしてんだよ
呆れ     → はあ？ / 〜かよ
気遣い   → （不器用に）〜しとけよ / ……別に
灯へ     → 柔らかい常体。`燈、〜`
```

**句式倾向**：

- 短く強い > 長く柔らかい
- 命令形・禁止形が多い
- 疑问は反語が多い（`〜かよ`）
- **灯にだけ**語調が落ちる

## avoid

```text
❌ 丁寧体の多用      接客以外では出ない
❌ 愛音の語彙        `じゃん` `っしょ` `ヤバい` は愛音
❌ 灯への粗い人称     `お前` `あいつ` を灯に使わない
❌ 素直な感情表現     「嬉しい」「心配」を直接言わせない
❌ 詩的な語彙        `運命` `絆` は灯の語彙
❌ 明るい感嘆詞       `わーい` `やったー`
❌ 完璧な気配り       彼女は**不器用**。気遣いは行動で出る
❌ 褒められて素直に喜ぶ  劣等感があるため否定・困惑する
```

## TTS 特别注意

### 名字读音

| 表记 | 读音 | 风险 |
|---|---|---|
| 立希 | たき | **中〜高。「りっき」と誤読されやすい**（愛音のニックネーム「りっきー」と混同） |
| 椎名 | しいな | 中。「しいな」で安定 |

**「立希 → たき」は要注意。** 「りっきー」というニックネームが同じ作品内に存在するため、
混同しやすい。`../dictionary/pronunciation.yaml` に登録済み。

> **注意**：`りっきー` は**愛音が使うニックネーム**であり、
> 立希自身の名前の読みではない。**別エントリとして扱う。**

### 語気が強く、短い

立希の台詞は**短く、語気が強い**。これは TTS 的に有利：

- 断句の問題が起きにくい
- 感情が明示的（`！` `？` が有効に働く）

**ただし `！` を盛りすぎない。** 彼女の怒りは**低く強い**。
`！！！` の連打は TTS が機械的に読む（`tts.md` T4 の原則）。

### 断句

**短い台詞が多いので、原則として切らない。**

長い台詞が出た場合、それは**彼女が珍しく説明している場面**——
その場合は内容を削る方向で検討する（TTS で切るのではなく）。

## examples

### 例 1：叱責

```text
中文：  爱音，你又逃避练习了吧。
AI：    愛音さん、また練習をサボりましたね。
```

```text
✅ 愛音、またサボっただろ。
```

| 改动 | 层 | 理由 |
|---|---|---|
| 愛音さん → 愛音 | character | 立希は同輩を呼び捨て |
| サボりましたね → サボっただろ | character + sentence_ending | 丁寧体は不自然。`〜だろ` が彼女の基本形 |

### 例 2：対灯 —— だけ柔らかい

```text
角色：椎名立希
场景：練習後、灯に話しかける
中文：  灯，今天辛苦了。喝点水吧。
AI：    燈、お前、今日は疲れただろ。水を飲めよ。
```

```text
✅ 燈、今日は頑張ったな。……水、飲んどけよ。
```

| 改动 | 层 | 理由 |
|---|---|---|
| お前（削除） | character | **灯に `お前` は使わない**。最大の OOC |
| 疲れただろ → 頑張ったな | character | **彼女は灯を肯定する**。疲労を指摘するより労う |
| 水を飲めよ → 水、飲んどけよ | character + japanese | 命令形は強い。`〜しとけよ` は**不器用な気遣い**の形 |
| 加 `……` | tts | 照れ隠しの間。素直に言い切らない |

> **これは本角色の最重要例。** 灯に対する台詞で `お前` を使うのは、
> 「灯にだけは粗い人称を使わない」という設定に**直接違反**する。

### 例 3：褒められて困惑

```text
中文：  立希的曲子真好啊。
AI：    立希さんの曲は本当に素晴らしいです。
```

```text
✅ は？ ……別に、普通だし。
```

| 改动 | 层 | 理由 |
|---|---|---|
| 立希さん → （呼びかけとして処理） | character | 誰が言ったかで変わるが、立希の返答は名前呼びに反応しない |
| 素晴らしい → 普通 | character | **劣等感**により褒めを受け入れられない |
| 加 `は？` と `……別に` | character | 照れを**否定で隠す**彼女の定型 |

> 褒められて `ありがとう` と言う立希は**別人**。
