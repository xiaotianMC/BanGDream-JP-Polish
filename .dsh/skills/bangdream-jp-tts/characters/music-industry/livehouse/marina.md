## speech_style

### formality

**基線は常体。ただし接客業なので相手で切り替わる。**

音声 17 行の実測：

| 指標 | 件数 |
|---|---|
| **常体**（だ / よ / ね / かな 終止） | **8** |
| です・ます | **1**（後述のボケ） |
| 一人称 `私` | 1 |
| `君`（相手＝玩家） | 1 |

→ ★ **常体が基線**。相手は**玩家（新手スタッフ）＝後輩**である。

**★ です・ます の唯一の実例は「ボケ」である：**

```text
小さな仕事の積み重ねが明日への一歩を切り開くです！……なんちゃって～
```

→ ことわざ風の**もっともらしい一文を丁寧体で言い切り**、
直後に `……なんちゃって～` で**自分から崩す**。
**敬体は「気取るための道具」であり、素の語体ではない。**

> ⚠️ **客・出演者への語体は未収録。**
> 職務上は丁寧体と推定されるが、**実例が無いので確定しない**（G8）。
> 店員としての定型（`いらっしゃいませ` 等）も出典に無い。
> **→ 接客場面の台詞は【待确认】に出す。**

### sentence_endings

| 句尾 | 语感 | 用例（音声実例） |
|---|---|---|
| `〜だよ` | 親しみ。多用 | `仕事が山積みだよ～` / `用意したんだ` |
| `〜だね` | 同意・労い | `がんばってるみたいだね` / `またきたね` |
| `〜かな` | 柔らかい提案・独白 | `いいかな？` / `どれにしようかな` |
| `〜からね` | 念押し（恩着せがましくない） | `またプレゼントあげるからね！` |
| `〜てね` | お願い | `たのしみにしてて` / `大事にしてね！` |
| `〜でしょ？` | **得意げな確認** | `用意したでしょ？` |
| `〜なかしなくていいよ` | ※ 音声表記のまま | `遠慮なかしなくていいよ` |

**禁用/低频句尾**：

- `〜であります` 等の過剰敬体 —— 彼女の敬体は**ボケの手段**であって基線ではない。
- **硬い断定（〜である / 〜だ。と切り捨て）** —— 音声 17 行に無い。
  彼女は**必ず柔らかく包む**。

> ★ **長音符 `—` を語尾に伸ばす癖**（`よろしく—！` `頑張ろう—` `あるんだ—！`）。
> 音声表記に繰り返し出る。**TTS 的には伸ばしとして重要**（下記参照）。

### vocabulary

**高频词（characteristic）**：

```text
プレゼント / いいもの / 用意する / 奮発する
がんばる / がんばってる / お疲れ様 / 感心
仕事 / 山積み / 頼みたいこと
調子 / 気に入って / 喜んで / 大事にして
```

★ **「プレゼント」が中心的語彙**。出典に「**麻里奈小姐的礼物箱**」という
節が独立しているほど、彼女の音声は**景品を渡す場面**に集中している。

★ **`うん、感心感心！`** —— **同じ語を重ねて褒める**形。
音声に `感心感心` と実際に出る。

**避免**：

- 音楽論・技術論の長い語り —— 彼女は**演奏の評価者ではない**
  （それは詩船の役割）。`preferred` 参照。
- 過度に丁寧な接客語 —— 上記のとおり素の語体ではない。

### emotional_style

**核心特质**：**明るく面倒見がよく、親しみを込めて茶化す**。

| 情绪 | 表达方式 |
|---|---|
| 兴奋 | 「いいものがある！」と**景品を煽る**。`奮発したんだ～！` |
| 惊讶 | **実例なし**。ただし `おっ` の気づきはある |
| 害羞 | **実例なし** |
| 悲伤 | **実例なし**。★ ただし**過去の挫折**はある（下記） |
| 生气 | **実例なし**。★ 彼女は**怒らない**——毒舌は「奸商」と評される**営業スマイルの裏側**として出る |
| 疑问 | `調子はどう？` `気に入って？` —— **相手を気遣う問い**が基本 |
| 犹豫 | **実例なし** |
| 吐槽 | ★ **「麻里奈小姐的礼物箱」がこれ**。景品がショボいのに**満面の笑みで渡す** |

**关键区分**：**最容易混同するのは 真次凛々子**（同じ LiveHouse スタッフ）。

| | 麻里奈 | 凛々子 |
|---|---|---|
| 職場 | **CiRCLE**（プレイヤーの職場） | **RiNG**（燈・立希のバイト先） |
| 出典の位置づけ | **「新手工作人员的首位角色」「前辈」** | 元 SPACE 従業員、現在 RiNG |
| 役割 | **景品箱・売店 NPC**。プレイヤーを茶化す | **設備からカフェまで担当**。後輩を指導 |

> ★ **麻里奈の「奸商」は二次的なネタ**。
> 出典が明記する本来の人物像は：

## preferred

```text
景品を渡す場面       → 満面の笑み + 過剰な煽り。中身のショボさは隠す
後輩を労う場面       → 「がんばってるね」「感心感心！」
依頼する場面         → 「〜なんだけど……いいかな？」と柔らかく切り出す
過去を語る場面       → 「始動前に解散した」という挫折。湿っぽくせず淡々と
```

**句式倾向**：

- **語尾を伸ばす**（`〜だよ～` `〜しよう—`）。これが彼女の温度感。
- **同じ語を重ねて褒める**（`感心感心`）。
- **持ち上げてから茶化す**。または**茶化してから本気で労う**。
- **命令形を使わない**。`〜してね` / `〜してて` で依頼する。

## avoid

```text
❌ 硬い敬語・過剰な丁寧体          # 敬体はボケの手段。基線ではない
❌ 冷たい「奸商」キャラ             # 根底は「音楽を志す人を応援したい」
❌ 音楽の技術論・演奏の評価         # それは詩船の役割
❌ 怒り・強い断定                   # 音声 17 行に一つも無い
❌ 客にも常体                      # 常体は親しい後輩に対して。接客は別（ただし実例未収録）
❌ `君` を全員に使う                # 音声の `君` は玩家（後輩）に対してのみ
```

## TTS 特别注意

### 名字读音

| 表記 | 读音 | 备注 |
|---|---|---|
| 月島 | つきしま | |
| 麻里奈 | **まりな** | ★ **日本語は平仮名で書かれる**（出典の本名欄・音声ファイル名ともに `まりな`）。`マリナ` は若宮イヴの**呼び方**であって本人の表記ではない |
| 麻里奈（中文名） | — | 出典は「月岛麻里奈」 |

> ★ **`まりな` は平仮名が正**。`牛込りみ`・`花園たえ`・`苗` 系と同じ扱い。
> **本文では `まりな` と書く。**
> ただし**他角色が片仮名で呼ぶ場合**（イヴの `マリナさん`）は、
> **呼称はそのまま**にする——発話者の表記だから。

### 断句

**音声に長音符が多い**：

```text
仕事仕事—！よろしく—！
うう～仕事が山積みだよ～……頑張ろう—
がんばってるみたいだね
```

→ ★ **`—`（長音符の代用ダッシュ）と `～`（波ダッシュ）が混在**。
**TTS 的には伸ばしとして扱われるべき**だが、
**ダッシュ `—` をどう読ませるかは未検証**（`adapters/gpt-sovits.md`）。

> ⚠️ 出典の表記をそのまま使うと**記号依存**になる。
> **片仮名の長音符 `ー` に正規化する**か、記号を残すかは
> **実機検証後に決める**。→【待确认】。

### `遠慮なかしなくていいよ` について

音声に `遠慮なかしなくていいよ` と記録されている。
標準語としては `遠慮しなくていいよ` が自然。

→ **出典の誤記の可能性がある**（`なかし` は一般的な形ではない）。
**推測で直さない**（G8）。台詞に使うなら【待确认】に出す。

## examples

> ★ **下の 2 例は音声の実例に基づく**（語体の根拠がある数少ない例）。

### 例 1：景品を渡す（出典の音声そのまま）

```text
中文：  怎么样，喜欢吗？嗯，不用跟我客气喔！
AI：    どうですか、気に入りましたか？はい、遠慮しないでくださいね！
```

```text
✅ どう、気に入って？うん、喜んでもらえたらよかった
```

| 改动 | 层 | 理由 |
|---|---|---|
| どうですか / 気に入りましたか → どう、気に入って？ | character | **音声の実例そのまま**。常体 + 短い問い |
| 遠慮しないでくださいね → （削除） | character | 音声では**この文が無い**。丁寧体に寄せると彼女でなくなる |
| 喜んでもらえたらよかった を追加 | character | 音声実例。**押し付けず、相手の喜びを基準にする**のが彼女 |

### 例 2：仕事を頼む（音声の実例ベース）

```text
中文：  有些事情想请你帮忙……可以吗？
AI：    お願いしたいことがあるのですが……よろしいでしょうか？
```

```text
✅ 君に頼みたいことがあるんだけど……いいかな？
```

| 改动 | 层 | 理由 |
|---|---|---|
| お願いしたいのですが → 頼みたいことがあるんだけど | character | **音声の実例そのまま**。`〜んだけど` で柔らかく切る |
| よろしいでしょうか → いいかな？ | character | 音声実例。**丁寧体ではなく常体 + `かな`** |
| 相手を `君` に | character | 音声実例。**玩家（後輩）に対してのみ** |
