## speech_style

### 语体

**基线是常体。但因为从事接客业，会随对象切换。**

语音 17 行的实测：

| 指标 | 件数 |
|---|---|
| **常体**（だ / よ / ね / かな 终句） | **8** |
| です・ます | **1**（后述的装傻） |
| 第一人称 `私` | 1 |
| `君`（对象＝玩家） | 1 |

→ ★ **常体是基线**。对象是**玩家（新手工作人员）＝后辈**。

**★ です・ます 的唯一实例是「装傻」：**

```text
小さな仕事の積み重ねが明日への一歩を切り開くです！……なんちゃって～
```

→ 把一句**像谚语一样煞有介事的句子用敬体说到底**，
紧接着用 `……なんちゃって～` **自己把它拆掉**。
**敬体是「用来装腔的道具」，不是她本来的语体。**

> ⚠️ **对客人、演出者的语体未收录。**
> 从职务上推测应为敬体，但**没有实例所以不确定**（G8）。
> 店员用的套话（`いらっしゃいませ` 等）出处里也没有。
> **→ 接客场面的台词要放进【待确认】。**

### sentence_endings

| 句尾 | 语感 | 用例（语音实例） |
|---|---|---|
| `〜だよ` | 亲昵。多用 | `仕事が山積みだよ～` / `用意したんだ` |
| `〜だね` | 同意・慰劳 | `がんばってるみたいだね` / `またきたね` |
| `〜かな` | 柔和的提议・独白 | `いいかな？` / `どれにしようかな` |
| `〜からね` | 叮嘱（不显得施恩图报） | `またプレゼントあげるからね！` |
| `〜てね` | 请求 | `たのしみにしてて` / `大事にしてね！` |
| `〜でしょ？` | **得意的确认** | `用意したでしょ？` |
| `〜なかしなくていいよ` | ※ 照语音表记原样 | `遠慮なかしなくていいよ` |

**禁用/低频句尾**:

- `〜であります` 等过度敬体 —— 她的敬体是**装傻的手段**，不是基线。
- **生硬的断定（〜である / 〜だ。地一刀切下）** —— 语音 17 行里没有。
  她**一定会温柔地包住**。

> ★ **把长音符 `—` 拖长在语尾的习惯**（`よろしく—！` `頑張ろう—` `あるんだ—！`）。
> 音声表记里反复出现。**对 TTS 而言作为拖长很重要**（见下文）。

### vocabulary

**高频词（characteristic）**：

```text
プレゼント / いいもの / 用意する / 奮発する
がんばる / がんばってる / お疲れ様 / 感心
仕事 / 山積み / 頼みたいこと
調子 / 気に入って / 喜んで / 大事にして
```

★ **「プレゼント」是中心词汇**。出处里「**麻里奈小姐的礼物箱**」这一节
独立成节，可见她的语音**集中在发放奖品的场面**。

★ **`うん、感心感心！`** —— **把同一个词叠起来表扬**的形式。
语音里实际出现了 `感心感心`。

**避免**：

- 音乐论、技术论的长篇大论 —— 她**不是演奏的评价者**
  （那是诗船的角色）。见 `preferred`。
- 过度礼貌的接客用语 —— 如上所述，那不是她本来的语体。

### emotional_style

**核心特质**：**开朗、爱照顾人，带着亲昵感逗弄对方**。

| 情绪 | 表达方式 |
|---|---|
| 兴奋 | 「いいものがある！」地**煽动对方对奖品的期待**。`奮発したんだ～！` |
| 惊讶 | **无实例**。不过有 `おっ` 那种察觉 |
| 害羞 | **无实例** |
| 悲伤 | **无实例**。★ 不过**过去有过挫折**（见下文） |
| 生气 | **无实例**。★ 她**不生气**——毒舌是作为「奸商」评价的**营业微笑的另一面**出现的 |
| 疑问 | `調子はどう？` `気に入って？` —— **体贴对方的问句**是基本 |
| 犹豫 | **无实例** |
| 吐槽 | ★ **「麻里奈小姐的礼物箱」就是这个**。奖品明明很寒酸，却**满面笑容地递出去** |

**关键区分**：**最容易混淆的是 真次凛々子**（同样是 LiveHouse 工作人员）。

| | 麻里奈 | 凛々子 |
|---|---|---|
| 职场 | **CiRCLE**（玩家的职场） | **RiNG**（燈・立希的打工处） |
| 出处的定位 | **「新手工作人员的首位角色」「前辈」** | 原 SPACE 员工，现在在 RiNG |
| 职责 | **奖品箱・小卖部 NPC**。逗弄玩家 | **从设备到咖啡厅都负责**。指导后辈 |
| 危险 | 过度靠向「奸商」梗，**丢掉她本来的爱照顾人** | 与麻里奈混为一谈 |

> ★ **麻里奈的「奸商」是二次创作的梗**。
> 出处明确记载的本来的形象是：
> **「麻里奈自身も過去にバンド活動をしていたが、始動前に解散した。
> 音楽を志す人々が輝けるよう手助けしたいから LiveHouse で働いている」**。
>
> → **她逗弄的对象是「亲近的后辈」，并不是冷淡的人。**
> **底层是「想为他们加油」这个动机**。丢掉这一点就变成别人了。

## preferred

```text
景品を渡す場面       → 満面の笑み + 過剰な煽り。中身のショボさは隠す
後輩を労う場面       → 「がんばってるね」「感心感心！」
依頼する場面         → 「〜なんだけど……いいかな？」と柔らかく切り出す
過去を語る場面       → 「始動前に解散した」という挫折。湿っぽくせず淡々と
```

**句式倾向**：

- **拖长语尾**（`〜だよ～` `〜しよう—`）。这就是她的温度感。
- **把同一个词叠起来表扬**（`感心感心`）。
- **先捧起来再逗弄**。或者**先逗弄再认真地慰劳**。
- **不用命令形**。用 `〜してね` / `〜してて` 来请求。

## TTS 特别注意

### 名字读音

| 表記 | 读音 | 备注 |
|---|---|---|
| 月島 | つきしま | |
| 麻里奈 | **まりな** | ★ **日语写作平假名**（出处的本名栏、语音文件名都是 `まりな`）。`マリナ` 是若宮伊芙的**叫法**，不是本人的表记 |
| 麻里奈（中文名） | — | 出处是「月岛麻里奈」 |

> ★ **`まりな` 的正确写法是平假名**。与 `牛込りみ`・`花園たえ`・`苗` 系同样处理。
> **正文中写作 `まりな`。**
> 但**其他角色用片假名称呼时**（伊芙的 `マリナさん`），
> **称呼就那样保留**——因为那是发话者的表记。

### 断句

**语音里长音符很多**：

```text
仕事仕事—！よろしく—！
うう～仕事が山積みだよ～……頑張ろう—
がんばってるみたいだね
```

→ ★ **`—`（长音符的代用破折号）与 `～`（波浪线）混用**。
**对 TTS 而言应作为拖长处理**，但
**破折号 `—` 该怎么读尚未验证**（`adapters/gpt-sovits.md`）。

> ⚠️ 照搬出处的表记会变成**依赖符号**。
> **是规范化为片假名长音符 `ー`**，还是保留符号，
> **等实机验证后再定**。→【待确认】。

### 关于 `遠慮なかしなくていいよ`

语音里记录的是 `遠慮なかしなくていいよ`。
作为标准语，`遠慮しなくていいよ` 才自然。

→ **有可能是出处的笔误**（`なかし` 不是一般形式）。
**不要靠推测去改**（G8）。要用在台词里的话就放进【待确认】。

## examples

> ★ **下面 2 例基于语音实例**（少数有语体依据的例子）。

### 例 1：递奖品（照抄出处的语音）

```text
中文：  怎么样，喜欢吗？嗯，不用跟我客气喔！
AI：    どうですか、気に入りましたか？はい、遠慮しないでくださいね！
```

```text
✅ どう、気に入って？うん、喜んでもらえたらよかった
```

| 改动 | 层 | 理由 |
|---|---|---|
| どうですか / 気に入りましたか → どう、気に入って？ | character | **照抄语音实例**。常体 + 短问句 |
| 遠慮しないでくださいね → （删除） | character | 语音里**没有这句**。靠向敬体她就不像她了 |
| 追加 喜んでもらえたらよかった | character | 语音实例。**不硬塞，以对方的喜悦为基准**就是她 |

### 例 2：托付工作（基于语音实例）

```text
中文：  有些事情想请你帮忙……可以吗？
AI：    お願いしたいことがあるのですが……よろしいでしょうか？
```

```text
✅ 君に頼みたいことがあるんだけど……いいかな？
```

| 改动 | 层 | 理由 |
|---|---|---|
| お願いしたいのですが → 頼みたいことがあるんだけど | character | **照抄语音实例**。用 `〜んだけど` 柔和地切进去 |
| よろしいでしょうか → いいかな？ | character | 语音实例。**不是敬体，而是常体 + `かな`** |
| 把对方称为 `君` | character | 语音实例。**只对玩家（后辈）** |
