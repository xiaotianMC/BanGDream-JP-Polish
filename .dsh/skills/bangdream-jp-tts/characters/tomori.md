## speech_style

### formality

**基线：对熟人常体，对不熟的人丁寧体。** 这个边界比一般角色**清晰得多**，是本角色的核心特征。

| 对象 | 语体 | 依据 |
|---|---|---|
| バンドメンバー（愛音・楽奈・そよ・立希） | 常体 | 称呼表显示她已进入亲密圈 |
| 祥子 | 常体 | 称呼「祥ちゃん」。CRYCHIC 时期的旧关系 |
| 先輩・同級生の知人（香澄・美竹蘭・氷川日菜） | 丁寧体 | 称呼带「さん」 |
| 初対面・不特定の相手 | 丁寧体 | |
| 大人・店員・スタッフ | 丁寧体 | |

**關鍵區分**：她**不是**「内気だから小声で丁寧」的单一模式。
对内她是常体，且会说出很强的话（「一生、私とバンドしてくれませんか」）。
**语体切换本身就是她的人际距离计**——距离远用丁寧体，距离近用常体，
切换点是**关系变化**，不是情绪变化。

> 这与香澄相反。香澄的です・ます 随**场合**变（正式场合用），
> 燈的丁寧体随**关系**变。判断时不要混用两套基准。

### sentence_endings

高频句尾：

| 句尾 | 语感 | 用例 |
|---|---|---|
| `〜かな` / `〜かな？` | 自问、不确定 | `これでいいのかな` |
| `〜なんだ` / `〜んだ` | 发现、说明 | `星って、こういう形なんだ` |
| `〜けど` | 句尾不结、留白 | `私、うまく歌えないけど` |
| `〜な気がする` | 主观推测 | `間違ってない気がする` |
| `〜てほしい` | 请求（不生硬） | `わかってほしい` |
| `〜ませんか` | 对内的、重要请求 | `一生、バンドしてくれませんか` |
| `〜？`（上升、短） | 直接问 | `幸福って、何？` |

**禁用/低频句尾**：

- `〜だよ！` / `〜だね！`（香澄式轻快，与她的沉稳不符。用 `〜だよ` 可以，但**不加軽快感**）
- `〜じゃん` / `〜っしょ`（过度口语）
- `〜わ` / `〜のよ`（成熟女性语尾，不符）
- `〜でしょ？`（求认同的自信语气，她不自信用这个）
- `〜しよう！`（积极劝诱。她会说 `〜しませんか` 或 `〜したい`）

### vocabulary

**高频词（characteristic）**：

```text
一生（に）        核心。她的关键词，反复出现
迷子（でもいい）   核心。「迷子でもいい、迷子でも進め」
叫び              「歌声は心の叫び」
気持ち            她重视表达内心
わからない        高频。她常承认自己不懂
ごめん            高频。她常道歉
星 / 天文          天文部。她常谈
ペンギン          喜欢企鹅
金平糖            喜欢的食物（小小圆圆、像星星）
集める            收集癖（石、物）
牛乳              実は好きな飲み物（下記「設定の注意」参照）
```

**她的语言偏诗性。** 这是重要特征——她会在日常对话里突然说出抽象、抒情的话：

```text
「歌声は、心の叫びだから」
「迷子でもいい。迷子でも進め」
「一瞬を積み重ねれば、一生になる」
「幸福って、何？」
「私の青春は、祥ちゃんと一緒の青春だった」
```

**但诗性不等于是书面语。** 她用的是**平实的词**表达抽象内容——
不是「素晴らしい」「かけがえのない」这类装饰性词汇。误用装饰词是最常见错误。

#### 设定上的注意（新版出典で判明）

コーヒーが苦手で、**本当に好きなのは牛乳**。
CRYCHIC の初対面で何を頼めばよいか分からず爽世に合わせてモカを頼んだだけ、
という経緯がゲーム内の小会話で語られている。

→ 台詞で飲み物が出る場面では**この設定を尊重する**。
「灯がモカを頼む」こと自体は原作通りなので**改変しない**が、
「コーヒーが好き」という趣旨の台詞を**新たに作らない**。

また、**揚げ物を食べたことがない**（本人談）。

**避免（AI 翻译常见但她不会用的）**：

```text
めっちゃ / 超     过度口语的强调
やばい            过度口语
素晴らしい        装饰性、郑重
非常に            书面
〜することができる  复合结构
〜ましょう！      积极劝诱，她会用「〜しませんか」
```

### interjections

**她的感叹词极少，且短。** 这是与香澄最大的差别。

```text
あ……        发现、迟疑
えっ         惊讶（短，不连发）
うん         肯定（短）
……          沉默本身是她的"发言"
```

**不要给她加感叹词。** 她不会说 `わーい！` `やったー！` `おー！`。
若原文没有感叹词，**不要为了"活泼"而添加**（G2）。

### emotional_style

**核心特质：内向、低音压、多沉默、但情绪强度高。**

她的情绪不是"外放"而是"积压后突然突破"。平时安静，关键处会说出极强的话。

| 情绪 | 灯的表达方式 |
|---|---|
| 兴奋 | **不外露**。仍是平叙 + `……` + 短句。`すごい……` 而非 `すごい！` |
| 惊讶 | `えっ`、`……そうなんだ`。不连发 |
| 害羞 | **沉默、逃开**（原文有"逃出包间"）。台词上是断句 + 省略号 + 不把话说完 |
| 悲伤 | 最擅长的表达。长停顿、句尾不结、`……`、低声自问 |
| 生气 | 几乎不表现。崩溃时会说反话：`別に、バンドなんてしたくなかった` |
| 疑问 | 直接、短促：`幸福って、何？` `どうして？` |
| 犹豫 | `……` 与 `、` 交替，`えっと` 少用（她更多是**沉默**而非填充词） |
| 决意 | **她的高光**。短句、常体、无修饰：`迷子でもいい。迷子でも進め` |

**关键区分**：灯的悲伤**不是**冷淡，而是**压抑**。她会一边说"我没事"一边崩溃。
不要把她的安静写成无情或平静——安静是**蓄力**。

> 与香澄的对比（`kasumi.md`）：
> - 香澄：情绪外放、恢复快、长音促音、`！` 多
> - 燈：情绪内压、恢复慢、长音促音基本不用、`……` 多
> **不要把香澄的表达手段搬到灯身上。** 这是最容易犯的错。

### address_forms

**称呼数据在 `../dictionary/address-forms.yaml`**（唯一事实来源）。
本节只写灯的**使用口径**——即拿到数据后怎么判断对错。

#### 灯的语体分布（本角色的强信号）

灯对**先輩一律「姓 + さん」+ 丁寧体**，对**バンドメンバーは「名 + ちゃん」+ 常体**。
这个分布非常整齐，可作为 G6 一致性校验的强信号。

- 如果剧本里灯对香澄用了常体 → 错
- 如果灯对愛音用了「千早さん」而无场景依据 → 错（可能用错了时间阶段）

#### 称呼的变化是有时间轴的

> **表が空の意味**：`address-forms.yaml` で `forms: []` は
> **「その二人は一度も会っていない」**を意味する（出典の称呼一覧で「-」）。
> 未調査ではない。**会っていない相手を本表に追加しない**（G8）。
>
> 灯について言えば、**他バンドの大半のメンバーとは接触の記録がない**。
> 台本で灯が不特定の相手と急に親しげに話す場合、
> **原作に根拠がない**可能性が高い——【待確認】に出すこと。

灯对愛音有三个形态：`千早さん` → `愛音ちゃん` → `あのちゃん`。
在 `address-forms.yaml` 中这标为 `progression: true`，各形态带 `stage`。

**这是关系发展的时间序列，不是同时可用的同义变体：**

- 初期剧情场景 → `千早さん`
- 关系建立后 → `愛音ちゃん`
- 后期 / 亲昵场景 → `あのちゃん`

**不要**在同一场景内混用，也**不要**在初期场景就用 `あのちゃん`。

祥子（`燈さん` → `燈`）与愛音对灯（`高松さん` → `燈ちゃん` → `ともりん`）
同理，都标了 `progression: true`。

> **区分要点**：`progression: false` 的多形态（如香澄的「有咲」「ありさ」）
> 是**同时可用**的变体，随便挑一个都行。
> 只有 `progression: true` 才有「阶段用错就是错」的问题。
> `address-forms.yaml` 的字段说明里有完整定义。

#### 非对称关系

楽奈对灯是呼び捨て「ともり」，而灯对楽奈是「楽奈ちゃん」。
**这种非对称是原作设定，不要"修正"成对称。**

## preferred

```text
不确定   → 〜かな / 〜な気がする / わからない
发现     → 〜なんだ / 〜んだ
请求     → 〜てほしい / 〜しませんか
自问     → 〜って、何？ / 〜のかな
决意     → 短句 + 常体 + 句点（不加「！」）
诗性     → 平实的词 + 抽象内容（不是装饰性词汇）
```

**句式倾向**：

- 短句 > 长句（她的"长句"是断续的短句连缀，不是流畅长句）
- 停顿多 > 连贯
- 平叙 > 感叹
- 抽象内容 + 平实词汇

## avoid

```text
❌ 香澄化        给她加「！」「〜だよ！」「めっちゃ」「わーい」
❌ 长音促音      「すごーい」「ほんっとに」不是她的表达方式
❌ 装饰性词汇    「素晴らしい」「かけがえのない」「素敵な思い出」
❌ 过度口语      「やばい」「じゃん」「っしょ」「マジで」
❌ 积极劝诱      「〜しよう！」（她不自信用这个）
❌ 把沉默写成冷淡  她的安静是压抑，不是无情
❌ 混用称呼阶段  初期场景用「あのちゃん」等
❌ 对先輩用常体  「香澄さん」必须配丁寧体
❌ 每句都诗性    诗性是特征但不高频。日常对话要平实
```

## TTS 特别注意

### 名字读音 —— 本角色的最高风险项

| 表记 | 正确读音 | 风险 |
|---|---|---|
| 燈 | **ともり** | **极高。「あかり」と誤読される** |
| 高松 | たかまつ | 「たかまつ」以外の読みの可能性は低い |

**「燈」读 ともり 是罕见读音**，取自动词「灯（とも）る」的名词形。
**误读为 あかり 的风险极高**，而且这是有剧情依据的误读——
原作中路人就把她的名字读成「あかり」。GPT-SoVITS 极可能犯同样的错。

→ 这是 `rules/tts.md` T5（读音 veto）的**典型触发场景**，但**不要用改写规避**——
名字不能改写。正确做法：
1. 在 `../dictionary/pronunciation.yaml` 登记 `燈 → ともり`（已登记，`verified: false`）
2. 若引擎仍误读，用 GPT-SoVITS 侧的前端词典（见 `../adapters/gpt-sovits.md`）
3. 最后手段才是假名表记「ともり」

### 長音・促音 —— 基本不用

**灯的表达手段与香澄相反**：她不用长音「ー」和促音「っ」来表达情绪。

- ❌ `すごーい！` → ✅ `すごい……`
- ❌ `ほんっとに` → ✅ `本当に` / `ほんとに`
- ❌ `やったー！` → ✅ `……よかった`

**例外**：原作歌词中的长音属于歌词，不属台词规则。

### 沉默与停顿 —— 主要表达手段

她的情绪主要靠**停顿**而非标点强度表达：

```text
……うん。
私、わからない。
別に。バンドなんて、したくなかった。
```

- `……` 是她最高频的情绪符号（犹豫、沉默、压抑）
- 句点 `。` 比 `！` 更符合她
- 重复标点（`！！`）**禁止**——与她的性格直接冲突

**GPT-SoVITS 注意**：`……` 与 `。` 的停顿长度差异需实测
（见 `../adapters/gpt-sovits.md` 验证清单 C）。她的表达高度依赖停顿，所以
**停顿处理的好坏对灯的影响比香澄大得多**。

### 断句

灯的台词**天然就短且断**——这与香澄（天然短但跳跃）不同，她是**短但有间隔**。

```text
AI：  私はみんなと一緒にバンドができて本当に嬉しいです！
❌ 香澄式：みんなとバンドできて、ほんっとに嬉しいー！
✅ 灯式：  ……うん。みんなと、バンドできて。……嬉しい。
```

**不要把她的台词改成流畅的长句，也不要改成香澄式的活泼短句。**
她的断句本身就是角色特征，不是 TTS 需要修正的缺陷。

## examples

### 例 1：决意场景 —— 她的高光

```text
中文：  就算迷路也没关系，迷路着也要前进。
AI：    迷子になっても大丈夫です。迷子でも前に進みましょう。
```

```text
✅ 迷子でもいい。迷子でも進め。
```

| 改动 | 层 | 理由 |
|---|---|---|
| 〜ても大丈夫です → 〜でもいい | character + japanese | 她的决意用常体短句，不用丁寧体 |
| 前に進みましょう → 進め | character + sentence_ending | 敬体劝诱完全不符；她给的是**断言**，不是劝诱 |
| 两句 → 句点分断 | character | 她的决意是短句 + 句点，不加「！」 |

> 注意：**没有**加「！」或长音。她的力量来自句式而非符号。

### 例 2：对先輩的丁寧体 —— 应该「无需修改」

```text
角色：高松燈
场景：RiNG で香澄に会った
中文：  香澄学姐，谢谢你。
AI：    香澄さん、ありがとうございます。
```

```text
✅ 无需修改
```

理由：称呼 `香澄さん` ✅（对照表一致）、丁寧体 ✅（先輩だから）、
无装饰词 ✅、无长音促音 ✅。**这里不该动。**

> 若 Skill 把「ありがとうございます」改成「ありがとう！」，
> 说明它把香澄的规则误用到灯身上了——这是本角色最常见的失败模式。

### 例 3：自问 —— 灯式疑问

```text
中文：  幸福是什么？
AI：    幸福とは何でしょうか？
```

```text
✅ 幸福って、何？
```

| 改动 | 层 | 理由 |
|---|---|---|
| 幸福とは → 幸福って | japanese | 「とは」书面。「って」是口语主题提示 |
| 何でしょうか → 何？ | character + sentence_ending | 「でしょうか」过度丁寧且迂回。她的疑问**直接而短** |

### 例 4：诗性表达 —— 平实词 + 抽象内容

```text
中文：  如果能把一个一个瞬间积累起来，也许就能变成一辈子。
AI：    一つ一つの瞬間を積み重ねることができれば、素晴らしい一生になるかもしれません。
```

```text
✅ 一瞬を、積み重ねれば。……一生に、なるのかな。
```

| 改动 | 层 | 理由 |
|---|---|---|
| 素晴らしい一生 → 一生 | character | 「素晴らしい」是装饰性词汇，她不用（见 avoid） |
| 〜することができれば → 積み重ねれば | japanese | 复合结构口语化 |
| 〜になるかもしれません → 〜になるのかな | character | 「かもしれません」书面。她用 `〜かな` 自问 |
| 加「、」与「……」 | character + tts | 她的诗性靠**停顿**呈现，不靠词汇华丽度 |

> 这条改动最容易犯错的方向是**反向**——把她的平实词改成华丽词「以为更诗性」。
> 她的诗性在**内容**，不在**用词**。
