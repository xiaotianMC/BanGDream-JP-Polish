## 人物像

- **Afterglow 的贝斯手**，就读于**羽丘女子学园**。
- **性格开朗和善的开心果**，经常因为**不会察言观色**而导致最后白忙一场。
- **乐队中最乐天的一员**，是五人的**协调者**、**Afterglow 的妈妈**，
  和**鸫**一起担任**中间人**的位置。
- **自愿担当乐团的队长**——★ 导致乐队名字差一点点就变成了「ひまりBand」。
- **整个 Afterglow 中最具有女子力的成员**。
- **非常重视朋友，纯粹而热烈**，总是一心一意帮助朋友。
- **泪点低**，对于感动系的故事没有抵抗力。
- **喜欢吃巧克力**，经常为了不停增加的体重发愁。
  ★ 名台词（正文引用）：**「吃这么多面包还不会胖的摩卡是大敌！」**
- **头脑比较简单**，经常成为乐队其他人的**捉弄对象**，可是自己又无力反抗。
  **从不因此而真正生气**。
- **非常健忘**：曾经忘了拿暑期作业的课本而让 Afterglow 不得不在黑灯瞎火的学校里
  呆了一晚上。
- **在家里其实是妹妹**（有姐姐）。
- **执着于当 Afterglow 可靠的队长**。认为自己没能达到这一要求时**会陷入自责**。
- **兰离队后和モカ两人在天台上继续着 Afterglow。**
- 是隔壁 **Hello, Happy World! 的濑田薫的铁粉**。
- 姓氏来自东京都涩谷区**上原**。

## examples

> ⚠️ **语体が未确认。** 下の例は「出处の事実」に限定して构成した。

### 例 1：円陣の挂け声（★ 出处に明记）

```text
角色：上原ひまり
场景：ライブ前の円陣
中文：  预备——！诶！诶！哦——！
AI：    せーの——！えい！えい！おー！
```

```text
✅ せーの——！えい！えい！おー！
```

| 改动 | 层 | 理由 |
|---|---|---|
| 挂け声はそのまま | character | ★ **出处明记の惯用句**。改写しない |
| `せーの` を追加 | japanese | 円陣の自然な挂け声。「预备」の対応 |
| `！` を残す | tts | 挂け声は**势いが必要**。标点を削らない |

> ★ **`【えい！えい！おー！】` は出处が明记した唯一の惯用句**。
> **胜手に変形しない**（「えいえいおー」と繋げるかは未确认）。

### 例 2：友人のことを思って泣く（★ 出典に实例あり）

出处原文：因为巴幻想的故事而**边哭边喊**。

```text
角色：上原ひまり
场景：巴の話を聞いて、感情が高ぶる
中文：  不要——！巴！不要离开我的身边！！
AI：    いや——！巴さん！私のそばを離れないでください！！
```

```text
✅ やだ——！巴！そばにいてよ！！
```

| 改动 | 层 | 理由 |
|---|---|---|
| `巴さん` → `巴` | character | 幼驯染。**直呼其名**（语体は推导） |
| 〜離れないでください → 〜いてよ | character | ★ **感情的になった時に敬体は不自然**（`rules/japanese.md` J1） |
| `！！` を残す | tts | ★ **泣き叫ぶ场面**。标点を弱めない |
| `私の` を削除 | japanese | 中文式の主语明示。日语では文脉で足りる |
