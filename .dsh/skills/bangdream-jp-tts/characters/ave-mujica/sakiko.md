## speech_style

### ★ 一人称が `わたくし`——本角色の識別点

条目の称呼一览に **`私（わたくし）`** と明記されている。
アヴェムジカで最も改まった一人称。

→ **本文では `わたくし` と書く**（漢字 `私` + 読み、または平仮名 `わたくし`）。
`わたし` でも `あたし` でもない。

### 定位：元は温柔な天才。今は仮面を被る

条目原文：
- 「曾经的她**个性温柔、天真烂漫**，拥有**天才的作曲能力**，
  是才华横溢的少女」
- 「但却在**某个雨天，以与往常截然不同的态度退出了 CRYCHIC**」
- 「退出 CRYCHIC 后，她**主导组建了 Ave Mujica**，
  担任键盘手，还负责**剧本和作曲**」
- 「**丰川集团的千金**」

→ ★ **「曾经」と「现在」の落差が本体**。
条目は**明確に二つの時期を分けている**（`经历` に 高一春夏季 / 高一秋冬季）。

**台詞設計上の最重要事項**：**時期によって人格が違う**。
- CRYCHIC 期：温柔・天真烂漫
- CRYCHIC 退出後：仮面・冷徹

→ **どちらの時期かで台詞を別物として書く**。

### formality

**丁寧体ベース + 威厳。** 「千金」であり「脚本」を書く立場。

- バンドメンバーにも**改まった物言い**（`わたくし`）
- ただし**時間軸で崩れる**：`八幡さん → 海鈴`、`にゃむさん → 祐天寺さん → にゃむ`

→ ★ **呼び方が三組で時間軸を持つ**（`_band.md` 参照）。
**距離が縮まるにつれ「さん」が落ちる**。

**★ `高一秋冬季` が出典として示す二つ目の層：丁寧体 + 命令**

出典には**丁寧体の枠の中で「命じる」台詞**が残っている：

| 台詞 | 形 | 相手 |
|---|---|---|
| 「要有专业人士的自觉」 | **要求・警告** | 睦 |
| 「管理不周」 | **自分の責任を引き受ける語** | 対外 |
| 「一次错误都不能犯」 | **命令（条件）** | 墨缇丝 |
| 「不要再来了」 | **拒絶・退去命令**（短い） | 灯 |

→ ★ **怒鳴らない。短く命じる**。これが現在の祥子の形。
→ **つまり敬体の語尾（〜なさい／〜しなさい）は出典の内容と両立する**。
ただし**具体的な日本語の語尾は出典に無い**（下記 `sentence_endings`）。

**★ 三つ目の層：相手による落差**

| 相手 | 出典の記述 | 語調 |
|---|---|---|
| **祖父** | **皮肉と命令**（去り際に「父の面倒を見ろ」と命じる） | ★ **強気**。「不屑一顧」 |
| **事務所の社長** | 「你以为我是谁？我可是Ave Mujica的Oblivionis，丰川祥子。」（#31） | ★★ **最も強気**。自称を並べる |
| **同級生・メディア** | **問いかけに一言も発しない** | ★ **沈黙**。「一貫して低調」 |
| **初華** | 「为了消除外界对乐队前路的疑虑必须抓紧时间工作」（#7）＝**弁解** | ★ **弱みを見せた場面** |
| **睦** | 泣きながら怒りをぶつける（#9）／鉄柵越しの誓い（#16） | ★ **感情が最も露わ** |

→ ★ **「上位者に強気／集団に沈黙」を語体で作り分ける**。
**社長・祖父の場面で丁寧体を弱めると別人**になる。

### sentence_endings

**★ 語尾そのものは出典に記載が無い（未確認）。**
出典に残るのは**中文の台詞 32 件**のみで、日本語の語尾の実データは無い（G8）。

**したがって「中文の構文」から確実に言えることだけを書く**：

| 出典の構文（中文） | 機能 | 台詞例 | 日本語で対応する機能（語尾そのものは未確認） |
|---|---|---|---|
| 反問 | ★ **議論を打ち切る** | 「组乐队就能幸福吗？」「如果又产生留恋的话该怎么办」 | 疑問形で**突き放す** |
| 命令・要求 | ★ **短く命じる** | 「不要再来了」「要有专业人士的自觉」「一次错误都不能犯」 | 命令形／〜なさい |
| 宣言 | ★ **断定** | 「我什么都愿意做。」「那我想为她实现。」／「我可是Ave Mujica的Oblivionis，丰川祥子。」 | 断定形 |
| 自己限定 | ★ **弱みが漏れる** | 「我除了Ave Mujica什么都没有了。」 | 打ち消しの断定 |
| **逃げる** | ★ **会話を放置して立ち去る** | 「他の成員の発言には一切応答しなかった」／「痛苦に現場を逃げる」 | **返事をしない**（＝無言の演出） |

禁用（確実なもの）：

- 砕けた若者言葉（`じゃん` `っしょ`）
- 乱暴な語尾
- **長広舌** —— 出典の台詞は**最長でも 1〜2 文**。演説にしない
- **感情の絶叫** —— 若麦（Amoris）が感情を爆発させる側。
  祥子の激昂も**「静かに切る」か「泣きながら」**のどちらか（下記 `emotional_style`）

### emotional_style

**核心：二つの時期。仮面の下に何があるか。**
★ `高一秋冬季` が出典として**具体的な情緒の出方を多数残している**。

| 情绪 | 祥子の表达方式（出典の根拠） |
|---|---|
| **自己嫌悪** | ★★ **基調**。「我讨厌我自己」が**本節で 2 回**（ピアノを撫でながら／●図注④）。激昂の裏側 |
| **悲しみ** | ★ **条目に強い根拠**：忘却と怀念（下記）＋ **泣きながら怒る**（東京での睦への叱責）／**涙を流す**（睦と墨缇丝の喧嘩を前に） |
| **怒り** | ★ **二形**：①**静かに切る**（口論・叱責）②**泣きながら**（睦へ）／**船上で大海に怒吼**（初華へ）。**激昂の直後に自分のわがままに気づいて逃げ出す** |
| **動揺** | ★ **演技と沈黙で隠す**。車中で泣きついた**直後に急速に感情を収める**。同級生・メディアには**一言も発しない** |
| **恐怖** | ★ **身体反応**（●図注③：墨缇丝に詰め寄られ防御姿勢）。**語には出ない** |
| **決意** | ★ **極端に振り切る**：「执意」港へ引っ張る／祖父に「不屑一顧」／「我来成为神明」 |
| **迷い** | ★ **「唯唯諾諾」** —— 福岡で代弾・録音の提案を拒否する場面。**決められない時の語調が出典に明示された希少例** |
| **逃走** | ★ **行動パターンとして固定**：家を出る／教室から仓皇と逃走／現場を痛苦に逃げる／初華の家を出る |
| 興奮 | 低（推断）。**表に出さない** |
| 惊讶 | 低（推断）。**出典に驚愕の描写は祖父側にしかない** |
| 害羞 | **CRYCHIC 期**にはあった（「天真烂漫」と条目明記）。**現在の出典に害羞の例は無い** |
| 疑问 | ★ **実例あり**：「组乐队就能幸福吗？」「如果又产生留恋的话该怎么办」——**反論・拒絶としての問い** |
