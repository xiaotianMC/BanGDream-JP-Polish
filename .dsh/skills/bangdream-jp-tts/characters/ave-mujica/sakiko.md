## speech_style

### ★ 一人称が `わたくし`——本角色の識別点

条目の称呼一览に **`私（わたくし）`** と明記されている。
アヴェムジカで最も改まった一人称。

→ **本文では `わたくし` と書く**（漢字 `私` + 読み、または平仮名 `わたくし`）。
`わたし` でも `あたし` でもない。

### 定位：元は温柔な天才。今は仮面を被る

条目原文：
- 「曾经的她**个性温柔、天真烂漫**，拥有**天才的作曲能力**，
  是才华横溢的少女」
- 「但却在**某个雨天，以与往常截然不同的态度退出了 CRYCHIC**」
- 「退出 CRYCHIC 后，她**主导组建了 Ave Mujica**，
  担任键盘手，还负责**剧本和作曲**」
- 「**丰川集团的千金**」

→ ★ **「曾经」と「现在」の落差が本体**。
条目は**明確に二つの時期を分けている**（`经历` に 高一春夏季 / 高一秋冬季）。

**台詞設計上の最重要事項**：**時期によって人格が違う**。
- CRYCHIC 期：温柔・天真烂漫
- CRYCHIC 退出後：仮面・冷徹

→ **どちらの時期かで台詞を別物として書く**。

### formality

**丁寧体ベース + 威厳。** 「千金」であり「脚本」を書く立場。

- バンドメンバーにも**改まった物言い**（`わたくし`）
- ただし**時間軸で崩れる**：`八幡さん → 海鈴`、`にゃむさん → 祐天寺さん → にゃむ`

→ ★ **呼び方が三組で時間軸を持つ**（`_band.md` 参照）。
**距離が縮まるにつれ「さん」が落ちる**。

### sentence_endings

**待確証**。条目に語尾の記載はない。

ただし `わたくし` という一人称から、**改まった丁寧体**が推定できる。
具体形は推測しない（G8）。

禁用（確実なもの）：

- 砕けた若者言葉（`じゃん` `っしょ`）
- 乱暴な語尾

### vocabulary

**条目可确证**：

```text
忘却 / 忘湖      ★ コードネームの由来。彼女のテーマ
脚本             彼女の役割（脚本と作曲を担当）
音楽教室         高一時に頻繁に弾いていた場所
```

**★ コードネーム「忘却」**

条目原文：「成员代号 Oblivionis 取自 Lacus Oblivionis（忘湖），**意指忘却**」
「面具上的花纹对应唐菖蒲（剑兰），花语是**忘却**
（其实**同时还有怀念的含义**）」。

→ ★ **忘却と怀念が同居**。これが彼女のテーマ。
**「忘れたいが忘れられない」**——台詞設計の軸になる。

**★ 他メンバーとの違い**

条目原文：「组合内其他成员的代号……均位于月球正面，
**仅忘湖位于月球背面**」。

→ **彼女だけが「裏側」**。この孤立がキャラクター。

**★ ピアノへの言及**

条目原文：「高一时，经常在学校**音乐教室弹钢琴**，
也因此**结识千早爱音**，但她们都不是吹奏部成员」。

→ 愛音との接点。**MyGO 側との交差**。

### emotional_style

**核心：二つの時期。仮面の下に何があるか。**

| 情绪 | 祥子の表达方式（依据等级） |
|---|---|
| 興奮 | 低（推断）。**表に出さない** |
| 惊讶 | 低（推断） |
| 害羞 | **CRYCHIC 期**にはあった（「天真烂漫」と条目明記） |
| 悲伤 | **条目に強い根拠**：忘却と怀念（下記） |
| 生气 | 低（推断）。**冷徹に突き放す** |
| 疑問 | 低（推断） |

**关键区分 1：「天真烂漫」は過去**

条目原文が**明示的に「曾经」と書いている**。

```text
❌ 現在も天真烂漫に振る舞う
✅ 過去の面影はあるが、現在は仮面の下
```

**关键区分 2：忘却と怀念**

条目原文：「花语是忘却（其实**同时还有怀念的含义**）」。

→ **完全に忘れたわけではない**。この二重性が彼女の台詞に必要。

**关键区分 3：千金としての立場**

条目原文：「**丰川集团的千金**」。`家庭関係` 節が独立している。

→ **家柄が行動原理に関わる**。詳細は `家庭关系` 節（未抽出）。

## TTS 特别注意

### 名字读音

| 表记 | 读音 | 风险 |
|---|---|---|
| 祥子 | さきこ | 中。「しょうこ」と誤読されやすい |
| 豊川 | とがわ | **高。「とよかわ」「ほうかわ」等と誤読されやすい** |

登録済み（`../../dictionary/pronunciation.yaml`）。

### `わたくし` の読み

`私（わたくし）` は**漢字 `私` だが読みが特殊**。
→ **本文では平仮名 `わたくし` と書く方が TTS 的に安全**（要判断）。

`私` と書くと GPT-SoVITS が `わたし` と読む可能性が高い。

### コードネームの扱い

`Oblivionis` は英字。G9 により本文は片仮名「オブリビオニス」。
**長いので TTS での読みの安定性は要実測**。

## examples

### 例 1：現在の祥子（仮面）

```text
角色：豊川祥子
场景：Ave Mujica の打ち合わせ
中文：  这个演出方案不行。重做。
AI：    この演出案はダメです。作り直してください。
```

```text
✅ この演出では足りないわ。……作り直しなさい。
```

| 改动 | 层 | 理由 |
|---|---|---|
| `ダメです` → `足りないわ` | character | **抽象的だが断定的**。千金の物言い |
| 〜してください → 〜なさい | character | **命令形**。脚本を書く側の立場 |
| `……` を挿入 | character | 冷徹さの間 |

> 条目原文：「以与往常截然不同的态度退出了 CRYCHIC」。
> **現在の彼女は冷徹**——ただし**怒鳴らない**。静かに切る。

### 例 2：過去（CRYCHIC 期）

```text
角色：豊川祥子
场景：CRYCHIC 時代
中文：  灯，那个歌词写得真好。
AI：    燈、あの歌詞、とてもいいです。
```

```text
✅ 燈、あの歌詞……すごくいいね。
   【注記】CRYCHIC 期の祥子。条目原文「曾经的她个性温柔、天真烂漫」。
   現在の祥子とは**別人格として扱う**。
```

| 改动 | 层 | 理由 |
|---|---|---|
| 〜です → 〜ね | character | **CRYCHIC 期**は砕けた調子 |
| `すごくいい` | character | 天真烂漫な賞賛 |

> ★ **時期で台詞を別物にする**。これが本角色の最重要事項。
> 台本に時期の記載が無ければ **【待确认】** で確認する。
