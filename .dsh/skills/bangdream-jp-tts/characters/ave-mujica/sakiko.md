## speech_style

### ★ 第一人称是 `わたくし`——本角色的识别点

条目的称呼一览中明记为 **`私（わたくし）`**。
是アヴェムジカ中最郑重的第一人称。

→ **正文中写作 `わたくし`**（汉字 `私` + 读音，或者平假名 `わたくし`）。
既不是 `わたし` 也不是 `あたし`。

### 定位：原本是温柔的天才。如今戴着面具

条目原文：
- 「曾经的她**个性温柔、天真烂漫**，拥有**天才的作曲能力**，
  是才华横溢的少女」
- 「但却在**某个雨天，以与往常截然不同的态度退出了 CRYCHIC**」
- 「退出 CRYCHIC 后，她**主导组建了 Ave Mujica**，
  担任键盘手，还负责**剧本和作曲**」
- 「**丰川集团的千金**」

→ ★ **「曾经」与「现在」的落差才是本体**。
条目**明确区分了两个时期**（`经历` 中有 高一春夏季 / 高一秋冬季）。

**台词设计上的最重要事项**：**不同时期人格不同**。
- CRYCHIC 期：温柔・天真烂漫
- CRYCHIC 退出后：面具・冷酷

→ **根据是哪个时期，把台词当作完全不同的东西来写**。

### 语体

**以敬体为基调 + 威严。** 既是「千金」，又是写「剧本」的立场。

- 对乐队成员也用**郑重的说法**（`わたくし`）
- 但会**随时间轴崩塌**：`八幡さん → 海鈴`、`にゃむさん → 祐天寺さん → にゃむ`

→ ★ **称呼在 3 组中拥有时间轴**（参见 `_band.md`）。
**随着距离拉近，「さん」会掉落**。

**★ `高一秋冬季` 作为出典显示的第二个层次：敬体 + 命令**

出典中残留着**在敬体框架内「下令」的台词**：

| 台词 | 形 | 对象 |
|---|---|---|
| 「要有专业人士的自觉」 | **要求・警告** | 睦 |
| 「管理不周」 | **承担自己责任的词** | 对外 |
| 「一次错误都不能犯」 | **命令（条件）** | 墨缇丝 |
| 「不要再来了」 | **拒绝・退去命令**（短） | 灯 |

→ ★ **不大声吼叫。简短地下令**。这就是现在祥子的形式。
→ **也就是说，敬体的语尾（〜なさい／〜しなさい）与出典的内容并不矛盾**。
不过**出典中没有具体的日语语尾**（见下文 `sentence_endings`）。

**★ 第三个层次：因对象而异的落差**

| 对象 | 出典的记述 | 语调 |
|---|---|---|
| **祖父** | **讽刺与命令**（临走时命令「照顾你父亲」） | ★ **强硬**。「不屑一顾」 |
| **事务所的社长** | 「你以为我是谁？我可是Ave Mujica的Oblivionis，丰川祥子。」（#31） | ★★ **最强硬**。罗列自称 |
| **同班同学・媒体** | **对询问一言不发** | ★ **沉默**。「一贯低调」 |
| **初華** | 「为了消除外界对乐队前路的疑虑必须抓紧时间工作」（#7）＝**辩解** | ★ **显露软弱的场面** |
| **睦** | 一边哭一边发泄怒火（#9）／隔着铁栅栏的誓言（#16） | ★ **感情最外露** |

→ ★ **用不同的语体来分别塑造「对高位者强硬／对群体沉默」**。
**在社长・祖父的场面削弱敬体就会变成另一个人**。

## examples

### 例 1：现在的祥子（面具）

```text
角色：豊川祥子
场景：Ave Mujica の打ち合わせ
中文：  这个演出方案不行。重做。
AI：    この演出案はダメです。作り直してください。
```

```text
✅ この演出では足りないわ。……作り直しなさい。
```

| 改动 | 层 | 理由 |
|---|---|---|
| `ダメです` → `足りないわ` | character | **抽象但断定**。千金的说法 |
| 〜してください → 〜なさい | character | **命令形**。写剧本一方的立场 |
| 插入 `……` | character | 冷酷的停顿 |

> 条目原文：「以与往常截然不同的态度退出了 CRYCHIC」。
> **现在的她冷酷**——但不**大声吼叫**。而是静静地斩断。

### 例 2：过去（CRYCHIC 期）

```text
角色：豊川祥子
场景：CRYCHIC 時代
中文：  灯，那个歌词写得真好。
AI：    燈、あの歌詞、とてもいいです。
```

```text
✅ 燈、あの歌詞……すごくいいね。
   【注记】CRYCHIC 期的祥子。条目原文「曾经的她个性温柔、天真烂漫」。
   与现在的祥子**作为另一个人格来对待**。
```

| 改动 | 层 | 理由 |
|---|---|---|
