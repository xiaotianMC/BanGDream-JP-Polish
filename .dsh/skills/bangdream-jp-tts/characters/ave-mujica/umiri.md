## ★ 这个角色的核心：**对「信任」的执着**

追踪上面的 `经历` 就会发现，海铃的行动**全部是对「不被相信」的反应**。
**#31（立希的「你不值得信任」）是转折点**，此后她
**持续思考那句话的含义**。

| # | 局面 | 出典的记述 |
|---|---|---|
| 31 | 被立希说「**你不值得信任**」 | ★★ 这是**转折点**。持续思考其含义 |
| 32 | 在支援对象 DISRUPTION 那里问成员 | 「自己真的不值得信任吗」→ **两人都回答「值得」** |
| 37 | 与若麦在咖啡店 | 讲述自己的过去，**承认对 CRYCHIC 的嫉妒** |
| 38 | 与若麦在咖啡店（续） | 被指出「**从没见过海铃自己主动承担责任**」 |
| 38 | → 察觉 | ★ **意识到「不值得信任」的含义** |
| 53 | 在 RiNG 的对决 | ★★ **亮出「辞掉了所有支援乐队」这张王牌，哭着恳求信任** |
| 58 | 再结成后，祥子与初华失踪 | ★★ **慌忙给祥子打电话，问「自己果然还是不值得信任吗」** |

**出典中残留的核心台词**：

```text
「我也是认真的，我想组 Ave Mujica，我想要互相信任！」
```

→ ★ **这是本角色的中心**。
**作为「支援」辗转于 30 支乐队的她，
不曾拥有过任何「被相信」的关系**。
「不值得信任」**不是对能力的否定，而是指她从未把真心托付给任何人**。

**在台词设计上**：
**「信 / 不信」是她词汇的中心**。
比起闲聊或工作的话题，**在关系的话题上她会变得多话**。

## speech_style

### 定位：职业支援乐手。沉着冷静

条目原文：
- 「**贝斯技巧达到了职业水准，曾同时担任 30 个乐团的支援乐手**」
- 「**个性沉稳冷静、善于察言观色**」
- 「和椎名立希、三角初华是**同一个班级**……
  **和立希是隔一位的前后桌，二人经常互相找茬**」

→ 关键词是 **「职业水准」「沉着冷静」「察言观色」「30 支乐队」**。

**★ 出典反复写到「冷静」（仅 `高一秋冬季` 就有 4 次）**：

```text
武道館で若麦が面具を剥いだ時       → 「保持了冷静」
睦が舞台上で倒れた時               → 「显得非常冷静」
解散を宣布された後                 → 「表现十分冷静」
他の議論・事件でも                 → 「显得比较冷静」
```

### 语体

**★ 基线是敬体。但只有对立希会混入常体。**

从出典的语体数据可以看出是**两层**：

| 对象 | 语体 | 出典的根据 |
|---|---|---|
| **立希** | **混入常体**（保持敬称） | ★ 实例众多（下表） |
| 若麦 | **敬体 + 讽刺** | 「因为我这张脸也算漂亮」（以敬体的材料回敬） |
| 初华・祥子 | **敬体** | 「那你直接去问她不就行了」（稍有松动） |
| 记者 | **拒绝** | 「其他人不说，难道你觉得我就会说吗？」 |
| 支援对象的成员 | **敬体** | 问「自己不值得信任吗」的场面 |

**★ 对立希的实例（出典中残留的台词）**：

```text
「找到我的人只有你一个。」              ← 鞄を投げられた時
「简直就像燃尽前的线香烟花一样呢。」      ← ノートを撮りながら
「到底想说什么啊？」                    ← 立希に「Mujica の一員なのか」と言われて
「（あなたは）何をした」                 ← 立希を噎せ返らせた一言
```

→ ★ 把 **`找到我的人只有你一个`** 改成敬体就会变成另一个人。
**只有这一句是常体，而且很短**。

**不过**：称呼是 **`立希さん`（不是姓，而是名 + さん）**，
敬体的框架**并没有崩**。
→ **「保持敬称而语尾松散」**——这就是她对立希的形式。

### sentence_endings

**由实例确认到的**：

| 句尾 | 用例 | 备注 |

| `〜不是吗` | `难道你觉得我就会说吗？` | 反问。对记者的拒绝 |
| `〜就行了` | （同上） | |
| `〜呢` | `简直就像燃尽前的线香烟花一样呢` | ★ **比喻 + 深有感触**。她的特征 |

**读 `高一秋冬季` 就会发现关系的本质在别处**：

```text
「回到学校后的海铃为了避免被同学围观，一下课就溜走了，
  只有立希能找到她。」
「被立希丢书包的海铃：找到我的人只有你一个。」
```

→ ★ **立希是「唯一能找到海铃的人」**。
「找茬」只是其**表面**，**「会来找自己的人」**才是本质。

**此外**：立希**直呼海铃的本名**（与 `立希さん` 方向相反）。
→ **非对称**：海铃 → 立希 是 `立希さん`，立希 → 海铃 是 `海鈴`。

**★ 身体能力的描写**

```text
「在立希直接把书包甩到她脸上时能双手接住，
  仅靠嘴里叼着的吸管没让纸包奶冻饮料掉下来」
「买的东西多到挂在双臂上如同光翼展开」
```

→ **接得漂亮的功夫，以及购物的量**。
**可用作台词的提示・停顿**（在 G8 的范围内）。

### address_forms

**称呼数据在 `../../dictionary/address-forms.yaml`。**
★ **本条目有称呼一览**，所以海铃→对方 是一次信息。

| 对象 | 海铃的称呼 |
|---|---|
| 豊川祥子 | `豊川さん` |
| 三角初華 | `三角さん` |
| 若葉睦 | `若葉さん` / `モーティスさん` |
| 祐天寺若麦 | `祐天寺さん` / `にゃむち` / `ニャムコ` |
| 椎名立希 | `立希さん`（★ **不是姓，而是名**） |

→ ★ **乐队内最有距离感的称呼方式**（对所有人都用「姓 + さん」）。
**例外是立希（名 + さん）和にゃむ（三种形态）**。

> ⚠️ **`立希さん` 是「名 + さん」**——
> 对其他的 Ave Mujica 成员都用姓，**只有立希用名**。
> **这是显示距离缩近的唯一称呼上的证据**。

**她自己怎么被称呼**：
- `海鈴` / `海鈴ちゃん`（**睦**）
- `海鈴ちゃん`（**初華**）
- `八幡さん`（**祥子**）/ `ウミコ`（**にゃむ**）
- `立希 → 海鈴 も `海鈴`（直呼其名）
- `八幡さん`（其他众多乐队）

> ★ **`ウミコ` 是にゃむ的发明**（片假名的爱称）。
> **并不是本人自称**。

**句式倾向**：

- ★ **使用比喻**（線香花火）。
- ★ **以反问回击**（「直接问不就行了」「你做了什么」）。
- ★ **切得短**。不发长篇大论。

## TTS 特别注意

### 名字读音

| 表记 | 读音 | 风险 |
|---|---|---|
| 海鈴 | うみり | **高。容易被误读为「うみすず」**（鈴→すず 的联想） |
| 八幡 | やはた | 中。容易被误读为「はちまん」 |
| Timoris | ティモリス | 代号。英文字母 → 正文用片假名 |

★ **两者都有误读风险**。已登记（`../../dictionary/pronunciation.yaml`）。

### 沉着冷静的语调

「沉稳冷静」，所以**抑扬要克制**。不适合多用 `！`。

**不过有两个会改变温度的对手**：

```text
立希  → 混入常体（「找到我的人只有你一个」）
若麦  → 唯一披露自己感情的场面（承认对 CRYCHIC 的嫉妒）
```

### 比喻的朗读

对应 `线香花火` 的日语是 **`線香花火`（せんこうはなび）**。
**从 TTS 角度是较长的复合词**——有时需要换气。

## examples

### 例 1：礼貌但有距离（支援对象・对外）

```text
角色：八幡海铃
场景：祥子に確認する
中文：  祥子，那份谱子，我可以拿一份吗？
AI：    祥子、その譜面、一部もらえますか？
```

```text
✅ 豊川さん、その譜面、一部いただけますか。
```

| 改动 | 层 | 理由 |
|---|---|---|
| `祥子` → `豊川さん` | character | ★ **对所有人都用「姓 + さん」**（出典的称呼一览） |
| `もらえますか` → `いただけますか` | character | **敬体**。作为职业人士的距离 |

> **不直呼 `祥子`**。出现就会 OOC。

### 例 2：对立希 —— 混入常体（★ 出典中有实例）

出典原文（被扔书包的场面）：**「找到我的人只有你一个。」**

```text
角色：八幡海铃
场景：立希に鞄を投げつけられて
中文：  找到我的人只有你一个。
AI：    私を見つけてくれる人は、立希さんだけです。
```

```text
✅ 俺を見つけられるのは、立希さんだけだよ。
```

| 改动 | 层 | 理由 |
|---|---|---|
| 〜です → 〜だよ | character | ★ **对立希会混入常体**（出典的实例群） |
| 维持 `立希さん` | character | ★ **不破坏敬称**。「敬称 + 常体」是她的形式 |
| `人は` → 缩短语序 | tts | 出典的台词是**短句**。变长会显得沉重 |

> ⚠️ **第一人称**：出典中有 `找到我的人`，**`我` = 私**。
> 但**没有音频的发言例**，所以读作 `私` 还是 `俺` **未确认**。
> 上例中的 `俺` 是**临时**。→ 参见下面的【待确认】。

### 例 3：用比喻推开解散（★ 出典中有实例）

出典原文：**「解散乐队是迟早的事，能延续下去的乐队才是少数」** /
**「简直就像燃尽前的线香烟花一样呢。」**

```text
角色：八幡海铃
场景：立希に Ave Mujica の先行きを聞かれて
中文：  简直就像燃尽前的线香烟花一样呢。
AI：    まるで燃え尽きる前の線香花火のようですね。
```

```text
✅ まるで、燃え尽きる前の線香花火みたいだね。
```

| 改动 | 层 | 理由 |
|---|---|---|
| 〜のようですね → 〜みたいだね | character | 因为对方是立希，所以用**常体**。比喻保持不变 |
| `まるで` + `みたい` | japanese | **比喻的固定搭配**。比 `〜のようだ` 更口语、更自然 |

> ★ **这个比喻照出典原样**。不是编造的。
> **不感伤地谈论解散**——用比喻**保持距离**的才是她。

### 例 4：承认嫉妒（★ 出典中有实例）

出典原文：在与若麦的咖啡店，**讲述自己的过去，
承认看到 CRYCHIC 最后一场公演时感到嫉妒**。

```text
角色：八幡海铃
场景：若麦とのカフェで、自分の過去を語る
中文：  看到 CRYCHIC 的最后演出时，我很是嫉妒。
AI：    CRYCHIC の最後の公演を見た時、私はとても嫉妬しました。
```

```text
✅ ……クライシックの最後のステージ、見てたよ。
　　あれは、ずるいなって思った。
```

| 改动 | 层 | 理由 |
|---|---|---|
| `嫉妬しました` → `ずるいなって思った` | character | ★ **本人不使用「嫉妒」这个词**。以「ずるい」漏出来的形式更像她 |
| `見た時` → `見てたよ` + 换行 | tts | ★ **制造语塞**。**她讲述自己感情的唯一场面**——不让她一口气说完 |
| `CRYCHIC` → `クライシック` | tts (G9) | 不照抄英文字母的出典表记 |

> ★ **「冷静」的她披露自己感情的唯一场面**。
> 出典在此处写到**若麦惊讶于「从没见过海铃自己主动承担责任」**。
> → **只有这个场面用常体，而且还断断续续**。用敬体整理就会变成另一个人。

> ⚠️ **已删除的例子**：以前这里放着「对初华的嫉妒（`花心是吧？信不信我去告状？`）」，
> 但已查明**出典中这句台词被 `just-kidding-text`
> （＝玩笑框、`<s class="just-kidding-text">`）包着**。
> → **不是本篇的台词**，所以从例子中移除。
> 「对初华嫉妒」这一**事实的处理未经验证**（参见 `表记待确认`）。
