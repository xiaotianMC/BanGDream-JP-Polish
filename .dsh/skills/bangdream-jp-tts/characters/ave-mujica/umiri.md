## speech_style

### 定位：プロの支援ミュージシャン。沈着冷静

条目原文：
- 「**贝斯技巧达到了职业水准，曾同时担任 30 个乐团的支援乐手**」
- 「**个性沉稳冷静、善于察言观色**」
- 「和椎名立希、三角初华是**同一个班级**……
  **和立希是隔一位的前后桌，二人经常互相找茬**」

→ キーワードは **「職業レベル」「沈着冷静」「察言观色」「30 バンド」**。

**★ バンド内で最も距離を置く呼び方をする**

出典の称呼一览で、海鈴は**全員に「姓 + さん」**：

| 対象 | 海鈴の称呼 |
|---|---|
| 豊川祥子 | `豊川さん` |
| 三角初華 | `三角さん` |
| 若葉睦 | `若葉さん` / `モーティスさん` |
| 祐天寺若麦 | `祐天寺さん` / `にゃむち` / `ニャムコ` |

→ ★ **`祐天寺さん` だけは三形態**（`にゃむち` `ニャムコ` も併記）。
**にゃむに対してのみ距離が縮まっている**——この非対称が特徴。

**参考**：`sayo.md`（Roselia）も全員に「名字 + さん」だったが、
**海鈴の場合はさらに「プロ対プロ」の距離**である。

### ★ 「互相找茬」（立希との関係）

条目原文：「和立希是隔一位的前后桌，**二人经常互相找茬**」。

→ ★ **立希との掛け合いが定型**。
`taki.md` にも記載がある：
「同班的八幡海铃知道其在玩乐队，**两人关系不错，会互相送饮料**，
在立希需要海铃帮忙时可以**不用预约**……
甚至**知道海铃会去哪里**」。

さらに `taki.md` の `轶事` に：
「立希和海铃虽然**都喜欢喝画着熊猫的饮料**，但两人的**口味喜好不同**，
立希喜欢**巧克力**口味，海铃喜欢**蜜柑**口味，
**二人互相送饮料时都会送自己喜欢的口味而不是对方的**，
而初华送饮料的时候则**专门送了立希喜欢的口味**」。

→ ★ **具体的で使える材料**。海鈴は**蜜柑味**。

★ **両方とも誤読リスクがある**。登録済み（`../../dictionary/pronunciation.yaml`）。

### 沈着冷静な語調

「沉稳冷静」なので、**抑揚は控えめ**。
`！` の多用は似合わない。

**ただし立希相手の「找茬」では軽口**になるので、
**相手によって温度が変わる**。

## examples

### 例 1：丁寧だが距離がある

```text
角色：八幡海铃
场景：祥子に確認する
中文：  祥子，那份谱子，我可以拿一份吗？
AI：    祥子、その譜面、一部もらえますか？
```

```text
✅ 豊川さん、その譜面、一部いただけますか。
```

| 改动 | 层 | 理由 |
|---|---|---|
| `祥子` → `豊川さん` | character | ★ **全員に「姓 + さん」**（出典の称呼一览） |
| `もらえますか` → `いただけますか` | character | **丁寧体**。プロとしての距離 |

> **`祥子` と呼び捨てにしない**。出すと OOC。

### 例 2：立希への「找茬」

```text
角色：八幡海铃
场景：椎名立希に話しかける
中文：  立希，你在发呆吗？谱子写完了？
AI：    立希さん、ぼんやりしてますか？譜面は書けましたか？
```

```text
✅ 立希、また止まってる。譜面、進んでないでしょ。
```

| 改动 | 层 | 理由 |
|---|---|---|
| `立希さん` → `立希` | character | ★ **例外**。条目明記「互相找茬」 |
| 〜ますか → 〜でしょ | character | **軽口**。丁寧体を崩す |
| `また止まってる` | character | 観察している（「察言观色」） |

> ★ **この例外が本角色の人間味**。
> **全員に丁寧なだけでは別人**——立希にだけ軽口を叩く。
