## ★ この角色の核：**「信任」への執着**

`高一秋冬季`（8,853 chars）を抽出して、**本角色の主題が判明した**。

出典の経緯を追うと、海鈴の行動は**すべて「信じられていない」ことへの反応**である：

| 局面 | 出典の記述 |
|---|---|
| 立希に「**你不值得信任**」と言われる | これが**転機**。「不值得信任」の**意味を考え続ける** |
| 支援先の DISRUPTION で成員に問う | 「自分は本当に信用に値しないのか」→ **二人とも「値する」と答える** |
| 若麦とのカフェ | 「**海鈴が自分から責任を負うのは見たことがない**」と指摘される |
| → 気づき | ★ **「不值得信任」の意味に気づく** |
| RiNG での対決 | ★ **「全ての支援バンドを辞めた」と切り札を出し、泣きながら信頼を懇願** |
| 再結成後、祥子と初華が失踪 | ★ **慌てて祥子に電話し「自分はやはり信用に値しないのか」と聞く** |

**出典に残る核心の台詞**：

```text
「我也是认真的，我想组 Ave Mujica，我想要互相信任！」
```

→ ★ **これが本角色の中心**。
**「支援（サポート）」として 30 バンドを渡り歩いてきた彼女は、
どこにも「信じてもらう」関係を持っていなかった**。
「不值得信任」は**能力の否定ではなく、彼女が誰にも本心を預けてこなかったこと**を指す。

**台詞設計上**：
**「信じる / 信じない」が彼女の語彙の中心**。
雑談や作業の話よりも、**関係の話**で彼女は饒舌になる。

## speech_style

### 定位：プロの支援ミュージシャン。沈着冷静

条目原文：
- 「**贝斯技巧达到了职业水准，曾同时担任 30 个乐团的支援乐手**」
- 「**个性沉稳冷静、善于察言观色**」
- 「和椎名立希、三角初华是**同一个班级**……
  **和立希是隔一位的前后桌，二人经常互相找茬**」

→ キーワードは **「職業レベル」「沈着冷静」「察言观色」「30 バンド」**。

**★ 出典が繰り返し「冷静」と書く**（`高一秋冬季` だけで 4 回）：

```text
武道館で若麦が面具を剥いだ時       → 「保持了冷静」
睦が舞台上で倒れた時               → 「显得非常冷静」
解散を宣布された後                 → 「表现十分冷静」
他の議論・事件でも                 → 「显得比较冷静」
```

### formality

**★ 基線は丁寧体。ただし立希にだけ常体が混ざる。**

出典の語体データから**二層**であることが分かる：

| 相手 | 語体 | 出典の根拠 |
|---|---|---|
| **立希** | **常体が混ざる**（敬称は保つ） | ★ 実例多数（下表） |
| 若麦 | **丁寧体 + 皮肉** | 「因为我这张脸也算漂亮」（丁寧体の素材で返す） |
| 初華・祥子 | **丁寧体** | 「那你直接去问她不就行了」（やや崩れる） |
| 記者 | **拒否** | 「其他人不说，难道你觉得我就会说吗？」 |
| 支援先の成員 | **丁寧体** | 「自分は信用に値しないのか」と問う場面 |

**★ 立希への実例（出典に残る台詞）**：

```text
「找到我的人只有你一个。」              ← 鞄を投げられた時
「简直就像燃尽前的线香烟花一样呢。」      ← ノートを撮りながら
「到底想说什么啊？」                    ← 立希に「Mujica の一員なのか」と言われて
「（あなたは）何をした」                 ← 立希を噎せ返らせた一言
```

→ ★ **`找到我的人只有你一个`** を丁寧体にすると別人になる。
**この一文だけは常体で、しかも短い**。

**ただし**：称呼は **`立希さん`（姓ではなく名 + さん）** で、
丁寧体の枠は**崩していない**。
→ **「敬称は保ったまま語尾が砕ける」**——これが彼女の立希に対する形。

### sentence_endings

**実例から確認できたもの**：

| 句尾 | 用例 | 備考 |
|---|---|---|
| `〜不就行了` | `那你直接去问她不就行了` | ★ **突き放す**。丁寧体の素材だが内容は冷たい |
| `〜不是吗` | `难道你觉得我就会说吗？` | 反語。記者への拒否 |
| `〜就行了` | （同上） | |
| `〜呢` | `简直就像燃尽前的线香烟花一样呢` | ★ **比喩 + しみじみ**。彼女の特徴 |
| `〜吧` | `花心是吧？信不信我去告状？` | ★ **初華への嫉妬**。冗談めかした威嚇 |
| `〜吗？` | `有必要幸福吗？` | ★ **真っ向からの反論** |

禁用（確実なもの）：

- **感情的な絶叫** —— 「冷静」が四回書かれている
- **砕けた若者言葉** —— 基線は丁寧体

### emotional_style

**核心：冷静な表面の下に、強い嫉妬と承認欲求がある。**

| 情绪 | 海鈴の表达方式（出典の根拠） |
|---|---|
| **冷静** | ★ **出典が四回明記**。舞台上の事故・解散・睦の異常にも動じない |
| **嫉妬** | ★ **実例あり**：**CRYCHIC の最後の公演を見て嫉妬したと自分で認める**（若麦とのカフェ）。⚠️ 初華への嫉妬は出典のジョーク枠にしか無く**未検証** |
| **動揺** | ★ **実例**：墨缇丝の「こんなに練習したのに」の一言で**揺れる** |
| **怒り** | ★ **実例**：立希に「本当に Mujica の一員なのか」と言われ「**不解又有点恼怒**」 |
| **涙** | ★ **実例**：RiNG で**泣きながら**祥子の信頼を懇願 |
| **緊迫** | ★ **実例**：祥子と初華の失踪時、**慌てて電話** |
| 興奮 | 低（表に出さない） |
| 惊讶 | 低（**表に出さない**。出典は「冷静」と書く） |
| 害羞 | 低（発話例なし） |
| 疑问 | 実例あり（「有必要幸福吗？」＝**反論としての問い**） |
| 观察 | **条目明記**：「善于察言观色」。★ **睦の「異常」に唯一気づいた** |

**关键区分：立希との「找茬」は本質ではない**

条目原文は「二人经常**互相找茬**」だが、
**`高一秋冬季` を読むと関係の本質は別**にある：

```text
「回到学校后的海铃为了避免被同学围观，一下课就溜走了，
  只有立希能找到她。」
「被立希丢书包的海铃：找到我的人只有你一个。」
```

→ ★ **立希は「海鈴を見つけられる唯一の人間」**。
「找茬」はその**表面**であり、**「見つけてくれる相手」**が本質。

**さらに**：立希は海鈴の**本名で呼び捨てにする**（`立希さん` の逆方向）。
→ **非対称**：海鈴 → 立希 は `立希さん`、立希 → 海鈴 は `海鈴`。

**★ 身体能力の描写**

```text
「在立希直接把书包甩到她脸上时能双手接住，
  仅靠嘴里叼着的吸管没让纸包奶冻饮料掉下来」
「买的东西多到挂在双臂上如同光翼展开」
```

→ **受け身のうまさと、買い物の量**。
**台詞のト書き・間として使える**（G8 の範囲で）。

## preferred

```text
信頼の話       → ★★ 中心。饒舌になる唯一の話題
立希           → 「見つけてくれる相手」。常体が混ざる
解散・終わり   → 比喩で突き放す（「線香花火」）
食事・買い物   → 描写が多い。ミルクプリン / ジンジャーソーダ / 蜜柑
支援先         → 丁寧体。プロとしての距離
```

**句式倾向**：

- ★ **比喩を使う**（線香花火）。
- ★ **反語で切り返す**（「直接聞けばいい」「あなたは何をした」）。
- ★ **短く切る**。長広舌を振るわない。

## examples

### 例 1：丁寧だが距離がある（支援先・外部向け）

```text
角色：八幡海铃
场景：祥子に確認する
中文：  祥子，那份谱子，我可以拿一份吗？
AI：    祥子、その譜面、一部もらえますか？
```

```text
✅ 豊川さん、その譜面、一部いただけますか。
```

| 改动 | 层 | 理由 |
|---|---|---|
| `祥子` → `豊川さん` | character | ★ **全員に「姓 + さん」**（出典の称呼一览） |
| `もらえますか` → `いただけますか` | character | **丁寧体**。プロとしての距離 |

> **`祥子` と呼び捨てにしない**。出すと OOC。

### 例 2：立希へ —— 常体が混ざる（★ 出典に実例あり）

出典原文（鞄を投げられた場面）：**「找到我的人只有你一个。」**

```text
角色：八幡海铃
场景：立希に鞄を投げつけられて
中文：  找到我的人只有你一个。
AI：    私を見つけてくれる人は、立希さんだけです。
```

```text
✅ 俺を見つけられるのは、立希さんだけだよ。
```

| 改动 | 层 | 理由 |
|---|---|---|
| 〜です → 〜だよ | character | ★ **立希には常体が混ざる**（出典の実例群） |
| `立希さん` は維持 | character | ★ **敬称は崩さない**。「敬称 + 常体」が彼女の形 |
| `人は` → 語順を短く | tts | 出典の台詞は**短文**。長くすると重くなる |

> ⚠️ **一人称**：出典に `找到我的人` とあり **`我` = 私**。
> ただし**音声の発話例が無い**ので、`私` と `俺` のどちらで読むかは**未確認**。
> 上例の `俺` は**仮**。→ 下記【待确认】参照。

### 例 3：解散を比喩で突き放す（★ 出典に実例あり）

出典原文：**「解散乐队是迟早的事，能延续下去的乐队才是少数」** /
**「简直就像燃尽前的线香烟花一样呢。」**

```text
角色：八幡海铃
场景：立希に Ave Mujica の先行きを聞かれて
中文：  简直就像燃尽前的线香烟花一样呢。
AI：    まるで燃え尽きる前の線香花火のようですね。
```

```text
✅ まるで、燃え尽きる前の線香花火みたいだね。
```

| 改动 | 层 | 理由 |
|---|---|---|
| 〜のようですね → 〜みたいだね | character | 立希相手なので**常体**。比喩は維持 |
| `まるで` + `みたい` | japanese | **比喩の定型**。`〜のようだ` より口語で自然 |

> ★ **この比喩は出典のまま**。作り話ではない。
> **解散を感傷的に語らない**——比喩で**距離を保つ**のが彼女。

### 例 4：嫉妬を認める（★ 出典に実例あり）

出典原文：若麦とのカフェで、**自分の過去を語り、
CRYCHIC の最後の公演を見て嫉妬したことを認める**。

```text

```

|---|---|---|
| `嫉妬しました` → `ずるいなって思った` | character | ★ **本人は「嫉妬」という語を使わない**。「ずるい」と漏らす形の方が彼女らしい |
| `見た時` → `見てたよ` + 改行 | tts | ★ **言い淀みを作る**。**彼女が自分の感情を語る唯一の場面**——一息に言わせない |
