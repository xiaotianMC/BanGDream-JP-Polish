## TTS 特别注意

### ★ 名前の表記

| 表記 | 読み | リスク |
|---|---|---|
| にゃむ | にゃむ | 低（**平仮名**） |
| 祐天寺 | ゆうてんじ | **高。「ゆうてんじ」は難読**（寺名でもある） |
| アモーリス | アモーリス | 低（片仮名） |

★ **名前が平仮名なので TTS 的に安全**。
**姓「祐天寺」が難読**——寺の名前でもあるが、人名としての読みは ゆうてんじ。

登録済み（`../../dictionary/pronunciation.yaml`）。

### `〜コ` 系愛称の読み

`サキコ` `ウイコ` `ウミコ` `ムーコ` は**片仮名**なので読みは安定。
**ただし元の名前と読みが変わる**：
- `ウイコ` ← 初華（**ういか**）
- `ウミコ` ← 海鈴（**うみり**）
- `ムーコ` ← 睦（**むつみ**）

→ ★ **`ういか` → `ウイコ`、`うみり` → `ウミコ`、`むつみ` → `ムーコ`**。
**名前の一部が変わっている**（愛称として作り直されている）。
TTS 的には片仮名なので安全だが、**原文の名前と混同しない**こと。

## examples

### 例 1：配信者的な明るさ

```text
角色：祐天寺若麦
场景：バンドの打ち合わせ
中文：  这个超有感觉的！就这个吧！
AI：    これ、すごくいい感じです！これでいきましょう！
```

```text
✅ これ、めっちゃいいじゃん！　これでいこうよ！
```

| 改动 | 层 | 理由 |
|---|---|---|
| 〜です → 〜じゃん | character + sentence_ending | 常体。**配信者的なノリ** |
| 〜ましょう → 〜いこうよ | character | 常体の勧誘 |
| `めっちゃ` | character | 砕けた強調 |

### 例 2：`〜コ` 系愛称

```text
角色：祐天寺若麦
场景：メンバーに話しかける
中文：  祥子，那个谱子给我看看。
AI：    祥子さん、その譜面、見せてください。
```

```text
✅ サキコ、その譜面、見せて。
```

| 改动 | 层 | 理由 |
|---|---|---|
| `祥子さん` → `サキコ` | character | ★ **片仮名の愛称**（出典の称呼一览） |
| 〜ください → 〜て | character | 常体。**短文** |

> ★ **この呼び方がアヴェムジカで彼女だけ**。
> 海鈴（`豊川さん`）・初華（`さきちゃん`）と**三者三様**。

### 例 3：Amoris の「愛」——広義

```text
角色：祐天寺若麦
场景：家族の話
中文：  因为我喜欢大家啊。这种心情是不会变的。
AI：    みんなのことが好きだからです。この気持ちは変わりません。
```

```text
✅ アタシ、みんなのこと好きなんだよね。……この気持ちは変わんないよ。
```

| 改动 | 层 | 理由 |
|---|---|---|
| `私` → `アタシ` | character | ★ **片仮名の一人称** |
| 〜です → 〜なんだよね | character | 常体。**説明 + 共感** |
| 対象を「みんな」に | character | ★ **`Amoris` は広義の愛**（家族愛・友愛） |

> ★ 条目原文：「更接近英语语境中"love"的广泛含义……
> 乃至亲情、友爱等多元情感」。
> **恋愛の文脈に寄せない**——`Amoris` の説明はそれを避けるために長い。
