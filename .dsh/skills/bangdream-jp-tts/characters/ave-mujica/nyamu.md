## TTS 特别注意

### ★ 名字的表记

| 表记 | 读音 | 风险 |
|---|---|---|
| にゃむ | にゃむ | 低（**平假名**） |
| 祐天寺 | ゆうてんじ | **高。「ゆうてんじ」属于难读**（也是寺名） |
| アモーリス | アモーリス | 低（片假名） |

★ **名字是平假名，所以对 TTS 来说安全**。
**姓「祐天寺」属于难读**——虽然也是寺庙的名字，但作为人名的读音是 ゆうてんじ。

已登记（`../../dictionary/pronunciation.yaml`）。

### `〜コ` 系爱称的读音

`サキコ` `ウイコ` `ウミコ` `ムーコ` 是**片假名**，所以读音稳定。
**但与原本的名字读音不同**：
- `ウイコ` ← 初華（**ういか**）
- `ウミコ` ← 海鈴（**うみり**）
- `ムーコ` ← 睦（**むつみ**）

→ ★ **`ういか` → `ウイコ`、`うみり` → `ウミコ`、`むつみ` → `ムーコ`**。
**名字的一部分发生了变化**（作为爱称被重新制作）。
对 TTS 来说因为是片假名所以安全，但**不要与原文的名字混淆**。

## examples

### 例 1：配信者的开朗

```text
角色：祐天寺若麦
场景：バンドの打ち合わせ
中文：  这个超有感觉的！就这个吧！
AI：    これ、すごくいい感じです！これでいきましょう！
```

```text
✅ これ、めっちゃいいじゃん！　これでいこうよ！
```

| 改动 | 层 | 理由 |
|---|---|---|
| 〜です → 〜じゃん | character + sentence_ending | 简体。**配信者式的劲头** |
| 〜ましょう → 〜いこうよ | character | 简体的劝诱 |
| `めっちゃ` | character | 口语化的强调 |

### 例 2：`〜コ` 系爱称

```text
角色：祐天寺若麦
场景：メンバーに話しかける
中文：  祥子，那个谱子给我看看。
AI：    祥子さん、その譜面、見せてください。
```

```text
✅ サキコ、その譜面、見せて。
```
