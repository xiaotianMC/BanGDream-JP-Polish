## speech_style

### ★ 定位：感情表現の欠落。そして別人格

条目原文：
- 「**缺乏情感表达，平时也是沉默不语的孩子**」
- 「是月之森校园**园艺部**的一员，**种植黄瓜**还种植有番茄和茄子等」
- 「曾是 CRYCHIC 的吉他手，**丰川祥子的青梅竹马**」

→ キーワードは **「無表情」「寡黙」「園芸」「祥子の幼馴染」**。

### ★★ 別人格「モーティス」——本角色最大の特徴

条目の称呼一览に、睦の自称が **`私` / `睦ちゃん` / `モーティス`** と
**三つ**記録されている。

さらに**他キャラからの呼称**にも別人格が現れる：
- 海鈴 → `若葉さん` / **`モーティスさん`**
- にゃむ → `ムーコ` / （なし）
- 祥子 → `睦` / **`モーティス`**
- 初華 → `睦ちゃん` / （なし）

→ ★ **「モーティス」は睦の別人格**（コードネームと同じ名前）。
**`睦ちゃん` と `モーティス` は別の人格として扱う必要がある**。

**重要な制約**：条目は別人格について
`轶事` に **`关于姐妹的推测`** という独立した小節を持つほど
**設定が複雑**。**本ファイルでは詳細を確定しない**——
**別人格の使い分けが必要な場面では必ず【待确认】に出す**。

> ⚠️ **推測で人格を書き分けない。** どちらの人格として話しているかが
> 台本から読み取れない場合、**それは台本側の不足**であり、
> Skill が補うべき情報ではない（G8）。

→ `rana.md` と同じ問題。**沈黙をどう扱うかは adapter の検証対象**。

## examples

### 例 1：極端に短い応答

```text
角色：若叶睦
场景：祥子に話しかけられる
中文：  我知道了。
AI：    わかりました。
```

```text
✅ ……うん。
```

| 改动 | 层 | 理由 |
|---|---|---|
| `わかりました` → `……うん` | character | **感情表現の欠落**。最短で返す |
| `……` を先頭に | tts + character | 反応の遅さ |

> **説明しない**。条目原文「缺乏情感表达，平时也是沉默不语」。

### 例 2：黄瓜（園芸）

```text
角色：若叶睦
场景：育てた黄瓜について
中文：  黄瓜，长出来了。
AI：    きゅうりが、できました。
```

```text
✅ きゅうり、できた。
```

| 改动 | 层 | 理由 |
|---|---|---|
| 〜ました → 〜た | character + sentence_ending | 常体。**短文** |
| 主語を省く | japanese | 「きゅうり」だけで通じる |

> 条目原文：「种植黄瓜」。**彼女が自分の意思で何かを語る稀な場面**。
> ただし**感情を足さない**——「うれしい」などは条目に根拠がない。

### 例 3：別人格 —— 【待确认】が必要な例

```text
角色：若叶睦
场景：別人格「モーティス」が表に出ている場面
中文：  我才是真的。她只是模仿。
AI：    私が本物よ。あの子はただの模倣。
```

```text
⚠ 出力保留。
【待确认】別人格「モーティス」の人格設計が本ファイルでは未確定。
・条目に `关于姐妹的推测` という独立小節があり、設定が複雑
・自称が `私` / `睦ちゃん` / `モーティス` と分かれることは出典に明記されているが、
  **それぞれの人格の語体・一人称・口調は記載されていない**
・台本に「どちらの人格か」の指定が必要。推測で書き分けない（G8）。
```

| 判断 | 理由 |
|---|---|
| 出力しない | **人格の書き分けは推測になる**。条目に語体の記載が無い |
| 【待确认】に出す | どちらの人格か＝台本側が指定すべき情報 |

> ★ **この例が示す判断の型**：キャラクターの根幹に関わる不明点は、
> **それらしい台詞で埋めない**。埋めると**間違った人格を固定してしまう**。
