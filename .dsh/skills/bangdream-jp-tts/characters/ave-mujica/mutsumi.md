★ **ただし `高一秋冬季` で「寡黙」に理由が付いた**：

| 条目 `简介` の言い方 | `高一秋冬季` が足すもの |
|---|---|
| 「缺乏情感表达」 | ★ **発話が**（無感情だからではなく）**「一説話すと物事が悪くなる」という信念**で回避されている |
| 「沉默不语」 | ★ 周囲は**睦の異常に誰も行動しなかった**（無視されているのではなく、**異常が異常として扱われない**） |

→ ★ **「無感情」ではなく「出力の抑制」＋「周囲の不感応」の二重構造**。
**台詞設計では、この二つを混同しない**。

### ★★ 別人格「モーティス」——語体は**未確認**のまま

条目の称呼一览に、睦の自称が **`私` / `睦ちゃん` / `モーティス`** と
**三つ**記録されている。

さらに**他キャラからの呼称**にも別人格が現れる：
- 海鈴 → `若葉さん` / **`モーティスさん`**
- にゃむ → `ムーコ` / （なし）
- 祥子 → `睦` / **`モーティス`**
- 初華 → `睦ちゃん` / （なし）

→ ★ **「モーティス」は睦の別人格**（コードネームと同じ名前）。
**`睦ちゃん` と `モーティス` は別の人格として扱う必要がある**。

**★★ 今回の抽出結果（最重要）**：

```text
出典は依然としてモーティスの語体を記述していない。
  一人称 ……… 記載なし
  語尾・口癖 … 記載なし
  敬語レベル … 記載なし
  声質 ……… 記載なし（「尖叫鬼叫」以外）

```

**ただし、語体とは別に「話し方の機構」として 3 点が根拠づけられた**：

| 根拠づけられた事実 | 出典の記述 |
|---|---|
| ① 初出の芝居は**異なる腔调**だった | `以异乎往日的腔调来了一段话剧表演` |
| ② **他人の話し方を時々真似る** | `还会时不时学其他人说话` |
| ③ 発話が**既存の台詞の寄せ集め** | 睦を模仿／愛音が「森南出演ドラマの台词」と指摘／看破されて`机械地复读` |

→ ★ **①②③ は「語体」ではない。「演技の材料」である。**
**これらから語尾や一人称を決めることはできない**（G8）。

> ⚠️ **推測で人格を書き分けない。** どちらの人格として話しているかが
> 台本から読み取れない場合、**それは台本側の不足**であり、
> Skill が補うべき情報ではない（G8）。

## TTS 特别注意

### 名字读音

| 表记 | 读音 | 风险 |
|---|---|---|
| 睦 | **むつみ** | **高。「むつき」「まこと」等と誤読されやすい** |
| 若葉 | わかば | 低〜中（一般語） |

★ **`睦` を `むつみ` と読むのは難読**。登録済み（`../../dictionary/pronunciation.yaml`）。

### `モーティス` の扱い

コードネーム `Mortis` は英字。G9 により本文は片仮名「モーティス」。
**ただし別人格としての呼称でもある**ので、
**どちらの意味で使われているか**を台本から判断する必要がある。

★ **`モーティス` の語体が未確認である以上、
`モーティス` の行に TTS 上の声色・速度の指定を書くこともできない**。
→ **指定が必要な場合は【待确认】に出す**。

### 沈黙の読み

**台詞が極端に短い、または無言の場面**では、
TTS 的には**行そのものを出力しない**という選択がある。

→ `rana.md` と同じ問題。**沈黙をどう扱うかは adapter の検証対象**。

★ **睦の「間」は演出上有意味**（反応の遅さ）。
**`……` を足すかどうかも adapter の検証対象**（推測で定型化しない）。

### 断句

**睦の台詞は天然に短い**。
長い訳文が出てきたら、それは**原文が長い**のではなく
**翻訳が説明を足している**可能性が高い。

```text
✅ 短く切る（出典の引用はすべて一息）
❌ 丁寧に繋いで長くする（「沉默不语」に反する）
```

★ **「不会长久」は 4 字**。**日本語でも同等に短く**。
**補足説明を足さない**（★ 意図自体が出典に無い → 足すと捏造になる）。

## examples

### 例 1：一言で状況を沈める（★ 出典に実例あり）

出典原文（武道館前、車中。祥子が泣きながら父を罵っている場面）：
**「睦却只问了一句『武道馆没问题吗』」** →
**出典は、それだけで「祥子的情绪稳定了下来」と書く**。

```text
角色：若叶睦
场景：車中、泣き叫ぶ祥子に対して
中文：  武道馆，没问题吗？
AI：    武道館は、大丈夫ですか？
```

```text
✅ 武道館、大丈夫？
```

| 改动 | 层 | 理由 |
|---|---|---|
| `大丈夫ですか` → `大丈夫？` | character | **常体**。出典の発話は**一句**で、敬体の枠を持たない |
| 助詞 `は` を落とす | japanese + tts | ★ **息を短くする**。出典は「只问了一句」＝**追加説明が無い** |

> ★ **この一句の効果は出典が明記している**（祥子の情緒が安定した）。
> → **説明を足してはいけない**。「大丈夫？」だけで状況が動くのが彼女。
> ⚠️ **話者の同定には出典上グレーな点がある**（原文は「睦却只问了一句」と
> 読めるが、直前に複数の人物が並ぶ）。**睦の発話として扱うが、
> 台本で別の話者になっていたら【待确认】に出す**。

### 例 2：失言恐怖 —— 発話の最小化（★ 出典に因果の記述あり）

出典：東京に戻った後、祥子が睦を拷问した際、
★ **睦は「自分が一説話すと物事が悪くなる」と考える**。
これは**「不会长久」の一件**（自分の発話が解散と解読された）と結びついている。

```text
角色：若叶睦
场景：祥子に「なぜ自分の側に立たないのか」と問い詰められて
中文：  （我）一说话，事情就会变糟。
AI：    私が何か言うと、物事が悪くなってしまうんです。
```

```text
✅ ……わたしが、しゃべると。
　　わるくなるから。
```

| 改动 | 层 | 理由 |
|---|---|---|
| `悪くなってしまうんです` → `わるくなるから` | character | **常体**。かつ★ **理由を述べる形を保つ**（出典は「考える」内容として提示） |
| 一文を二行に割る | tts | ★ **言い淀み**。**これが彼女が長く話す数少ない場面**——滑らかに言わせない |
| `私` → `わたし`（仮名） | 表記 | ⚠️ **一人称の読みは未確認**。下記【待确认】参照 |
