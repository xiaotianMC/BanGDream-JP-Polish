# Japanese 规则

日语自然度层。处理"语法没错、但日本人不会这么说"的问题。

**优先级低于角色规则，高于 TTS 规则。** 也就是说：一个表达即使对 TTS 不太友好，只要它是角色的真实说话方式，就应该保留。

> ★ **登场人物全部是女性**（G11）。如果偏向男性语，
> 就按 `rules/global.md` 的 **G11** 修正。
> 但**机械地补上女性语尾同样糟糕**——要读 G11 的「过度修正」一节。

---

## J0 两遍法：先译得像日本人说话，再用规则复核

**这是所有翻译模式的默认流程**（用户指定 2026-02-14）。
`SKILL.md` 的 `Execution order` 会引用本节。

### 为什么分两遍

一次翻译里同时满足角色语尾、TTS 读音、专有名词统一、句长上限，
**结果必然发硬**——每加一条约束，句子就离"日本人真会这么说"远一点。

→ **先把自然度做出来，再让规则去复核它。**
规则的作用是**挑剔和修正**，不是**从零生成**。

```text
❌ 试图在一遍里同时满足所有约束 → 约束有多少，译文就有多生硬
✅ ① 先作为自然的日语来翻译（不在意约束）
   ② 再对这份初版套用所有层的规则来修改
```

### Pass 1：自然初版（有意避开规则）

**目的只有一个：「日本人实际会这么说吗」。**
以下这些**在 Pass 1 不适用**：

```text
× 角色的语尾・第一人称・口癖（characters/<角色>.md）
× 称呼表（address-forms.yaml）
× TTS 的断句・表记・读音（rules/tts.md）
× 专有名词的统一（proper-nouns.yaml。但**已知的人名原样保留**）
× 句长上限
```

**但 Pass 1 也必须绝对遵守的东西**：

```text
✅ G1 不改变语义・不增减信息   ← 这里不能放宽
✅ G3 不过度润色
✅ 不丢失中文原文所带的信息
✅ 已知的人名不擅自造译名，原样保留
```

> ⚠️ **「抛开规则」并不等于「随便翻译」。**
> Pass 1 的目标是**自然**，而不是**草率**。
> 不是「没有约束就可以省略」——**信息量不能减少**。

### Pass 2：用规则复核初版

对初版**从上到下依次**套用规则（`SKILL.md` 的 Stage 1〜6）。

★ **Pass 2 不是「评价」，而是「修改」**：

```text
✅ 逐一推敲初版的用词
   「这个词是不是书面语」「助词是否正确」
   「节奏是不是口语的节奏」
✅ 无需修改的地方原样保留
❌ 全部重写（＝ Pass 1 不够自然的证据。要重做）
```

### ★ 规则破坏自然度时

**不能为了通过规则而降低自然度。**

```text
❌ 为了满足规则，故意用不自然的说法
❌ 为了满足规则，删掉信息
❌ 为了满足规则，偏向不像角色的平板说法
```

规则与自然度**无法两立**时，
**不要擅自二选一，而是列入【待确认】**（G8）：

```text
【待确认】<文> — 满足<规则>会降低自然度。
  案A（规则优先）: <…>
  案B（自然度优先）: <…>
  → 请指定采用哪一个
```

> **Skill 不判断哪个更正确。** 只提示，让对方选。

### 把 Pass 1 留在输出中

**不要丢掉初版。** 在输出中以 `【自然初版】` 一并列出。
如果用户无法比较两者，就无法验证 Pass 2 做了什么。

## J1 书面语 → 口语

### 判断前提

**不是所有书面语都要改。** 先判断说话场景：

| 场景 | です・ます 是否合适 |
|---|---|
| 对长辈 / 前辈 / 老师 / 客人 | ✅ 正确，保留 |
| 营业、正式宣传、致词 | ✅ 正确，保留 |
| 同辈朋友间日常对话 | ⚠️ 视角色而定 |
| 兴奋、惊讶、吐槽、情绪爆发时 | ❌ 通常不自然 |

同一句「〜です」在营业场合是对的，在私下兴奋时是错的。**脱离场景判断"书面语"是错的。**

### 常见改写方向

```text
今日は本当に楽しかったです。
→ 今日は本当に楽しかった！
```
→ 同辈 + 情绪高扬时，です 显得疏离。降为常体。

```text
私はとても嬉しいです。
→ めっちゃ嬉しい！ / すごく嬉しい！
```
→ 「私は」在日语口语中通常省略（见 J2-1）。副词口语化。

```text
〜をすることができます。
→ 〜できる
```
→ 形式名词 + する 的复合结构在口语中会缩。同类：

```text
〜ということはない    → 〜ってことはない
〜してしまいました    → 〜しちゃった
〜しておきます        → 〜しとく
〜ている              → 〜てる
〜なければならない    → 〜なきゃ / 〜ないと
〜かもしれません      → 〜かも
〜でしょう            → 〜でしょ
```

### 反向陷阱

**不要过度口语化。** 把每一句都塞满「〜じゃん」「〜っしょ」「〜だわ」会让角色变成刻板印象，也会违反 G2/G3。

判断依据始终是：**这个角色在这种场合会这么说吗**，而不是"口语化 = 好"。

## J2 中文式表达

AI 翻译最常见的失败模式：语法正确，但结构是中文的。

### J2-1 主语冗余

中文习惯"我……你……他……"，日语口语倾向于省略已知主语。

```text
私は今日はとても楽しいです。あなたはどうですか？
→ 今日めっちゃ楽しい！そっちは？
```

**注意**：日语省略主语依赖上下文。当主语不明确、或需要强调对比时（「私がやる」vs「あなたがやる」），主语**必须**保留。省略过头会造成歧义，违反 G1。

### J2-2 代词与称呼

日语口语很少用「あなた」「彼」「彼女」直接称呼对方。

```text
あなたはすごいですね！
→ 有咲、すごいね！      （用名字）
→ すごいね！            （省略）
```

- 「あなた」对同辈使用会显得生硬甚至挑衅。仅在妻子对丈夫等特定语域成立。
- 「彼」「彼女」作主语时，日语常说名字或省略。
- 称呼形式查 `../dictionary/address-forms.yaml`。

### J2-3 助词误用

| 误 | 正 | 说明 |
|---|---|---|
| 〜に行く：学校**に**行く | 学校**に**行く ✅ | 这个是正的 |
| 日本語**を**上手です | 日本語**が**上手です | な形容词的对象用 が |
| 私**は**好きです（偏爱对象） | 私**が**好きです | 「我喜欢 X」是 X が 好き |
| 〜**と**同じ | 〜**と**同じ ✅ | 但「〜と同じぐらい」注意 |
| ライブ**を**参加する | ライブ**に**参加する | 参加 用 に |
| 〜**を**会う | 〜**に**会う | 会う 用 に |

### J2-4 语序

日语是 SOV，修饰从句在被修饰词前。中译常见的语序残留：

```text
我很高兴能和大家一起办演唱会。
→ ❌ 私はとても嬉しいです、みんなと一緒にライブができて。
→ ✅ みんなと一緒にライブができて、とても嬉しい！
```

日语口语里，**原因/条件从句在前，结论在后**是最自然的顺序。中文的"结果 + 补充原因"结构直译过来会断裂。

### J2-5 敬语错位

- **二重敬语**：「おっしゃられる」「ご覧になられる」→ 「おっしゃる」「ご覧になる」
- **过度谦让**：不需要自谦的场合使用谦让语，会显得滑稽或疏远。
- **敬语等级跳变**：同一段话内 です・ます 与 だ・である 混杂而无理由。口语中偶发混杂是自然的（句末调整），但成段混杂通常是翻译残留。
- **角色敬语基线**：每个角色的敬语基线见 `../characters/<band>/<角色>.md`。**不要越过角色设定去统一敬语等级**（违反 G4 / 原则 3）。

### J2-6 中日同形异义词

中文词直译成日语汉字，词义不对：

| 中文 | 错误直译 | 正确日语 |
|---|---|---|
| 检讨 | 検討（=研究讨论） | 反省 |
| 汽车 | 汽車（=蒸汽火车） | 車 / 自動車 |
| 大丈夫（中文"大丈夫"） | — | 大丈夫 = 没问题 |
| 勉强 | 勉強（=学习） | 無理 |
| 爱 | 愛（书面/沉重） | 好き |
| 心情 | 心情（少用） | 気持ち |

**注意**：「愛」在日语中语感很重，日常口语用「好き」。中文"我爱这个乐队" →「このバンド好き」，不是「愛してる」。

### J2-7 语气词的自然位置

日语语气词在句末，且**一个句末通常只放一个**。

```text
❌ 楽しかったよね！
✅ 楽しかったね！  /  楽しかったよ！
```

叠加语气词（「〜だよね」「〜じゃんか」）在特定角色/方言中是特征，但需要角色设定支持，不能通用。

## J3 标点

标点是本层与 TTS 层的交界。这里管**语义正确性**，`tts.md` 管**朗读效果**。

### 基本规则

| 符号 | 用途 | 注意 |
|---|---|---|
| `。` | 句末 | 口语短句常可换 `！`；但陈述句末保留 `。` 更稳 |
| `！` | 感叹、强调、大声 | 日语中「！」后通常**不再加「。」** |
| `？` | 疑问 | 口语中「？」可作疑问标记，也可能只是上升语调 |
| `……` | 犹豫、无语、余韵 | **不是停顿工具**。语义上不需要就不要加（G5） |
| `、` | 并列、短停顿 | 日语逗号密度应低于中文 |
| `ー` | 长音 | 属表记，不属标点。见 `tts.md` T4 |
| `〜` | 范围 / 拖音 | 作范围用「〜」；作拖音时注意引擎处理差异 |

### 常见问题

```text
❌ 楽しかったです！！      → 连续感叹号
✅ 楽しかった！

❌ 本当に？。              → 问号句号连用
✅ 本当に？

❌ 今日は、みんなと、ライブを、して、楽しかった。
✅ 今日はみんなとライブができて、楽しかった！
```
→ 逗号过密会让 TTS 逐词停顿，失去流畅感。

### 中日标点差异

- 中文全角 `，` 与日语 `、` **不是同一个**。日语正式正文用 `、`。
- 中文 `……` 是双省略号，日语 `……`（两点）也常见，单 `…` 亦可。**项目内统一**，不要混用。
- 中文引号 `「」` 与日语一致，但中文书名号 `《》` 在日语中不用。

## J4 检查清单

过一遍日语自然度时，逐项确认：

- [ ] です・ます 使用符合场景与角色基线（不是一律去掉）
- [ ] 没有中文式主语冗余
- [ ] 「あなた」「彼」「彼女」未滥用
- [ ] 助词搭配正确（が/を/に/と）
- [ ] 语序符合日语（原因在前、结论在后）
- [ ] 无二重敬语、无敬语等级无理由跳变
- [ ] 无中日同形异义词
- [ ] 句末语气词未叠加
- [ ] 标点密度合理，无连续标点
- [ ] 同形异义、惯用搭配无误
