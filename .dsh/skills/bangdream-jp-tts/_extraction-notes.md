# 出典抽出の運用記録（G10 の実例集）

> **これは作業メモではなく、恒久的な運用記録。**
> Ave Mujica 5 人の `高一秋冬季` 抽出（2026-02-14）で**実際に踏んだ誤りと、
> そこから得た横断的な知見**を残す。
>
> 一次メモ（`_extract-<角色>.md`）は各角色ファイルへ折り込み済みで**削除した**。
> 本ファイルは**抽出・引用の手順に関わる知見のみ**を保持する。

## 1. ★★ 出典 HTML には「本編でない」テキストが混ざる

抽出ツール（`extract.mjs`）は、対策前は以下のマークアップを
**区別せず地の文に混ぜていた**：

| マークアップ | 意味 | 危険度 |
|---|---|---|
| `<s class="just-kidding-text" title="只为博君一笑，不必照单全收XD">` | **ジョーク枠**。本編の台詞ではない | ★★ 引用すると誤りになる |
| `class="heimu"` | **伏せ字**（マウスオーバーで表示）。ネタバレ・推測・補足 | ★ 地の文と連結され文境界が不明瞭 |

### 実際に踏んだ誤り

`umiri.md` の例 4 に **初華への嫉妬**として
`花心是吧？信不信我去告状？` を引用していたが、
**出典ではこれが `just-kidding-text` に包まれている**。
→ **修正済み**（CRYCHIC への嫉妬＝本人が認めた実例に差し替え）。

さらに、**本編扱いしていた以下の 3 件も出典自身がジョーク指定**であることが判明：

```text
・甜甜圈是被掰开的        ← 真奈がドーナツを半分にする行為
・海铃早就跑得没影了       ← 海鈴が先に帰っていた
・立希への謝罪＋奶冻＋海鈴抓包  ← 初華が立希に謝る場面
```

### ★ 対策（実施済み）

**`extract.mjs` を改修し、これらを抽出結果の中で明示するようにした**：

```text
〖冗談〗…〖/冗談〗     just-kidding-text
〖伏せ字〗…〖/伏せ字〗  heimu
```

→ **抽出結果にこれらのマークが出たら、引用前に必ず判断する**（G10）。

### 既に使用したページのジョーク枠（監査結果・途中まで）

| ページ | 件数 | 注意すべき内容 |
|---|---|---|
| 祐天寺若麦 | 4 | ★ 海鈴との「热度」やり取り全体がジョーク枠 |
| 丰川祥子 | 9 | 父親の投資ネタ等（明らかなネタ） |
| 长崎爽世 | 12 | 愛称・ネタ |
| 千早爱音 | 7 | 愛称・ネタ |
| 高松灯 | 2 | 立希の評価、アカウント推測 |

| 今井莉莎 | 3 | ネタ |

→ **`轶事` 節の内容は特にジョークが多い**。
**角色ファイルに反映するのは `经历` 節を優先し、`轶事` は出典の明示を確認してから。**

## 2. ★ 初華の「正体」について既存記述の誤り

### 誤り：「祥子だけが最終的に `初音` と呼ぶ」

`_extract-uika.md` の指摘：

> 祥子は渡船上でも「**初华你个大笨蛋**」と呼ぶ。
> **本節で `初音` と発話するのは定治のみ。**

→ ★ **`初音` と呼ぶのは 豊川定治（実父）である**。
`address-forms.yaml` の
「祥子 → 初華：`初華/初音さん → 初音`（時間軸）」
は**出典の解釈を誤っている可能性がある**。

**確認が必要**：出典の称呼一覧が `初華/初音さん→初音` と書いているのは
**誰の欄か**。祥子の欄であれば「祥子は初華を初音と呼ぶ」だが、
`_extract-uika.md` の本文記述と矛盾する。

→ ⚠️ **未解決として記録。推測で直さない**（G8）。

**調査結果（2026-02-14）**：`address-forms.yaml` を確認したところ、
`初華/初音さん → 初音` の時間軸は**豊川祥子の `addresses` 節**（＝祥子 → 初華）に
記録されており、出典の**祥子の称呼一覧に基づく**。つまり：

```text
① 祥子の称呼一覧        → 祥子は初華を「初華 → 初音さん → 初音」と呼ぶ（時間軸）
② 高一秋冬季の地の文    → 祥子は渡船上でも「初华」と呼び、
                          「初音」と発話するのは定治のみ
```

→ ★ **両方とも出典に基づく。矛盾を解消できない。**
**どちらか一方を消してはいけない**（G8）。
**「祥子が初音と呼ぶようになる」は時間軸の終点であり、
どの局面からかを出典は明示していない**、と理解するのが安全。

> ★ **豊川定治（実父）が称呼表に未登録**であることも判明。
> `proper-nouns.yaml` にも項目が無い。→ `校准待办` に記載。
> 定治を `address-forms.yaml` の主体にするには
> `proper-nouns.yaml` への登録が先に必要（validator が要求する）。

### 正体が露見した 3 経路（出典明記）

```text
① 豊川家の管家が門前で「明らかに初華を認識して」ドアを開けた
② 初華が豊川家に入った（越界）ことを定治が知った
③ 定治が祥子の面前で「初音，你给我回去。」と呼び、祥子は出国を命じられる
```

図キャプションに「**真名暴露风波平息后**…再次同居」＝
**「真名暴露の騒動」があった**ことが示されるが、
**範囲・周知先は本節に記載なし**。

### ★★ 最も重要な未解決：否定と確定の並置

```text
別荘で初華が自分の身世を交代し、すべての隠蔽と裏切りを謝罪
  → 祥子は「温柔に受け入れる」
観星台で祥子が一件ずつ「その時の『初华』は今の彼女か」を確認
  → 初華は「成为偶像的梦想」も含め**全部否定**
それでも祥子は「**あの夜一緒に星を見たのは今の彼女**」と確定
```

→ ★ **出典は決着させていない。**
**`uika.md` に「どちらが正しいか」を書いてはいけない**（G8）。

### ★ 人形の記憶欠落（「双子説」の証拠・その2）

初華が祥子の持つ**人形**の由来を尋ねる場面。
出典は「**早期『双子説』证据之二——妹妹は人形を見たことがあるが、
今の初華は覚えていない**」と明記（`heimu` 内）。

→ ★ **「記憶に誤りがある」の具体例**。`uika.md` の
「島の回想を詳しく語らせない」制約の**具体的な根拠**になる。

### ★ 「忘记一切」と `Oblivionis` の由来は**初華の誤解**

出典自身が「**误以为（誤解）**」と明示。
初華は**祥子の母の死が理由**だと思い込んでいる。
→ **正しい理由は本節に無い**。

→ ⚠️ `sakiko.md` の `Oblivionis`＝忘却 の説明に
**この「誤解」を混ぜない**。

## 3. ★ 抽出で「資料の水位」が角色ごとに違うことが分かった

同じ `高一秋冬季` を抽出しても、**得られるものが角色ごとに大きく違う**。
**この差を無視して同じ深さのファイルを書こうとすると、推測で埋めることになる**。

| 角色 | 節の長さ | 音声節 | 得られたもの |
|---|---|---|---|
| 豊川祥子 | 15,461 chars | 無し | ★ 台詞 32 件。演技力・自己嫌悪・灯への両義性 |
| 若葉睦 | 13,930 chars | 無し | ★ 台詞 19 件。**モーティスの語体は依然不明** |
| 三角初華 | 10,671 chars | 無し | ★ 正体・記憶の核心。一人称・語尾は依然不明 |
| 八幡海鈴 | 8,853 chars | 無し | ★ 立希への常体、CRYCHIC への嫉妬。「信任」が主題 |
| 祐天寺若麦 | 節自体が無い | 無し | ★ **`经历` 全体**で代替。動機＝熱量、劣等感 |

**重要な含意**：

- ★ **5 人全員に `语音`（音声）節が無い** → **一人称・語尾は 5 人とも確定できない**。
  音声データがあったのは **月島麻里奈（17 行）だけ**。
- → **語尾を「らしく」書きたくなる圧力が最も強い状況**。
  ここで埋めると **G8 違反が 5 人分まとめて発生する**。
  **「未確認」と書いてあることが正しい状態**。

## 4. 図キャプションは台詞を含む

出典の画像キャプション（`<figcaption>`）に**台詞が入っている**ことがある。
例：祥子の `「我来成为神明我不做人了！灯灯！」`、
初華の `「不准从我身边抢走小祥！」`。

→ **地の文だけ読むと取りこぼす**。
ただし **キャプションは場面を要約した編者の文**である可能性があるため、
**「キャプション由来」と区別して記録する**。
