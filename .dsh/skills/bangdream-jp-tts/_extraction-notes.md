## 1. ★★ 出处 HTML 里混有「非正篇」文本

抽取工具（`extract.mjs`）在采取对策前，会把以下标记
**不加区分地混进正文**：

| 标记 | 含义 | 危险度 |
|---|---|---|
| `<s class="just-kidding-text" title="只为博君一笑，不必照单全收XD">` | **玩笑框**。不是正篇台词 | ★★ 引用即成为错误 |
| `class="heimu"` | **涂黑**（鼠标悬停显示）。剧透・推测・补充 | ★ 与正文拼接后句边界不明 |

### 实际踩过的错误

`umiri.md` 的例 4 中，曾把
`花心是吧？信不信我去告状？` 作为 **对初华的嫉妒** 引用，
但**出处中这段被 `just-kidding-text` 包着**。
→ **已修正**（替换为对 CRYCHIC 的嫉妒＝本人承认的实例）。

此外，**以下 3 件曾被当作正篇处理，经查明出处本身也指定为玩笑**：

```text
・甜甜圈是被掰开的        ← 真奈把甜甜圈掰成两半的行为
・海铃早就跑得没影了       ← 海铃先回去了
・向立希道歉＋奶冻＋海铃抓包  ← 初华向立希道歉的场面
```

### ★ 对策（已实施）

**已修改 `extract.mjs`，使这些标记在抽取结果中被明确标出**：

```text
〖冗談〗…〖/冗談〗     just-kidding-text
〖伏せ字〗…〖/伏せ字〗  heimu
```

→ **抽取结果中出现这些标记时，引用前必须先判断**（G10）。

### 已使用页面的玩笑框（审计结果・中途）

| 页面 | 件数 | 需要注意的内容 |
|---|---|---|
| 祐天寺若麦 | 4 | ★ 与海铃的「热度」互动整体都是玩笑框 |
| 丰川祥子 | 9 | 父亲的投资段子等（明显的段子） |
| 长崎爽世 | 12 | 爱称・段子 |
| 千早爱音 | 7 | 爱称・段子 |
| 高松灯 | 2 | 立希的评价、账号推测 |
| 白金燐子 | 4 | 段子 |
| 今井莉莎 | 3 | 段子 |

→ **`轶事` 节的内容尤其多玩笑**。
**反映到角色文件时优先 `经历` 节，`轶事` 要先确认出处的明示。**

## 2. ★ 关于初华的「真身」，既有记述有误

### 错误：「只有祥子最终会称她为 `初音`」

`_extract-uika.md` 的指摘：

> 祥子在渡船上也称她「**初华你个大笨蛋**」。
> **本节中说出 `初音` 的只有定治。**

→ ★ **称 `初音` 的是丰川定治（生父）**。
`address-forms.yaml` 的
「祥子 → 初華：`初華/初音さん → 初音`（时间轴）」
**可能误解了出处**。

**需要确认**：出处的称呼一览写 `初華/初音さん→初音`，
**是谁那一栏**。如果是祥子那一栏，就是「祥子称初华为初音」，但这与
`_extract-uika.md` 的正文记述矛盾。

→ ⚠️ **作为未解决事项记录。不要凭推测修改**（G8）。

**调查结果（2026-02-14）**：确认 `address-forms.yaml` 后发现，
`初華/初音さん → 初音` 的时间轴记录在**丰川祥子的 `addresses` 节**（＝祥子 → 初华）中，
**基于出处的祥子称呼一览**。也就是说：

```text
① 祥子的称呼一览      → 祥子称初华为「初華 → 初音さん → 初音」（时间轴）
② 高一秋冬季的正文    → 祥子在渡船上也称「初华」，
                         说出「初音」的只有定治
```

→ ★ **两者都基于出处。矛盾无法消解。**
**不能删掉其中任何一方**（G8）。
**理解为「祥子开始称她为初音」是时间轴的终点，
出处并未明示是从哪个局面开始**，这样才安全。

> ★ **丰川定治（生父）未登记在称呼表中**也已查明。
> `proper-nouns.yaml` 中也没有条目。→ 记入 `校准待办`。
> 要让定治成为 `address-forms.yaml` 的主体，
> 需要先登记到 `proper-nouns.yaml`（validator 会要求）。

### 真身暴露的 3 条路径（出处明记）

```text
① 丰川家的管家在门前「明显认出了初华」并开了门
② 定治得知初华进入了丰川家（越界）
③ 定治当着祥子的面称「初音，你给我回去。」，祥子被命令出国
```

图注中「**真名暴露风波平息后**…再次同居」＝
提示**曾有过「真名暴露的骚动」**，
但**范围・周知对象本节没有记载**。

### ★★ 最重要的未解决：否定与确定的并置

```text
在别墅初华交代了自己的身世，为所有隐瞒与背叛道歉
  → 祥子「温柔地接受」
在观星台祥子逐一确认「那时的『初华』是现在的她吗」
  → 初华连「成为偶像的梦想」也**全部否定**
即便如此祥子仍确定「**那晚一起看星星的是现在的她**」
```

→ ★ **出处并未给出结论。**
**不得在 `uika.md` 中写「哪一方正确」**（G8）。

### ★ 人偶的记忆缺失（「双子说」的证据・之二）

初华询问祥子持有的**人偶**由来的场面。
出处在 `heimu` 内明记「**早期『双子说』证据之二——妹妹见过人偶，
现在的初华却不记得**」。

→ ★ **「记忆有误」的具体例子**。它成为 `uika.md` 的
「不让详谈岛上回忆」这一约束的**具体根据**。

### ★ 「忘记一切」与 `Oblivionis` 的由来是**初华的误解**

出处自身明示「**误以为（误解）**」。
初华误以为理由是**祥子母亲的死**。
→ **真正的理由本节没有**。

→ ⚠️ 不要把它混进 `sakiko.md` 的 `Oblivionis`＝忘却 的说明中。

## 3. ★ 抽取中发现「资料的水位」因角色而异

即使抽取同一个 `高一秋冬季`，**不同角色能得到的也大不相同**。
**无视这个差异去写同样深度的文件，就会靠推测来填补**。

| 角色 | 节长度 | 语音节 | 得到的东西 |
|---|---|---|---|
| 豊川祥子 | 15,461 chars | 无 | ★ 台词 32 件。演技力・自我厌恶・对灯的两义性 |
| 若葉睦 | 13,930 chars | 无 | ★ 台词 19 件。**莫提斯的语体依然不明** |
| 三角初華 | 10,671 chars | 无 | ★ 真身・记忆的核心。第一人称・语尾依然不明 |
| 八幡海鈴 | 8,853 chars | 无 | ★ 对立希的常体、对 CRYCHIC 的嫉妒。「信任」是主题 |
| 祐天寺若麦 | 节本身不存在 | 无 | ★ 用**整个 `经历`** 替代。动机＝热量、劣等感 |

**重要的含义**：

- ★ **5 人全都没有 `语音` 节** → **5 人的第一人称・语尾都无法确定**。
  有语音数据的**只有月岛麻里奈（17 行）**。
- → **这是「想把语尾写得『像样』」的压力最强的状况**。
  在这里填补会**一次性发生 5 人份的 G8 违规**。
  **写着「未确认」才是正确的状态**。

## 4. 图注也含有台词

出处的图片说明（`<figcaption>`）中**有时含台词**。
例：祥子的 `「我来成为神明我不做人了！灯灯！」`、
初华的 `「不准从我身边抢走小祥！」`。

→ **只读正文会漏掉**。
但**说明有可能是编者概括场面的文字**，所以要
**与「来自图注」区分开来记录**。
